# Stoch (SlowK, SlowD) - Стохастический осциллятор (Stochastic Oscillator)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса в диапазоне 0–100

---

## Краткое описание
💡 Стохастический осциллятор измеряет положение текущей цены закрытия относительно ценового диапазона за заданный период. Значения колеблются в фиксированном диапазоне 0–100, где уровни выше 80 указывают на зону перекупленности, а ниже 20 — на перепроданность. Метод возвращает **медленную версию** индикатора (Slow Stochastic) с двойным сглаживанием для снижения шумов. Предпочтителен на средних и долгосрочных таймфреймах (H1 и выше), так как на младших периодах генерирует избыточное количество ложных сигналов.

## Особенности расчёта индикатора
В отличие от классического «быстрого» стохастика (Fast Stochastic), данный метод реализует **медленную версию** с двойным сглаживанием: сначала Fast %K сглаживается в линию Slow %K, затем полученная линия дополнительно сглаживается для формирования сигнальной линии %D. Это снижает чувствительность к краткосрочным колебаниям и уменьшает количество ложных пересечений.

## Автор — разработчик индикатора
Джордж Лейн ([George Lane](lane-george.md)), американский аналитик, впервые описал индикатор в 1954 году. Публично представлен в журнале «Технический анализ акций и товаров» (Technical Analysis of Stocks & Commodities) в 1980-х годах как инструмент для выявления импульса и разворотов рынка.

## Формула расчёта
```math
Fast %K = 100 × (Close - LowestLow) / (HighestHigh - LowestLow)
Slow %K = MA(Fast %K, optInSlowKPeriod)
Slow %D = MA(Slow %K, optInSlowDPeriod)
```
**Пояснение переменных:**
- `Close` — цена закрытия текущего бара
- `LowestLow` — минимальная цена Low за `optInFastKPeriod` периодов
- `HighestHigh` — максимальная цена High за `optInFastKPeriod` периодов
- `MA` — скользящая средняя (тип задаётся параметрами `optInSlowKMAType`/`optInSlowDMAType`)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимумов баров (цены High) |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимумов баров (цены Low) |
| `inClose` | `ReadOnlySpan<T>` | — | Массив цен закрытия (Close) |
| `optInFastKPeriod` | `int` | `5` | Период поиска экстремумов для расчёта исходного %K. Уменьшение повышает чувствительность, но усиливает шум. |
| `optInSlowKPeriod` | `int` | `3` | Период сглаживания Fast %K → Slow %K. Увеличение снижает запаздывание, но замедляет реакцию. |
| `optInSlowKMAType` | `MAType` | `Sma` | Тип скользящей средней для сглаживания %K (SMA, EMA, WMA и др.) |
| `optInSlowDPeriod` | `int` | `3` | Период сглаживания линии Slow %K для получения сигнальной линии %D |
| `optInSlowDMAType` | `MAType` | `Sma` | Тип скользящей средней для расчёта линии %D |

## Этапы расчёта
1. Для каждого бара определяется ценовой диапазон за `optInFastKPeriod`: находятся `HighestHigh` и `LowestLow`.
2. Рассчитывается сырое значение Fast %K по формуле выше.
3. Fast %K сглаживается скользящей средней за `optInSlowKPeriod` → получаем линию **Slow %K**.
4. Линия Slow %K дополнительно сглаживается за `optInSlowDPeriod` → получаем сигнальную линию **Slow %D**.

## Результат расчёта
- **Возвращает:** два массива — `outSlowK` (медленная линия %K) и `outSlowD` (сигнальная линия %D).
- **Lookback период:** `(optInFastKPeriod - 1) + MaLookback(optInSlowKPeriod) + MaLookback(optInSlowDPeriod)`. Например, при стандартных настройках (5,3,3) = 4 + 2 + 2 = **8 баров** — первые 8 значений будут недоступны.
- **Интерпретация:** значения колеблются от 0 до 100. Линия %K (быстрая) пересекает %D (медленную) — формируются торговые сигналы.

## Интерпретация значений
- **> 80** — зона перекупленности (потенциальный разворот вниз)
- **< 20** — зона перепроданности (потенциальный рост)
- **Пересечение %K и %D:** 
  - %K пересекает %D снизу вверх — бычий сигнал
  - %K пересекает %D сверху вниз — медвежий сигнал
- **Дивергенция:** расхождение между ценой и осциллятором сигнализирует об ослаблении тренда

## Практическое применение
✅ **Для чего использовать**
- Фильтрация сигналов трендовых индикаторов в боковике
- Подтверждение разворотов при достижении экстремальных зон (20/80)
- Выявление дивергенций на старших таймфреймах
- Определение силы импульса при пробое уровней поддержки/сопротивления

💡 **Идеи для стратегий**
1. **Классический разворот:** покупка при выходе из зоны <20 с пересечением %K выше %D.
2. **Подтверждение тренда:** в восходящем тренде игнорировать сигналы перекупленности (>80), искать только покупки при откатах к 50.
3. **Дивергенция + пробой:** медвежья дивергенция + пробой локального минимума цены → сигнал на продажу.
4. **Фильтрация по волатильности:** использовать только сигналы, когда размах (%K – %D) превышает 15 пунктов (сильный импульс).

⚠️ **Ограничения**
- Генерирует ложные сигналы в устойчивом тренде («застревание» в зоне перекупленности/перепроданности)
- Малоэффективен на таймфреймах ниже M15 из-за высокого уровня шума
- Запаздывает при резких разрывах цены (гэпах)

## Сравнение с аналогами
| Индикатор | Скорость реакции | Запаздывание | Шумоустойчивость | Особенность |
|-----------|------------------|--------------|------------------|-------------|
| **Stoch (медленный)** | Средняя | Среднее | Высокая | Двойное сглаживание, меньше ложных сигналов |
| **Stoch (быстрый)** | Высокая | Низкое | Низкая | Чувствителен к шуму, много ложных пересечений |
| **RSI** | Средняя | Среднее | Средняя | Одна линия, акцент на скорости изменения цены |
| **Williams %R** | Высокая | Низкое | Низкая | Инвертированная шкала (-100…0), более резкие сигналы |

# StochRsi (FaskK, FastD) — Стохастический индекс относительной силы (Stochastic RSI)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса на основе RSI

---

## Краткое описание
💡 **StochRSI** (Stochastic Relative Strength Index) — гибридный осциллятор, применяющий формулу стохастического осциллятора к значениям индекса относительной силы (RSI), а не к исходным ценам. Это делает его значительно чувствительнее классического RSI и позволяет выявлять экстремальные уровни перекупленности/перепроданности внутри диапазона изменений RSI. Индикатор колеблется в диапазоне 0–100 и генерирует сигналы по пересечению двух линий: быстрой %K и сглаженной %D.

## Формула расчёта
Расчёт выполняется в три этапа:

```math
1. RSI = 100 - (100 / (1 + RS)), где RS = Средний_прирост / Средний_убыток за optInTimePeriod

2. %K = 100 × (RSI_t - min(RSI, optInFastKPeriod)) / (max(RSI, optInFastKPeriod) - min(RSI, optInFastKPeriod))

3. %D = MA(%K, optInFastDPeriod, optInFastDMAType)
```

**Пояснение переменных:**
- `RSI_t` — текущее значение RSI
- `min(RSI, N)` / `max(RSI, N)` — минимальное/максимальное значение RSI за N периодов
- `MA` — скользящая средняя (по умолчанию SMA)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inRange` | `Range` | весь массив | Диапазон индексов для обработки (опционально) |
| `optInTimePeriod` | `int` | `14` | Период расчёта базового RSI. Уменьшение повышает чувствительность, но усиливает шум |
| `optInFastKPeriod` | `int` | `5` | Период поиска экстремумов RSI для линии %K. Чем меньше — тем резче реакция |
| `optInFastDPeriod` | `int` | `3` | Период сглаживания %K для получения линии %D |
| `optInFastDMAType` | `MAType` | `Sma` | Тип скользящей средней для сглаживания %D (SMA, EMA, WMA и др.) |
| `outFastK` | `Span<T>` | — | Выходной массив: несглаженная линия %K (основной сигнал) |
| `outFastD` | `Span<T>` | — | Выходной массив: сглаженная линия %D (сигнальная линия) |

## Результат расчёта
- **Выходные данные:** Два массива — `outFastK` (быстрая линия) и `outFastD` (сигнальная линия), значения в диапазоне 0–100.
- **Lookback период:** `RsiLookback(optInTimePeriod) + StochFLookback(optInFastKPeriod, optInFastDPeriod, optInFastDMAType)`. Первое валидное значение появляется после суммарной задержки обоих этапов расчёта.
- **Интерпретация:** Значения близкие к 0 — перепроданность, к 100 — перекупленность. Сигналы генерируются при пересечении линий %K и %D.

## Практическое применение
✅ **Для чего использовать**
- Выявление экстремальных условий внутри диапазона движения RSI
- Поиск скрытых дивергенций при боковом движении цены
- Фильтрация ложных сигналов обычного RSI за счёт двойного преобразования
- Торговля в условиях высокой волатильности на коротких таймфреймах

💡 **Идеи для стратегий**
1. **Пересечение линий:** Покупка при пересечении %K снизу вверх через %D в зоне <20; продажа при пересечении сверху вниз в зоне >80.
2. **Дивергенция:** Расхождение между ценой (новый максимум) и StochRSI (не подтверждает максимум) — сигнал разворота.
3. **Консолидация в экстремуме:** Удержание %K выше 80 (перекупленность) или ниже 20 (перепроданность) более 5 баров — сигнал продолжения тренда.
4. **Фильтр по тренду:** Использовать только сигналы покупки при восходящем тренде (цена выше 200-периодной SMA) и наоборот.

⚠️ **Ограничения**
- Высокая чувствительность приводит к множеству ложных сигналов во флэте
- Требует комбинации с трендовыми фильтрами на волатильных рынках
- Менее эффективен на очень длинных периодах (оптимален для таймфреймов до H4)

## Сравнение с аналогами
| Критерий | StochRSI | RSI | Stochastic |
|----------|----------|-----|------------|
| **Чувствительность** | ⚡⚡⚡ Очень высокая | ⚡⚡ Средняя | ⚡⚡ Средняя |
| **Запаздывание** | Низкое | Среднее | Среднее |
| **Шум** | Высокий | Умеренный | Умеренный |
| **Зона применения** | Короткие таймфреймы, волатильность | Универсальный | Универсальный |

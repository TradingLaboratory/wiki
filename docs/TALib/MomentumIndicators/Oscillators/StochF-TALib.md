# StochF (FastK, FastD) - Стохастический осциллятор, быстрая версия (Stochastic Fast)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса с диапазоном 0–100

---

## Краткое описание
💡 Быстрый стохастик измеряет положение цены закрытия относительно ценового диапазона (High-Low) за заданный период. В отличие от медленной версии, использует минимальное сглаживание, что повышает чувствительность к краткосрочным движениям, но увеличивает количество ложных сигналов. Возвращает две линии: **%K** (сырое значение) и **%D** (сглаженная версия %K). Диапазон строго ограничен 0–100, что позволяет однозначно определять зоны перекупленности (>80) и перепроданности (<20). Предпочтителен для анализа внутридневных таймфреймов (M5–H1) при работе с импульсными движениями.

## Особенности расчёта индикатора
Быстрая версия рассчитывает %K напрямую без предварительного сглаживания цены закрытия (в отличие от медленной версии, где цена сглаживается перед расчётом %K). Это делает индикатор более реактивным, но менее устойчивым к рыночному шуму.

## Автор — разработчик индикатора
Джордж Лейн (George Lane), американский аналитик, впервые описал стохастический осциллятор в 1954 году. Методология была популяризирована в 1970-х годах как инструмент анализа цикличности рынка.

## Формула расчёта
```
%K = 100 * (Close - LowestLow) / (HighestHigh - LowestLow)
%D = MA(%K, optInFastDPeriod)
```
Где:
- **Close** — цена закрытия текущего бара
- **LowestLow** — минимальное значение Low за `optInFastKPeriod` периодов
- **HighestHigh** — максимальное значение High за `optInFastKPeriod` периодов
- **MA** — скользящая средняя типа `optInFastDMAType` с периодом `optInFastDPeriod`

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимальных цен баров (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимальных цен баров (Low) |
| `inClose` | `ReadOnlySpan<T>` | — | Массив цен закрытия (Close) |
| `optInFastKPeriod` | `int` | `5` | Период поиска экстремумов для расчёта %K. Уменьшение повышает чувствительность, но усиливает шум |
| `optInFastDPeriod` | `int` | `3` | Период сглаживания %K для получения линии %D. Увеличение снижает количество ложных сигналов |
| `optInFastDMAType` | `MAType` | `Sma` | Тип скользящей средней для сглаживания (%D): SMA, EMA, WMA и др. |

## Этапы расчёта
1. Для каждого бара определяется окно длиной `optInFastKPeriod` для поиска минимального Low и максимального High
2. Рассчитывается сырое значение %K по формуле с нормализацией в диапазон 0–100
3. Линия %D получается путём применения скользящей средней к последовательности значений %K

## Результат расчёта
Метод возвращает два массива:
- **`outFastK`** — значения быстрой линии %K (сырой осциллятор)
- **`outFastD`** — значения сглаженной линии %D (сигнальная линия)

Период запаздывания (lookback):
```
lookback = (optInFastKPeriod - 1) + MaLookback(optInFastDPeriod, optInFastDMAType)
```
Например, при параметрах по умолчанию (5, 3, SMA): lookback = 4 + 2 = 6 баров.

## Интерпретация значений
- **0–20**: зона перепроданности (потенциал роста)
- **80–100**: зона перекупленности (потенциал падения)
- **Пересечение %K и %D**: быстрая линия пересекает сигнальную снизу вверх — сигнал к покупке; сверху вниз — к продаже
- **Дивергенция**: расхождение между экстремумами цены и осциллятора указывает на ослабление тренда

## Практическое применение
✅ **Для чего использовать**
• Выявление краткосрочных точек разворота в диапазонных рынках
• Подтверждение силы импульса при пробое уровней
• Фильтрация ложных пробоев (цена вышла за уровень, но осциллятор не подтвердил движение)
• Торговля на отскоках от границ диапазона 20/80

💡 **Идеи для стратегий**
1. **Классический вход по пересечению**: Покупка при пересечении %K линии %D снизу вверх в зоне <20; продажа — при пересечении сверху вниз в зоне >80
2. **Дивергенция + уровень**: Вход при бычьей дивергенции (цена ниже минимума, осциллятор выше) + выход из зоны перепроданности
3. **Фильтр тренда**: Использовать только сигналы в направлении старшего тренда (например, покупать только при %K > %D на восходящем рынке)

⚠️ **Ограничения**
• Даёт много ложных сигналов во флэте с высокой волатильностью
• Менее эффективен в сильном тренде (долгое пребывание в зонах 20/80 без разворотов)
• Требует подтверждения другими инструментами при работе на старших таймфреймах

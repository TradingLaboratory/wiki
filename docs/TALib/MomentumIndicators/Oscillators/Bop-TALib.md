# Bop — Баланс Сил (BOP)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса без запаздывания

---

## Краткое описание
💡 **BOP** (Balance of Power) — осциллятор, измеряющий относительную силу покупателей против продавцов внутри одного бара через позицию цены закрытия в дневном диапазоне. Значения лежат в теоретическом диапазоне **[-1.0, +1.0]**, где положительные значения указывают на доминирование покупателей, отрицательные — на давление продавцов. Индикатор не имеет запаздывания (lookback = 0) и работает на любом таймфрейме, но наиболее информативен на внутридневных графиках (M5–H1), где чётко видна внутрибаровая динамика.

## Автор
Игорь Левшин ( [Igor Levshin](levshin-igor.md)) впервые описал индикатор в середине 1990-х годов в профессиональных торговых публикациях как инструмент оценки баланса сил на микроуровне. Точный год первого упоминания — 1995.

## Формула расчёта
```math
BOP = (Close - Open) / (High - Low)
```
**Пояснение:**
- `Close - Open` — направление движения цены внутри бара
- `High - Low` — полный торговый диапазон (нормализующий множитель)
- При `High == Low` (нулевой диапазон) значение принимается равным **0**

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inOpen` | `ReadOnlySpan<T>` | — | Цены открытия баров |
| `inHigh` | `ReadOnlySpan<T>` | — | Максимальные цены баров |
| `inLow` | `ReadOnlySpan<T>` | — | Минимальные цены баров |
| `inClose` | `ReadOnlySpan<T>` | — | Цены закрытия баров |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных (опционально) |
| `outReal` | `Span<T>` | — | Выходной массив значений BOP в диапазоне [-1.0, +1.0] |
| `outRange` | `out Range` | — | Диапазон индексов с валидными значениями (Start = первый обработанный бар) |

## Результат расчёта
Метод возвращает массив `outReal` с нормализованными значениями силы движения для каждого бара. Период запаздывания **равен 0** — первое значение рассчитывается для самого первого бара входных данных. Выходной диапазон `outRange` всегда начинается с индекса `inRange.Start`, так как для расчёта не требуются исторические данные.

## Практическое применение
✅ **Для чего использовать**
• Оценка внутрибарового контроля цены (покупатели vs продавцы)
• Фильтрация ложных пробоев: слабый BOP при пробое = низкая вероятность продолжения
• Подтверждение разворотов: рост/падение BOP опережает ценовые экстремумы
• Анализ силы тренда на коротких таймфреймах без запаздывания

💡 **Идеи для стратегий**
1. **Дивергенция на коротком ТФ:** цена обновляет минимум, но BOP формирует более высокий минимум → сигнал на покупку.
2. **Фильтр пробоя:** пробой сопротивления + BOP > 0.5 → подтверждённый пробой; пробой + BOP < 0 → ложный сигнал.
3. **Пересечение нуля:** вход в лонг при переходе BOP из отрицательной зоны в положительную на фоне растущего объёма.

⚠️ **Ограничения**
• На барах с очень узким диапазоном («доджи») значения становятся шумными
• Не учитывает объёмы — слабый сигнал при высоком объёме может быть значимее сильного при низком
• На старших ТФ (D1+) менее информативен из-за усреднения внутрибаровой динамики

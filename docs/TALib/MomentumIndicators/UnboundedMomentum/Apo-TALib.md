# Apo — Абсолютный ценовой осциллятор (APO)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса на основе разницы скользящих средних

---
## Краткое описание
💡 **APO** (Absolute Price Oscillator) измеряет разницу между двумя скользящими средними в абсолютных единицах цены. В отличие от процентного осциллятора PPO, значения APO выражены в тех же единицах, что и исходная цена (пункты, доллары), что упрощает интерпретацию силы импульса. Индикатор колеблется вокруг нулевой линии без фиксированных границ — диапазон зависит от волатильности актива. Стандартные периоды 12/26 заимствованы из MACD.

## Автор-разработчик
Конкретный автор APO не выделен отдельно в литературе — индикатор является логическим развитием концепции двойных скользящих средних. Тесно связан с индикатором MACD, разработанным **Джеральдом Аппелем** ([Gerald Appel](appel-gerald)) в конце 1970-х годов. Популяризирован в рамках анализа расхождений (divergence) и пересечений скользящих средних.

## Формула расчёта
```math
APO = FastMA(price, fastPeriod) - SlowMA(price, slowPeriod)
```
- `FastMA` — быстрая скользящая средняя (период `optInFastPeriod`)
- `SlowMA` — медленная скользящая средняя (период `optInSlowPeriod`)
- `price` — обычно цены закрытия (Close)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной ряд цен (обычно Close) |
| `optInFastPeriod` | `int` | `12` | Период быстрой MA: уменьшение повышает чувствительность, но добавляет шум |
| `optInSlowPeriod` | `int` | `26` | Период медленной MA: увеличение снижает запаздывание, но сглаживает сигналы |
| `optInMAType` | `MAType` | `Sma` | Тип скользящей средней (SMA, EMA, WMA и др.) |

## Результат расчёта
Метод возвращает массив `outReal` с разницей между скользящими средними для каждого бара. Первое валидное значение появляется после периода **lookback = max(fastPeriod, slowPeriod) - 1** (для стандартных 12/26 — с 25-го бара). Значения выше нуля указывают на доминирование восходящего импульса, ниже нуля — на нисходящий.

## Практическое применение
✅ **Для чего использовать**
- Выявление смены импульса при пересечении нулевой линии
- Оценка силы тренда по амплитуде отклонения от нуля
- Поиск дивергенций между ценой и осциллятором
- Фильтрация ложных пробоев уровней поддержки/сопротивления

💡 **Идеи для стратегий**
1. Сигнал покупки при пересечении нулевой линии снизу вверх + подтверждение ростом объёма
2. Продажа при формировании медвежьей дивергенции на максимумах цены
3. Выход из позиции при сближении APO к нулю (ослабление импульса)
4. Комбинация с полосами Боллинджера: вход при пересечении нуля + пробой внешней полосы

⚠️ **Ограничения**
- Генерирует ложные сигналы во флэте из-за «пилообразных» колебаний около нуля
- Абсолютные значения сложнее сравнивать между разными активами (в отличие от PPO)
- Запаздывает на резких разворотах из-за инерции скользящих средних

## Сравнение с аналогами
| Индикатор | Единицы измерения | Границы | Чувствительность | Лучшее применение |
|-----------|-------------------|---------|------------------|-------------------|
| **APO** | Абсолютные (пункты) | Нет | Средняя | Оценка силы импульса в пунктах |
| **PPO** | Процентные (%) | Нет | Средняя | Сравнение активов разной цены |
| **MACD** | Абсолютные + сигнальная линия | Нет | Низкая | Торговля по пересечениям линий |
| **ROC** | Процентные (%) | Нет | Высокая | Краткосрочные импульсные движения |

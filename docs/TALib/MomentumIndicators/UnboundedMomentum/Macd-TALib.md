# Macd (Macd, MacdSignal, MacdHist) - Сходимость/расходимость скользящих средних (MACD)

**Категория:** `MomentumIndicators` • **Тип:** Трендовый осциллятор импульса

---

## Краткое описание

MACD (Moving Average Convergence/Divergence) — трендовый импульсный индикатор, анализирующий взаимоотношение двух экспоненциальных скользящих средних (быстрой и медленной). Индикатор не имеет фиксированных границ — значения колеблются вокруг нулевой линии, где положительные значения указывают на восходящий импульс, отрицательные — на нисходящий. Предпочтителен на таймфреймах от 1 часа и выше, особенно эффективен на дневных графиках. Измеряет силу и направление тренда через анализ расхождений между EMA, выявляя изменения импульса раньше ценовых разворотов. 📈

## Автор

Джеральд Аппель ([Gerald Appel](appel-gerald)), разработан в конце 1970-х годов. Впервые описан в его работах по техническому анализу, став одним из самых популярных индикаторов в трейдинге.

## Формула расчёта
```math
MACD = EMA(fastPeriod) - EMA(slowPeriod)
Signal = EMA(MACD, signalPeriod)
Histogram = MACD - Signal
```

**Пояснение переменных:**
- `EMA(fastPeriod)` — экспоненциальная скользящая средняя за короткий период (стандартно 12)
- `EMA(slowPeriod)` — экспоненциальная скользящая средняя за длинный период (стандартно 26)
- `Signal` — сигнальная линия (сглаженная линия MACD, стандартно период 9)
- `Histogram` — гистограмма, отражающая расстояние между линией MACD и сигнальной линией

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Цены закрытия (Close) или другой временной ряд |
| `optInFastPeriod` | `int` | `12` | Период быстрой EMA: уменьшение повышает чувствительность, но увеличивает шум |
| `optInSlowPeriod` | `int` | `26` | Период медленной EMA: увеличение снижает запаздывание, но замедляет реакцию на развороты |
| `optInSignalPeriod` | `int` | `9` | Период сигнальной линии: чем меньше — быстрее пересечения, но больше ложных сигналов |
| `inRange` | `Range` | весь массив | Диапазон обрабатываемых данных (опционально) |

## Этапы расчёта

1. Расчёт быстрой EMA входных цен за период `optInFastPeriod`
2. Расчёт медленной EMA входных цен за период `optInSlowPeriod`
3. Вычисление линии MACD как разности быстрой и медленной EMA
4. Сглаживание линии MACD через EMA с периодом `optInSignalPeriod` → сигнальная линия
5. Расчёт гистограммы как разности линии MACD и сигнальной линии

## Результат расчёта

Метод возвращает три выходных массива:
- `outMACD` — значения линии индикатора (разность двух EMA)
- `outMACDSignal` — значения сигнальной линии (сглаженная линия MACD)
- `outMACDHist` — значения гистограммы (расстояние между линиями)

**Период запаздывания:**  
`Lookback = EmaLookback(optInSlowPeriod) + EmaLookback(optInSignalPeriod)`  
Минимальное количество баров для первого валидного значения. При стандартных параметрах (26, 9) требуется ~34 бара.

## Интерпретация значений

- **Нулевая линия:** пересечение снизу вверх — подтверждение восходящего тренда; сверху вниз — нисходящего
- **Гистограмма:** расширение столбцов = усиление импульса; сужение = ослабление и возможный разворот
- **Положительные значения:** быстрая EMA выше медленной → восходящий импульс
- **Отрицательные значения:** быстрая EMA ниже медленной → нисходящий импульс

## Практическое применение

✅ **Для чего использовать**
• Выявление смены импульса до формирования ценовых разворотов
• Подтверждение силы текущего тренда через положение относительно нулевой линии
• Фильтрация ложных пробоев при совместном использовании с ценовыми уровнями
• Анализ дивергенций для прогнозирования разворотов

💡 **Идеи для стратегий**
1. **Пересечение линий:** покупка при пересечении MACD сигнальной линии снизу вверх + подтверждение выше нулевой линии
2. **Дивергенция + гистограмма:** бычья дивергенция + сужение гистограммы → подготовка к лонгу
3. **Нулевая линия как фильтр:** только сигналы пересечения линий в направлении основного тренда (выше/ниже нуля)
4. **Сжатие гистограммы:** вход при расширении гистограммы после периода сжатия (всплеск импульса)

⚠️ **Ограничения**
• Слабоэффективен во флэте — генерирует ложные пересечения линий
• Запаздывает на коротких таймфреймах (<15 минут) из-за двойного сглаживания
• Не подходит для определения перекупленности/перепроданности (нет фиксированных границ)

## Сравнение с аналогами
| Критерий | MACD | RSI | Stochastic |
|----------|------|-----|------------|
| **Тип** | Трендовый импульс | Осциллятор | Осциллятор |
| **Границы** | Нет (около нуля) | 0–100 | 0–100 |
| **Запаздывание** | Среднее (двойное сглаживание) | Низкое | Низкое |
| **Шум во флэте** | Высокий | Средний | Высокий |
| **Сильная сторона** | Выявление смены импульса | Перекупленность/перепроданность | Точные точки входа на разворотах |

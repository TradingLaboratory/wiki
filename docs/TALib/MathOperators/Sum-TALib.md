# Sum — Суммирование (SUM)

**Категория:** `MathOperators` • **Тип:** Математический оператор / Скользящая сумма

---

## Краткое описание

Индикатор **Sum** вычисляет скользящую сумму значений входного ряда за указанный период. 📊 Это не осциллятор: диапазон значений не ограничен и зависит от масштаба входных данных (цены, объёма). Предназначен для накопительных расчётов, оценки общего движения цены или объёма за окно времени. Часто используется как базовый строительный блок для создания пользовательских индикаторов (например, собственных скользящих средних). Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

В отличие от наивного суммирования каждого периода заново, реализация использует **оптимизированное скользящее окно**: к текущей сумме добавляется новое значение и вычитается самое старое. Это значительно снижает вычислительную нагрузку. Поддерживает любые числовые типы (`float`, `double`).

## Автор - разработчик индикатора

*   **Автор:** Стандартная математическая функция (авторство не принадлежит конкретному аналитику).
*   **Реализация:** Библиотека TA-Lib (Mario Fortuni и сообщество).
*   **Год:** Конец 1990-х (начало разработки TA-Lib).
*   **Источник:** Документация библиотеки TA-Lib.

## Формула расчёта
```math
Sum_t = \sum_{i=0}^{N-1} X_{t-i}
```
**Оптимизированная версия (скользящее окно):**
```math
Sum_t = Sum_{t-1} + X_t - X_{t-N}
```
*   $X_t$ — текущее значение входного ряда.
*   $N$ — период суммирования (`optInTimePeriod`).
*   $Sum_t$ — результат на текущем баре.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (Close, Volume и т.д.). |
| `inRange` | `Range` | — | Диапазон индексов в `inReal` для обработки. |
| `outReal` | `Span<T>` | — | Массив для записи результатов (валидные значения). |
| `outRange` | `out Range` | — | Диапазон индексов `inReal`, соответствующих валидным данным в `outReal`. |
| `optInTimePeriod` | `int` | `30` | Период суммирования. Минимум 2. Влияет на глубину окна. |

**Период запаздывания (Lookback):** `optInTimePeriod - 1`.  
Первые `N-1` баров не имеют валидного значения полной суммы.

## Этапы расчёта

1.  **Валидация:** Проверка входных диапазонов и периода (минимум 2).
2.  **Инициализация:** Расчет суммы первых `N` элементов для старта.
3.  **Скользящий цикл:** Для каждого нового бара: `ТекущаяСума += НовоеЗначение - СтароеЗначение`.
4.  **Запись:** Сохранение результата в `outReal` и обновление `outRange`.

## Интерпретация значений

*   **Абсолютная величина:** Значение само по себе не несет сигнала (в отличие от RSI). Важно изменение суммы во времени.
*   **Рост:** Указывает на преобладание положительных значений или рост объёма в окне.
*   **Индексы:** `outRange` показывает, каким барам входных данных соответствуют значения в выходе.

## Практическое применение

✅ **Для чего использовать**
• Расчет накопленного объёма за период (Volume Sum).  
• Суммирование ценовых изменений (Price Change Sum) для оценки импульса.  
• Создание кастомных скользящих средних (Sum / Period).  

💡 **Идеи для стратегий**
1.  **Объёмный прорыв:** Вход в сделку, если `Sum(Volume, 20)` превышает среднее значение за 50 периодов.  
2.  **Накопление цены:** Если сумма изменений цены за 10 баров > 0, тренд восходящий.  
3.  **Фильтр волатильности:** Использовать сумму диапазонов (High-Low) для оценки активности рынка.  

⚠️ **Ограничения**
• Чувствителен к масштабу цены (не подходит для сравнения разных активов без нормализации).  
• Не имеет границ перекупленности/перепроданности.  

## Сравнение с аналогами

| Критерий | **Sum** | **Add** | **SMA** | **Cumulative Sum** |
|----------|---------|---------|---------|-------------------|
| **Входные данные** | 1 массив | 2 массива | 1 массив | 1 массив |
| **Операция** | Сумма за окно N | Попарное сложение | Среднее за окно | Сумма с начала |
| **Формула** | `Σ(X[t-N+1...t])` | `A[t] + B[t]` | `Σ/N` | `Σ(X[0...t])` |
| **Период** | Требуется (`optInTimePeriod`) | Не требуется | Требуется | Не требуется |
| **Lookback** | `N - 1` | `0` | `N - 1` | `0` |
| **Границы** | Нет | Нет | Нет | Нет |
| **Применение** | Окно накопления | Векторная операция | Сглаживание тренда | Долгосрочный поток |

### 🔑 Ключевые отличия Sum от Add

| Аспект | **Sum** | **Add** |
|--------|---------|---------|
| **Количество входов** | Один временной ряд (`inReal`) | Два временных ряда (`inReal0`, `inReal1`) |
| **Тип операции** | **Временное суммирование** — складывает значения одного ряда за N периодов | **Векторное сложение** — складывает два разных ряда поэлементно |
| **Период** | Требует указания периода (`optInTimePeriod`) | Не имеет периода — работает по всей длине массива |
| **Запаздывание** | Есть (`N-1` баров) | Отсутствует (результат с первого бара) |
| **Пример** | `Sum(Close, 20)` = сумма закрытий за 20 баров | `Add(High, Low)` = `(High[t] + Low[t])` для каждого бара |
| **Use Case** | Накопление за окно времени | Комбинирование двух индикаторов или ценовых рядов |

**Практический пример различия:**
```csharp
// Sum — скользящая сумма Close за 10 периодов
Sum(Close, optInTimePeriod: 10)  // Результат: [10-й бар, 11-й бар, ...]

// Add — поэлементное сложение High + Low
Add(High, Low)  // Результат: [0-й бар, 1-й бар, 2-й бар, ...]
```

> 💡 **Запомните:** `Sum` = **когда** суммировать (временное окно), `Add` = **что** суммировать (два ряда данных).

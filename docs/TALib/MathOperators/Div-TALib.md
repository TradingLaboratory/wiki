# Div — Векторное арифметическое деление (DIV)

**Категория:** `MathOperators` • **Тип:** Математический оператор / Утилита

---

## Краткое описание
💡 **Div** выполняет поэлементное деление одного временного ряда на другой. Это не готовый торговый индикатор, а строительный блок для создания пользовательских метрик. Диапазон значений не ограничен (зависит от входных данных). **Важно:** при делении на ноль метод не выбрасывает исключение — возвращается `Infinity` или `NaN` (стандарт IEEE 754). Предпочтительный таймфрейм зависит от задачи (обычно тот же, что у входных рядов). Измеряет **отношение** между двумя величинами (например, Цена/Объем или Индикатор A/Индикатор B). Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора
Отличается от классических индикаторов отсутствием накопления истории. Расчёт происходит «здесь и сейчас» для каждого бара независимо от предыдущих. Нет сглаживания или запаздывания.

⚠️ **Поведение при делении на ноль:**
| Ситуация | Результат |
|----------|-----------|
| `Positive / 0` | `PositiveInfinity` (+∞) |
| `Negative / 0` | `NegativeInfinity` (-∞) |
| `0 / 0` | `NaN` (Not a Number) |

Метод **не проверяет** знаменатель на ноль — ответственность на разработчике.

## Формула расчёта
```math
Result[i] = Input0[i] / Input1[i]
```
- `Result[i]` — значение результата на текущем баре.
- `Input0[i]` — значение числителя (первый ряд данных).
- `Input1[i]` — значение знаменателя (второй ряд данных).

**Пример:** Если `Input0` (Close) = 100, а `Input1` (MA20) = 50, то результат = 2.0.  
**Пример с нулём:** Если `Input0` = 100, а `Input1` = 0, то результат = `+Infinity`.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal0` | `ReadOnlySpan<T>` | — | **Числитель.** Цены (Close), объемы или значения другого индикатора |
| `inReal1` | `ReadOnlySpan<T>` | — | **Знаменатель.** Цены, объемы или значения другого индикатора |
| `inRange` | `Range` | Весь массив | Диапазон индексов входных данных для обработки |
| `outReal` | `Span<T>` | — | **Результат.** Массив отношений (числитель / знаменатель), может содержать `Infinity`/`NaN` |
| `outRange` | `out Range` | — | Диапазон валидных индексов в выходном массиве |
| `RetCode` | `Enum` | — | Код возврата: `Success` или ошибка (например, `OutOfRangeParam`) |

## Результат расчёта
- **Период запаздывания (Lookback):** `0`. Первое значение доступно сразу для первого бара входных данных.
- **Вывод:** Массив `outReal` содержит коэффициенты отношения. Если `outRange` корректен, длина результата равна количеству обработанных элементов.
- **Специальные значения:** Проверяйте результат на `IsInfinity()` и `IsNaN()` перед использованием в стратегиях.

## Этапы расчёта
1. Валидация входных диапазонов и длин массивов.
2. Проверка на выход за границы (`OutOfRangeParam`).
3. Цикл по индексам от `startIdx` до `endIdx`.
4. Выполнение операции деления `inReal0[i] / inReal1[i]`.
5. Запись результата в `outReal` и установка `outRange`.

## Интерпретация значений
- **Значение > 1:** Числитель больше знаменателя (например, Цена выше Скользящей Средней).
- **Значение < 1:** Числитель меньше знаменателя.
- **Значение = 1:** Величины равны (пересечение).
- **`PositiveInfinity`:** Знаменатель = 0, числитель > 0 (критическая ситуация).
- **`NegativeInfinity`:** Знаменатель = 0, числитель < 0.
- **`NaN`:** Неопределённость (0/0 или операция с `NaN`).
- **Индексы:** Соответствуют индексам входных массивов (синхронизированы).

## Практическое применение
✅ **Для чего использовать**
• Нормализация данных (например, деление цены на индекс рынка).
• Создание относительных индикаторов (Price/MA, Volume/Price).
• Парный трейдинг (расчет коэффициента соотношения двух активов).

💡 **Идеи для стратегий**
1. **Отклонение от средней:** `Close / SMA(Close, 20)`. Значения > 1.05 — перекупленность.
2. **Сила объема:** `Volume / SMA(Volume, 20)`. Всплески > 2.0 — аномальный интерес.
3. **Межрыночный анализ:** `AssetA_Price / AssetB_Price`. Торговля на схождение/расхождение коэффициента.

⚠️ **Ограничения**
• **Деление на ноль:** Требуйте предварительной проверки знаменателя или фильтрации `Infinity`/`NaN` в результатах.
• Не является самостоятельным сигналом — требует пороговых значений.
• Чувствителен к шуму в знаменателе (малые значения усиливают волатильность результата).

**Рекомендация по защите:**
```csharp
// Перед использованием результата
if (float.IsInfinity(value) || float.IsNaN(value))
{
    // Пропустить бар или заменить на нейтральное значение
}
```

# Obv — Балансовый объём (OBV)

**Категория:** `VolumeIndicators` • **Тип:** Кумулятивный индикатор потока объёма

---

## Краткое описание
💡 **OBV** (On Balance Volume) измеряет кумулятивный поток объёма, добавляя объём при росте цены закрытия и вычитая при её падении относительно предыдущего периода. Индикатор не ограничен диапазоном значений — представляет собой непрерывно накапливающуюся сумму, где направление тренда важнее абсолютных величин. Разработан для выявления скрытого накопления (accumulation) или распределения (distribution) через анализ соотношения объёма и цены. Эффективен на любых таймфреймах, но особенно полезен на дневных и выше для фильтрации рыночного шума.

## Особенности расчёта индикатора
В отличие от многих объёмных индикаторов, OBV не использует сглаживание или взвешивание по цене — расчёт строго бинарный: объём полностью добавляется или вычитается в зависимости от направления движения цены закрытия. Отсутствие lookback-периода (0) позволяет получать первое валидное значение сразу на первом баре диапазона.

## Автор — разработчик индикатора
Джозеф Гранвилл ([Joseph Granville](granville-joseph.md)) впервые описал индикатор в 1963 году в книге «Granville's New Key to Stock Market Profits». Гранвилл утверждал, что «движение объёма предшествует движению цены», что легло в основу концепции OBV.

## Формула расчёта
```
OBV[0] = Volume[0]
OBV[i] = OBV[i-1] + Volume[i]   если Close[i] > Close[i-1]
OBV[i] = OBV[i-1] - Volume[i]   если Close[i] < Close[i-1]
OBV[i] = OBV[i-1]               если Close[i] == Close[i-1]
```
**Пояснение переменных:**
- `Close[i]` — цена закрытия текущего периода
- `Volume[i]` — объём торгов текущего периода
- `OBV[i]` — кумулятивное значение балансового объёма на периоде *i*

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Цены закрытия (Close) для определения направления движения |
| `inVolume` | `ReadOnlySpan<T>` | — | Объёмы торгов (Volume) за соответствующие периоды |
| `inRange` | `Range` | — | Диапазон обработки данных (начальный/конечный индексы) |
| `outReal` | `Span<T>` | — | Выходной массив кумулятивных значений OBV |
| `outRange` | `out Range` | — | Диапазон индексов входных данных с валидными значениями OBV |

**Lookback период:** `0` — первое значение рассчитывается на первом баре входного диапазона без пропусков.

## Этапы расчёта
1. Инициализация OBV объёмом первого периода в диапазоне
2. Для каждого последующего периода сравнение `Close[i]` с `Close[i-1]`:
   - При росте цены — добавление `Volume[i]` к накопленному значению
   - При падении цены — вычитание `Volume[i]`
   - При неизменной цене — сохранение предыдущего значения OBV
3. Сохранение кумулятивного результата в выходной массив

## Интерпретация значений
- **Восходящий тренд OBV** — доминирование покупателей, накопление актива
- **Нисходящий тренд OBV** — доминирование продавцов, распределение актива
- **Боковое движение** — отсутствие значимого потока объёма
- **Расхождение (divergence)** — несоответствие направления OBV и цены (бычье/медвежье предупреждение)

## Практическое применение
✅ **Для чего использовать**
• Подтверждение силы тренда: совпадающие направления цены и OBV усиливают сигнал
• Выявление расхождений перед разворотом тренда
• Фильтрация ложных пробоев уровней (низкий объём = слабый пробой)
• Определение зон накопления на боковиках

💡 **Идеи для стратегий**
1. **Подтверждение пробоя:** цена пробивает сопротивление + резкий рост OBV → сигнал на покупку
2. **Бычье расхождение:** цена формирует новые минимумы, OBV — более высокие минимумы → подготовка к росту
3. **Трендовый фильтр:** вход в лонг только при восходящем тренде OBV (сглаженном через SMA)
4. **Объёмный спред:** сравнение скорости роста OBV и цены для оценки качества движения

⚠️ **Ограничения**
• Чувствителен к единичным всплескам объёма (например, новостные события)
• Не даёт самостоятельных торговых сигналов — требует подтверждения ценой или другими индикаторами
• На младших таймфреймах подвержен рыночному шуму из-за спорадических объёмов

## Сравнение с аналогами
| Индикатор              | Тип данных                      | Сглаживание   | Чувствительность   | Основное применение                   |
| ---------------------- | ------------------------------- | ------------- | ------------------ | ------------------------------------- |
| **OBV**                | Только направление цены         | Нет           | Высокая            | Выявление скрытого потока             |
| **Chaikin Money Flow** | High/Low/Close + Volume         | SMA(21)       | Средняя            | Оценка давления покупателей/продавцов |
| **Volume Profile**     | Распределение объёма по уровням | Нет           | Зависит от периода | Поиск ключевых ценовых зон            |
| **VWAP**               | Цена + объём                    | Накопительное | Низкая             | Определение справедливой цены дня     |

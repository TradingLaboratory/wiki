# SarExt — Параболический SAR расширенный (Parabolic SAR Extended)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор с динамическим стоп-лоссом

---

## Краткое описание
💡 Параболический индикатор «Стоп и разворот» (Stop and Reverse), улучшенная версия классического SAR Уэллса Уайлдера. Точки индикатора следуют за ценой, ускоряясь по мере развития тренда, и меняют позицию при его развороте. Возвращает положительные значения для длинных позиций (точки ниже цены) и отрицательные для коротких (точки выше цены). Не имеет фиксированных границ — значения лежат в диапазоне ценовых баров. Эффективен на трендовых таймфреймах (от часового и выше), слабо работает во флэте. Измеряет направление и силу тренда, одновременно выступая уровнем динамического стоп-лосса.

## Особенности расчёта
Расширенная версия отличается от классического SAR возможностью независимой настройки факторов ускорения для длинных и коротких позиций, а также применением смещения (`offset`) при развороте тренда. Это позволяет точно адаптировать чувствительность индикатора к особенностям рынка.

## Автор
Welles Wilder (Уэллс Уайлдер) — оригинальная версия описана в 1978 году в книге *«Новые концепции технической торговли» (New Concepts in Technical Trading Systems)*. Расширенная реализация (`SarExt`) разработана сообществом TALib для гибкой параметризации.

## Формула расчёта
```math
SAR_t = SAR_{t-1} + AF × (EP - SAR_{t-1})
```
**Пояснение переменных:**
- `SAR_t` — значение индикатора на текущем баре
- `AF` — фактор ускорения (начинается с `optInAccelerationInit`, растёт при новых экстремумах до `optInAccelerationMax`)
- `EP` — экстремальная точка: максимальная цена для позиции Long, минимальная для Short

**Пример:** При восходящем тренде с `SAR_{t-1} = 100`, `EP = 110`, `AF = 0.04` → `SAR_t = 100 + 0.04 × (110 - 100) = 100.4`

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимумов (High) ценовых баров |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимумов (Low) ценовых баров |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных (начальный/конечный индексы) |
| `outReal` | `Span<T>` | — | Выходной массив: **положительные** значения = позиция Long (SAR ниже цены), **отрицательные** = позиция Short (SAR выше цены) |
| `outRange` | `out Range` | — | Диапазон индексов с валидными значениями индикатора |
| `optInStartValue` | `double` | `0.0` | Начальное значение SAR: >0 — старт из Long, <0 — из Short, =0 — автоопределение по первым двум барам |
| `optInOffsetOnReverse` | `double` | `0.0` | Смещение при развороте: положительное увеличивает дистанцию между ценой и SAR после смены позиции |
| `optInAccelerationInitLong` | `double` | `0.02` | Начальный фактор ускорения для длинных позиций |
| `optInAccelerationLong` | `double` | `0.02` | Инкремент ускорения при новых максимумах (Long) |
| `optInAccelerationMaxLong` | `double` | `0.2` | Максимальный фактор ускорения для длинных позиций |
| `optInAccelerationInitShort` | `double` | `0.02` | Начальный фактор ускорения для коротких позиций |
| `optInAccelerationShort` | `double` | `0.02` | Инкремент ускорения при новых минимумах (Short) |
| `optInAccelerationMaxShort` | `double` | `0.2` | Максимальный фактор ускорения для коротких позиций |

**Lookback:** `SarExtLookback() = 1` — для первого расчёта требуется всего 1 предыдущий бар.

## Этапы расчёта
1. Определение начального направления тренда (по знаку `optInStartValue` или анализу направленного движения первых двух баров)
2. Инициализация: `SAR = Lowest Low` (для Long) или `Highest High` (для Short) предыдущего бара; `EP = Highest High`/`Lowest Low` текущего бара
3. Для каждого бара:
   - Расчёт нового SAR по формуле с текущим фактором ускорения
   - Проверка, чтобы SAR не проникал в ценовой диапазон предыдущих двух баров
   - При пересечении SAR цены — разворот позиции, сброс SAR к EP с применением смещения `optInOffsetOnReverse`
   - Обновление EP при достижении нового экстремума и увеличение AF (до максимума)

## Интерпретация значений
- **Положительное значение** → точка SAR расположена **ниже цены** → восходящий тренд, уровень стоп-лосса для длинной позиции
- **Отрицательное значение** → точка SAR расположена **выше цены** → нисходящий тренд, уровень стоп-лосса для короткой позиции
- **Смена знака** → пересечение SAR цены → сигнал потенциального разворота тренда

## Практическое применение
✅ **Для чего использовать**
• Динамический стоп-лосс, следующий за трендом
• Фильтрация бокового движения (точки «скачут» внутри диапазона)
• Подтверждение силы тренда (ускорение движения точек вдоль цены)
• Визуальное определение разворотов на графике

💡 **Идеи для стратегий**
1. **Трендовая система:** Открытие длинной позиции при первом положительном значении после серии отрицательных (и наоборот для шорта)
2. **Фильтр по ускорению:** Торговля только при `AF > 0.1` — подтверждение зрелого тренда
3. **Комбинация с волатильностью:** Использование `optInOffsetOnReverse > 0` для уменьшения ложных сигналов в условиях высокой волатильности
4. **Адаптивная настройка:** Разные параметры ускорения для Long/Short при асимметричных трендах (например, медвежьи тренды быстрее бычьих)

⚠️ **Ограничения**
• Генерирует ложные сигналы во флэте с частыми разворотами
• Запаздывает на начальной стадии тренда (точки формируются позади цены)
• Чувствителен к экстремальным ценовым всплескам («хвосты» баров)

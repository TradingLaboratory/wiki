# Max — Максимум в скользящем окне (Highest)

**Категория:** `MathOperators` • **Тип:** Оператор поиска экстремумов

---

## Краткое описание
⚡ Функция `Max` вычисляет максимальное значение (Highest) в скользящем окне заданной длины. В отличие от осцилляторов, возвращает абсолютные значения из входного ряда (цены, объёмы), а не нормализованный диапазон. Первое валидное значение появляется с задержкой `период - 1` баров. Широко применяется как базовый компонент для построения ценовых каналов (Дончиана), определения уровней сопротивления и выявления локальных максимумов.

## Особенности расчёта
Алгоритм использует оптимизированный подход: при сдвиге окна пересчитывает максимум только если предыдущий экстремум выходит за левую границу окна или новый бар превышает текущий максимум. Это снижает вычислительную сложность по сравнению с полным перебором окна на каждом шаге.

## Автор — разработчик индикатора
Базовая концепция скользящего максимума не имеет конкретного автора — это фундаментальная математическая операция. Широкое применение в техническом анализе получила в рамках системы Дончиана (Дж. Дончиан, 1960-е годы) для построения ценовых каналов.

## Формула расчёта
```
Maxₜ = max(inReal[t - period + 1], inReal[t - period + 2], ..., inReal[t])
```
**Пояснение:**
- `Maxₜ` — максимальное значение на баре `t`
- `inReal` — входной ценовой ряд (обычно High для поиска максимумов цены)
- `period` — длина скользящего окна

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные: цены (High для максимума), объёмы или значения других индикаторов |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для обработки (опционально) |
| `outReal` | `Span<T>` | — | Выходной массив с валидными значениями максимума (длина = `outRange.End - outRange.Start + 1`) |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых рассчитаны значения (`Start = lookback`, `End = последний бар`) |
| `optInTimePeriod` | `int` | `30` | Длина скользящего окна: чем больше период — сильнее сглаживание, но выше запаздывание |

## Результат расчёта
- **Выходные данные:** `outReal` содержит последовательность максимальных значений входного ряда в скользящем окне.
- **Lookback:** `optInTimePeriod - 1` — количество баров до появления первого валидного значения.
- **Код возврата:** `RetCode.Success` при успешном расчёте или код ошибки при некорректных входных данных.

## Этапы расчёта
1. Валидация входного диапазона и периода (минимум 2 бара)
2. Расчёт индекса первого валидного значения: `startIdx = max(исходный_start, period - 1)`
3. Инициализация: поиск максимума в первом окне длиной `period`
4. Итерация по барам: при сдвиге окна — обновление максимума без полного пересчёта
5. Запись текущего максимума в `outReal` для каждого бара начиная с `startIdx`

## Интерпретация значений
- Каждое значение `outReal[i]` соответствует максимальной цене (или другому параметру) за последние `period` баров до текущего момента.
- При использовании с ценами `High` — показывает динамический уровень сопротивления.
- Резкий скачок значения указывает на формирование нового локального максимума.

## Практическое применение
✅ **Для чего использовать**
• Построение верхней границы канала Дончиана (в паре с `Min` для нижней границы)
• Определение динамических уровней сопротивления
• Фильтрация шума: сравнение текущей цены с `Max(period)` для подтверждения пробоя
• Базовый компонент для расчёта истинного диапазона (в составе ATR)

💡 **Идеи для стратегий**
1. Пробой сопротивления: покупка при закрытии выше `Max(High, 20)` за последние 20 баров
2. Отскок от максимума: продажа при открытии ниже `Max(High, 10)` после достижения этого уровня
3. Канальная торговля: комбинация `Max(High, N)` и `Min(Low, N)` для диапазонной торговли

⚠️ **Ограничения**
• Сильное запаздывание при больших периодах (максимум «догоняет» цену)
• Частые ложные пробои при высокой волатильности на малых периодах
• Не подходит для определения силы тренда — только для уровней цен

## Сравнение с аналогами
| Критерий | `Max` | `SMA` | `EMA` |
|----------|-------|-------|-------|
| Тип выхода | Абсолютные значения | Среднее значение | Взвешенное среднее |
| Запаздывание | `period - 1` | `period / 2` | Меньше чем у SMA |
| Чувствительность к экстремумам | Максимальная | Низкая | Средняя |
| Применение | Уровни цен, каналы | Тренд, сглаживание | Тренд с акцентом на недавние данные |

# Min — Минимальное значение (Lowest)

**Категория:** `MathOperators` • **Тип:** Индикатор экстремума ценового диапазона

---

## Краткое описание
💡 Индикатор вычисляет минимальное значение (минимум) в скользящем окне за заданный период. В отличие от осцилляторов, возвращает абсолютные ценовые уровни в том же диапазоне, что и исходные данные. Чаще всего применяется к ценам Low для определения динамических уровней поддержки, построения ценовых каналов (в паре с MAX) или как компонент сложных индикаторов (Stochastic, Williams %R). Работает на любых таймфреймах, чувствительность регулируется параметром периода.

## Особенности расчёта
Реализация использует оптимизированный алгоритм поиска минимума: при сдвиге окна проверяется, вышло ли предыдущее минимальное значение за границу окна. Если нет — пересчёт не требуется, что снижает вычислительную сложность по сравнению с «грубым» перебором всего окна на каждой итерации.

## Автор
Базовая математическая операция без конкретного автора. Применяется в техническом анализе с момента его формирования как метод выделения экстремумов. В составе TA-Lib реализована как элементарный строительный блок для более сложных индикаторов.

## Формула расчёта
```math
MIN_t = \min(P_{t-n+1}, P_{t-n+2}, ..., P_t)
```
Где:
- `MIN_t` — минимальное значение на баре `t`
- `P` — входной ценовой ряд (обычно Low)
- `n` — период окна (`optInTimePeriod`)

Пример: при `optInTimePeriod = 14` значение на текущем баре — минимум из цен последних 14 баров включая текущий.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной ряд (обычно цены **Low**, но допустимы любые числовые последовательности) |
| `inRange` | `Range` | весь массив | Диапазон индексов входных данных для обработки |
| `optInTimePeriod` | `int` | `30` | Размер скользящего окна: чем меньше — выше чувствительность к локальным минимумам, но чаще ложные пробои уровней |
| `outReal` | `Span<T>` | — | Выходной массив с валидными значениями минимумов (длина = `outRange.End - outRange.Start + 1`) |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых рассчитаны значения (`Start` = первый валидный бар) |
| *Возврат* | `RetCode` | — | Код результата: `Success` при успешном расчёте или код ошибки |

**Lookback period:** `optInTimePeriod - 1` баров — количество баров, необходимых до появления первого валидного значения.

## Этапы расчёта
1. Определить стартовый индекс с учётом периода запаздывания: `startIdx = max(заданный_старт, optInTimePeriod - 1)`
2. Для каждого бара найти минимум в окне `[текущий_бар - период + 1, текущий_бар]`
3. Сохранить найденное значение в выходной массив
4. Сдвинуть окно на один бар вправо и повторить до конца диапазона

## Интерпретация значений
- Каждое значение `outReal[i]` — абсолютный минимум цены в окне размером `optInTimePeriod`, заканчивающемся на баре `outRange.Start + i`
- При использовании с ценами **Low** формирует «зубчатую» линию поддержки, отражающую локальные минимумы
- Плоские участки линии означают, что минимум сохраняется в течение нескольких баров (сильный уровень поддержки)

## Практическое применение
✅ **Для чего использовать**
- Динамическое определение уровней поддержки без ручной прорисовки
- Построение нижней границы ценового канала (в паре с индикатором `Max`)
- Фильтрация входов: покупка при отскоке от уровня `Min` с подтверждением объёмом
- Базовый компонент для расчёта стохастических осцилляторов

💡 **Идеи для стратегий**
1. Пробой уровня: лонг при закрытии выше `Min(period=20)` после 3+ баров ниже него
2. Дивергенция: цена формирует новый минимум, но `Min(period=14)` не обновляет минимум — сигнал разворота
3. Канальная торговля: вход в лонг у `Min(period=50)`, тейк-профит у `Max(period=50)`

⚠️ **Ограничения**
- Запаздывает на `period - 1` баров относительно реального минимума
- На флэтах генерирует «пилообразные» ложные сигналы
- Не учитывает объёмы — минимум на низком объёме менее значим
- Требует подтверждения другими инструментами для надёжных сигналов

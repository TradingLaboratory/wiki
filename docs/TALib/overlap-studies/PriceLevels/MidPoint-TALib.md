# MidPoint — Средняя точка

**Категория:** `OverlapStudies` • **Тип:** Индикатор центральной тенденции

---

## Краткое описание
💡 Индикатор вычисляет среднюю арифметическую точку между максимальным и минимальным значениями входного ряда за заданный период. В отличие от осцилляторов, значения MidPoint находятся в том же диапазоне, что и исходные цены (например, 100–150$ для акций), без фиксированных границ. Работает на любых таймфреймах, но наиболее эффективен на среднесрочных периодах (1H–D1) для фильтрации краткосрочного шума. Измеряет центральную линию ценового движения, выступая как сглаженный ориентир тренда.

## Особенности расчёта
В отличие от похожего индикатора `MidPrice` (который использует отдельные массивы High и Low), MidPoint рассчитывается на основе **единственного временного ряда** — обычно цен закрытия. Это делает его универсальным для анализа любых числовых последовательностей (не только цен).

## Автор индикатора
Конкретный автор неизвестен — индикатор представляет собой базовую математическую трансформацию ценового ряда, широко применяемую в техническом анализе с середины XX века как элемент скользящих диапазонов.

## Формула расчёта
```
MidPoint[t] = (Highest(inReal, period) + Lowest(inReal, period)) / 2
```
Где:
- `Highest` — максимальное значение во входном ряду за последние `period` баров
- `Lowest` — минимальное значение за тот же период
- `t` — текущий бар

Пример для периода 5: если цены закрытия за 5 баров = [100, 102, 98, 105, 101], то `MidPoint = (105 + 98) / 2 = 101.5`.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных (начальный/конечный индексы) |
| `outReal` | `Span<T>` | — | Выходной массив со значениями индикатора (только валидные данные) |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых рассчитаны значения |
| `optInTimePeriod` | `int` | `14` | Период расчёта: чем больше — сильнее сглаживание, но выше запаздывание. Минимум: 2 |

## Результат расчёта
Метод возвращает `Core.RetCode` (статус выполнения). Выходной массив `outReal` содержит значения центральной линии в ценовых единицах. **Lookback период**: `optInTimePeriod - 1` — первое валидное значение появляется на баре с индексом `13` при периоде 14.

## Этапы расчёта
1. Для текущего бара формируется скользящее окно размером `optInTimePeriod`
2. В окне определяются минимальное (`Lowest`) и максимальное (`Highest`) значения
3. Рассчитывается средняя точка: `(Highest + Lowest) / 2`
4. Процесс повторяется для каждого последующего бара сдвигающимся окном

## Интерпретация значений
- Значение индикатора отражает **центр диапазона** движения цены за период
- Цена выше MidPoint → краткосрочное бычье давление
- Цена ниже MidPoint → краткосрочное медвежье давление
- Горизонтальное движение индикатора → боковой тренд (флэт)
- Наклон линии вверх/вниз → подтверждение направления тренда

## Практическое применение
✅ **Для чего использовать**
• Выявление центральной оси тренда при отсутствии явного направления
• Фильтрация ложных пробоев в диапазонной торговле
• Динамический уровень поддержки/сопротивления в сочетании с ценой

💡 **Идеи для стратегий**
1. **Пробой центра диапазона**: покупка при закрытии выше MidPoint после 3+ баров ниже него (и наоборот для продажи)
2. **Дивергенция**: расхождение между ценой (новый максимум) и MidPoint (плоский/падающий) — сигнал разворота
3. **Канальная система**: верхняя граница = `Highest`, нижняя = `Lowest`, MidPoint = центральная линия для входов при отскоке от границ

⚠️ **Ограничения**
• Слабо реагирует на резкие импульсы из-за сглаживания
• Неэффективен в условиях сильного тренда (запаздывает за ценой)
• Требует подтверждения другими инструментами при работе во флэте

## Сравнение с аналогами
| Критерий | MidPoint | SMA | MidPrice |
|----------|----------|-----|----------|
| **Исходные данные** | Один ряд (Close) | Один ряд | Два ряда (High + Low) |
| **Чувствительность** | Средняя | Низкая | Высокая |
| **Запаздывание** | Умеренное | Высокое | Низкое |
| **Шумоустойчивость** | Высокая | Очень высокая | Средняя |

# Ma — Скользящее среднее (MA)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор / Сглаживание

---

## Краткое описание

📈 **Moving Average** — универсальный инструмент для сглаживания ценовых рядов и выявления направления тренда. Не является осциллятором, не имеет фиксированных границ (следует за ценой). Подходит для любых таймфреймов. Измеряет среднюю цену за период, фильтруя рыночный шум. Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

⚡ Метод `Ma` является **обёрткой (wrapper)**. Он не вычисляет значения самостоятельно, а делегирует расчёт конкретным алгоритмам (SMA, EMA, KAMA и др.) в зависимости от параметра `optInMAType`. 

❗ **Важно:** Некоторые сложные скользящие требуют дополнительных параметров. При вызове через `Ma` используются **внутренние значения по умолчанию** из соответствующих методов TA-Lib:

| Тип MA | Дополнительный параметр | Значение по умолчанию |
|--------|------------------------|----------------------|
| **KAMA** | Fast Period | `2` |
| **KAMA** | Slow Period | `30` |
| **T3** | Volume Factor (VFactor) | `0.7` |
| **MAMA** | Fast Limit | `0.5` |
| **MAMA** | Slow Limit | `0.05` |

Для тонкой настройки этих параметров рекомендуется вызывать специализированные методы (`Kama`, `T3`, `Mama`) напрямую.

## Автор - разработчик индикатора

*   **Общий концепт:** Статистический инструмент, авторство не атрибутировано.
*   **Отдельные типы:** 
    *   KAMA — Перри Кауфман (Perry Kaufman), 1998 г.
    *   MAMA — Джон Элерс (John Ehlers), 2001 г.
*   **Источник:** Классическая техническая литература (например, «Technical Analysis of the Financial Markets» Дж. Мерфи).

## Формула расчёта
Зависит от выбранного типа (`optInMAType`). Базовая формула для SMA:
```math
SMA = \frac{\sum_{i=1}^{n} P_i}{n}
```
*   `P_i` — цена (Close, High и т.д.)
*   `n` — период (`optInTimePeriod`)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены Close) |
| `inRange` | `Range` | — | Диапазон обработки входных данных |
| `outReal` | `Span<T>` | — | **Выход:** массив рассчитанных значений индикатора |
| `outRange` | `out Range` | — | **Выход:** диапазон валидных данных (учитывает lookback) |
| `optInTimePeriod` | `int` | `30` | Период усреднения. Влияет на чувствительность и запаздывание |
| `optInMAType` | `Core.MAType` | `Sma` | Тип алгоритма (Sma, Ema, Wma, Dema, Tema, Trima, Kama, Mama, T3) |

## Этапы расчёта

1.  Валидация входного диапазона и периода (должен быть ≥ 1).
2.  Если период = 1, копирует входные данные без изменений.
3.  _SWITCH_ по типу `optInMAType`.
4.  Вызов соответствующей функции (например, `Ema`, `Kama`) с передачей данных.
5.  Возврат кода успеха и заполнение `outRange`.

## Интерпретация значений

*   **Наклон:** Восходящий — бычий тренд, нисходящий — медвежий.
*   **Положение цены:** Цена выше MA — поддержка/бычий сигнал, ниже — сопротивление/медвежий.
*   **Индексы:** `outRange.Start` указывает на первый бар, где значение корректно (период запаздывания).

## Практическое применение
✅ **Для чего использовать**
• Фильтрация тренда (торговля только по направлению MA).
• Динамические уровни поддержки и сопротивления.
• Сглаживание данных для других индикаторов.

💡 **Идеи для стратегий**
1.  **Пересечение:** Быстрая MA пересекает медленную снизу вверх → Покупка.
2.  **Отскок:** Цена возвращается к MA в тренде → Вход по тренду.
3.  **Фильтр:** Открывать позиции только если Close > MA(200).

⚠️ **Ограничения**
• Сильное запаздывание на больших периодах.
• В боковике (флэте) generates много ложных сигналов.
• В рамках `Ma` нельзя настроить спец. параметры для KAMA/T3/MAMA.

| Тип | Скорость | Запаздывание | Шумоустойчивость | Особенности |
|-----|----------|--------------|------------------|-------------|
| **SMA** | Низкая | Высокое | Высокая | Базовый стандарт |
| **EMA** | Средняя | Среднее | Средняя | Вес последних цен |
| **DEMA/TEMA** | Высокая | Низкое | Низкая | Минимум лага, больше шума |
| **KAMA** | Адаптивная | Зависит от волатильности | Высокая | Игнорирует флэт |
| **T3** | Высокая | Низкое | Средняя | Гладкая кривая |
| **MAMA** | Адаптивная | Минимальное | Высокая | Следование циклам |

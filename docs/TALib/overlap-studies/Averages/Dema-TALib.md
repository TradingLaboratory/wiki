# Dema — Двойная экспоненциальная скользящая средняя (DEMA)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор с уменьшенным запаздыванием

---

## Краткое описание
💡 **DEMA** (Double Exponential Moving Average) — модификация экспоненциальной скользящей средней, разработанная для минимизации запаздывания (lag) при сохранении сглаживающих свойств. В отличие от обычной EMA, DEMA комбинирует первую и вторую экспоненциальные средние по формуле `2×EMA − EMA(EMA)`, что обеспечивает более быструю реакцию на развороты тренда. Индикатор возвращает значения в том же диапазоне, что и входные цены (не является осциллятором), и эффективен на любых таймфреймах — от минутных до дневных. Измеряет направление и силу тренда с меньшей задержкой по сравнению с классическими скользящими средними.

## Особенности расчёта индикатора
DEMA не является простым усреднением двух EMA — это композиция, где вторая EMA вычитается из удвоенной первой для компенсации запаздывания. Важно не путать DEMA с EMA2 (EMA от EMA): последняя даёт двойное запаздывание, тогда как DEMA его уменьшает.

## Автор — разработчик индикатора
Патрик Г. Маллой ([Patrick G. Mulloy](mulloy-patrick.md))
)) впервые описал индикатор в журнале **Stocks & Commodities** (1994, том 12, №1: «Smoothing Data With Faster Moving Averages» и №2: «Smoothing Data With Less Lag»).

## Формула расчёта
```math
DEMA = 2 × EMA(t, period) − EMA(EMA(t, period), period)
```
**Пояснение:**
- `EMA(t, period)` — первая экспоненциальная скользящая средняя от исходного ряда цен
- `EMA(EMA(t, period), period)` — вторая экспоненциальная средняя (EMA2), рассчитанная от первой EMA
- `period` — период сглаживания

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inRange` | `Range` | весь массив | Диапазон индексов входных данных для обработки |
| `optInTimePeriod` | `int` | `30` | Период сглаживания: уменьшение повышает чувствительность к ценовым изменениям, но увеличивает шум; увеличение даёт более плавную линию с большим запаздыванием |
| `outReal` | `Span<T>` | — | Выходной массив со значениями DEMA (только валидные элементы) |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых рассчитаны валидные значения |

## Этапы расчёта
1. Рассчитывается первая EMA от исходного ряда цен на расширенном диапазоне (с учётом периода запаздывания)
2. Рассчитывается вторая EMA (EMA2) от значений первой EMA
3. Применяется формула: `DEMA = 2 × первая_EMA − вторая_EMA`
4. Формируется выходной массив только с валидными значениями (после завершения периода запаздывания)

## Результат расчёта
- **Выход:** массив `outReal` содержит значения DEMA, соответствующие ценам в диапазоне `outRange`
- **Период запаздывания:** `lookback = EmaLookback(period) × 2`. Для периода 30 требуется минимум 58 баров входных данных для первого валидного значения
- **Интерпретация:** каждое значение DEMA отражает текущую «сглаженную» цену с минимальной задержкой относительно реального движения

## Интерпретация значений
- Значения выше цены → восходящий тренд с поддержкой
- Значения ниже цены → нисходящий тренд с сопротивлением
- Пересечение цены и DEMA снизу вверх → потенциальный сигнал покупки
- Пересечение цены и DEMA сверху вниз → потенциальный сигнал продажи

## Практическое применение
✅ **Для чего использовать**
• Фильтрация ложных пробоев при торговле по тренду
• Генерация сигналов разворота с меньшей задержкой, чем у SMA/EMA
• Сглаживание ценовых данных для визуализации тренда без сильного запаздывания
• База для построения динамических уровней поддержки/сопротивления

💡 **Идеи для стратегий**
1. **Пересечение двух DEMA:** быстрая DEMA(9) пересекает медленную DEMA(21) снизу → сигнал покупки
2. **Цена-DEMA:** вход в лонг при закрытии свечи выше DEMA(30) после предыдущего закрытия ниже
3. **Комбинация с осциллятором:** сигнал от пересечения цены и DEMA подтверждается выходом RSI из зоны перепроданности

⚠️ **Ограничения**
• На флэтах генерирует ложные сигналы из-за повышенной чувствительности
• Требует адаптации периода под волатильность инструмента (стандартный 30 может быть неоптимален)
• Не подходит для измерения силы тренда — только для определения направления и моментов разворота

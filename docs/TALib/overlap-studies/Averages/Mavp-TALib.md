# Mavp — Скользящее среднее с переменным периодом (MAVP)

**Категория:** `OverlapStudies` • **Тип:** Адаптивное скользящее среднее

---

## Краткое описание
💡 **MAVP** (Moving Average with Variable Period) — адаптивный индикатор, рассчитывающий скользящее среднее с динамически изменяемым периодом для каждой точки данных. В отличие от классических MA с фиксированным периодом, чувствительность индикатора регулируется внешним массивом `inPeriods`, что позволяет адаптироваться к волатильности рынка: короткие периоды повышают реактивность при сильных движениях, длинные — сглаживают шум в боковиках. Диапазон значений совпадает с ценовым диапазоном входных данных (не осциллятор). Предпочтителен для мультитаймфрейм-анализа и адаптивных систем.

## Особенности расчёта
Алгоритм оптимизирован: для каждого уникального периода расчёт выполняется один раз с кэшированием результатов, что снижает вычислительную сложность. Все значения периода автоматически усекаются до диапазона [`optInMinPeriod`, `optInMaxPeriod`], предотвращая ошибки при выходе за границы.

## Автор — разработчик индикатора
Концепция адаптивных скользящих средних с переменным периодом была систематизирована и популяризирована **Джоном Ф. Элерсом** ([John F. Ehlers](ehlers-john.md)). В своих работах он развил идею динамической адаптации параметров фильтров к рыночным условиям. Ключевые публикации:
- **«Rocket Science for Traders»** (2001) — введение адаптивных циклических индикаторов
- **«Cybernetic Analysis for Stocks and Futures»** (2004) — развитие концепции адаптивных фильтров и скользящих средних

В библиотеке TA-Lib индикатор реализован как стандартизированный инструмент для гибкого расчёта скользящих средних с внешним управлением периода.

## Формула расчёта
```
MAVP[i] = MA(inReal, period = inPeriods[i])
```
Где:
- `MA` — выбранное скользящее среднее (SMA/EMA/WMA и др.)
- `inPeriods[i]` — период для точки `i`, ограниченный [`optInMinPeriod`, `optInMaxPeriod`]

Пример: при `inPeriods[100] = 5` и `optInMAType = EMA` значение `outReal[100]` будет равно экспоненциальному среднему за 5 баров.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inPeriods` | `ReadOnlySpan<T>` | — | Массив периодов для каждой точки; значения усекаются до [`optInMinPeriod`, `optInMaxPeriod`] |
| `inRange` | `Range` | — | Диапазон обработки входных данных; если не указан — обрабатывается весь массив |
| `outReal` | `Span<T>` | — | Выходной массив со значениями индикатора (только валидные точки) |
| `outRange` | `out Range` | — | Диапазон индексов в `inReal`, для которых рассчитаны валидные значения |
| `optInMinPeriod` | `int` | `2` | Минимальный допустимый период; снижение повышает чувствительность, но увеличивает шум |
| `optInMaxPeriod` | `int` | `30` | Максимальный допустимый период; увеличение усиливает сглаживание и запаздывание |
| `optInMAType` | `MAType` | `Sma` | Тип скользящего среднего: `Sma`, `Ema`, `Wma`, `Dema`, `Tema` и др. |

**Период запаздывания (lookback):** `optInMaxPeriod - 1` баров. Первое валидное значение появляется после накопления данных за максимальный период.

## Этапы расчёта
1. Валидация входных диапазонов и параметров
2. Усечение всех значений `inPeriods` до диапазона [`minPeriod`, `maxPeriod`]
3. Для каждого уникального периода — однократный расчёт соответствующего типа MA
4. Кэширование результатов и заполнение `outReal` для всех точек с одинаковым периодом
5. Формирование `outRange` с индексом первого валидного значения (`startIdx = lookbackTotal`)

## Интерпретация значений
- Значение `outReal[i]` соответствует скользящему среднему с периодом `inPeriods[i]` для точки `inReal[i]`
- При росте периода линия индикатора сглаживается и запаздывает; при снижении — становится реактивнее
- Диапазон `outRange` указывает, для каких баров входных данных получены корректные значения (первые `lookback` баров пропускаются)

## Практическое применение
✅ **Для чего использовать**
• Адаптация чувствительности к волатильности: короткие периоды в трендах, длинные — в флетах
• Фильтрация ложных пробоев через динамическое изменение периода на основе ATR или стандартного отклонения
• Построение многослойных систем с разной реакцией на одних и тех же данных

💡 **Идеи для стратегий**
1. **Волатильностно-адаптивный фильтр**: `inPeriods[i] = 10 + (ATR[i] > порог ? -5 : +5)` — сокращение периода при росте волатильности для быстрого входа в тренд
2. **Режимный переключатель**: период = 5 в тренде (по ADX > 25), период = 20 во флете — снижение ложных сигналов
3. **Мультитаймфрейм-подтверждение**: использование периода из старшего ТФ для сглаживания шума на младшем

⚠️ **Ограничения**
• Требует внешнего источника для генерации массива периодов — «сырой» индикатор без логики адаптации
• При резких скачках периода возможны артефакты в виде разрывов линии
• Не рекомендуется для скальпинга на таймфреймах < 5 минут из-за повышенной чувствительности к шуму

## Сравнение с аналогами
| Индикатор | Тип адаптации | Запаздывание | Шумоустойчивость | Сложность настройки |
|-----------|---------------|--------------|------------------|---------------------|
| **MAVP** | Внешняя (через массив периодов) | Переменное | Зависит от логики генерации периодов | Высокая (требует алгоритма периодов) |
| **KAMA** | Встроенная (на основе шума) | Автоматически регулируемое | Высокая | Низкая |
| **FRAMA** | Фрактальная | Адаптивное | Средняя | Средняя |
| **SMA** | Нет | Фиксированное | Низкая при коротких периодах | Минимальная |

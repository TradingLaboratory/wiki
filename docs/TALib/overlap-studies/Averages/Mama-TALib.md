# Mama (MAMA, FAMA) - Адаптивное скользящее среднее MESA (MAMA)

**Категория:** `OverlapStudies` • **Тип:** Адаптивный трендовый индикатор

---

## Краткое описание

**MESA** (Maximum Entropy Spectral Analysis) — это адаптивное скользящее среднее, которое динамически подстраивается под доминирующий рыночный цикл. 📈 Индикатор генерирует две линии: **MAMA** (основная) и **FAMA** (сигнальная). Значения не ограничены диапазоном (не осциллятор), следуют за ценой. Предназначен для выделения тренда с минимальным запаздыванием и фильтрации рыночного шума. Предпочтительно использовать на таймфреймах от H1 и выше, где циклы выражены четче.

## Особенности расчёта индикатора

В отличие от классических MA (SMA/EMA), MAMA использует **преобразование Хилберта** для определения текущего периода цикла рынка. Коэффициент сглаживания (Alpha) меняется автоматически: увеличивается на тренде (быстрая реакция) и уменьшается во флэте (сглаживание).

## Автор - разработчик индикатора

- **John Ehlers** (Джон Элерс)
- Впервые упомянут в конце 1990-х — начале 2000-х.
- Источник: Описан в книге Джона Элерса (реализация совместима с TradeStation).

## Формула расчёта
```text
DeltaPhase = prevPhase - currentPhase
Alpha = FastLimit / DeltaPhase (ограничено SlowLimit..FastLimit)

MAMA = Alpha * Price + (1 - Alpha) * prevMAMA
FAMA = (Alpha/2) * MAMA + (1 - Alpha/2) * prevFAMA
```
- **Alpha**: фактор адаптивности.
- **Price**: сглаженная цена (WMA).
- **DeltaPhase**: разница фаз цикла.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены Close) |
| `optInFastLimit` | `double` | `0.5` | Верхняя граница Alpha. Рост = выше чувствительность |
| `optInSlowLimit` | `double` | `0.05` | Нижняя граница Alpha. Рост = больше сглаживания |
| `outMAMA` | `Span<T>` | — | Основная адаптивная линия (тренд) |
| `outFAMA` | `Span<T>` | — | Сглаженная линия (сигнал) |
| `outRange` | `Range` | — | Диапазон валидных данных в выходных массивах |

**Результат и запаздывание:**  
Метод возвращает `RetCode` (статус). Валидные данные доступны после периода запаздывания.  
**Lookback:** `UnstablePeriod + 32`. Фиксированная часть (32 бара) нужна для инициализации буферов Хилберта и WMA.

## Этапы расчёта

1. Сглаживание цены через взвешенное скользящее среднее (WMA).
2. Преобразование Хилберта для получения квадратурных компонентов (I/Q).
3. Вычисление доминирующего периода цикла на основе фазовых различий.
4. Расчет Alpha-фактора в пределах Fast/Slow лимитов.
5. Обновление линий MAMA и FAMA с использованием текущего Alpha.

## Интерпретация значений

- **Направление:** Рост MAMA/FAMA указывает на восходящий тренд, падение — на нисходящий.
- **Пересечения:** Бычий сигнал, когда MAMA пересекает FAMA снизу вверх. Медвежий — сверху вниз.
- **Расхождение:** Большое расстояние между линиями подтверждает силу тренда, схождение предупреждает о консолидации.

## Практическое применение

✅ **Для чего использовать**
• Определение направления тренда с меньшим лагом, чем у EMA.
• Генерация сигналов входа/выхода по пересечению линий.
• Фильтрация ложных пробоев во флэте.

💡 **Идеи для стратегий**
1. **Trend Follow:** Вход в лонг при пересечении MAMA > FAMA + подтверждение объемом.
2. Trend Follow: Определение устойчивого тренда по наклону и MAMA и FAMA
3. **Filter:** Использовать наклон FAMA как фильтр для других осцилляторов (RSI, Stoch).
4. **Exit:** Выход из позиции при обратном пересечении линий.

⚠️ **Ограничения**
• Запаздывание все же присутствует (32 бара + unstable period).
• Может давать ложные сигналы на очень коротких таймфреймах (M1, M5) из-за шума.

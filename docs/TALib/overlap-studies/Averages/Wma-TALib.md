# Wma — Взвешенная скользящая средняя (WMA)

**Категория:** `OverlapStudies` • **Тип:** Сглаживающая скользящая средняя с линейными весами

---

## Краткое описание

💡 **WMA** (Weighted Moving Average) — скользящая средняя, где более свежие цены получают больший вес по линейной шкале (1, 2, 3…). В отличие от простой средней (SMA), WMA быстрее реагирует на изменения цены за счёт акцента на недавних данных. Диапазон значений совпадает с диапазоном входных цен. Предпочтителен для краткосрочного анализа на таймфреймах от M5 до H4. Измеряет направление и силу краткосрочного тренда, эффективно фильтруя шум при сохранении отзывчивости.

## Особенности расчёта индикатора

Алгоритм использует оптимизированный подход: вместо прямого умножения на веса применяется накопление сумм с последующей коррекцией при сдвиге окна. Это минимизирует количество операций с плавающей точкой и обращений к памяти. Сумма весов рассчитывается по формуле арифметической прогрессии: `n × (n + 1) / 2`.

## Автор — разработчик индикатора

Классический математический метод, не имеющий единого автора. В техническом анализе применяется с середины XX века как альтернатива простой скользящей средней для повышения чувствительности к текущим ценовым движениям.

## Формула расчёта
```
WMA = Σ(Price[i] × Weight[i]) / Σ(Weight)
где:
  • Weight[i] = 1, 2, 3, ..., n (вес растёт к текущему бару)
  • Σ(Weight) = n × (n + 1) / 2
  • n — период расчёта (optInTimePeriod)
```

**Пример для периода 3:**  
Для цен [10, 11, 12]:  
Взвешенная сумма = 10×1 + 11×2 + 12×3 = 68  
Сумма весов = 3×4/2 = 6  
WMA = 68 / 6 ≈ 11.33

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены Close) |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для расчёта |
| `optInTimePeriod` | `int` | `30` | Период усреднения. Меньше значение → выше чувствительность, но больше шума. Минимум: 2 |
| `outReal` | `Span<T>` | — | Выходной массив со значениями WMA (только валидные точки) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны значения: `Start = optInTimePeriod - 1`, `End = длина inReal` |
| *возврат* | `RetCode` | — | Код результата: `Success` при успешном расчёте |

**Период запаздывания (lookback):** `optInTimePeriod - 1`  
Первое валидное значение появляется на баре с индексом `период - 1`.

## Этапы расчёта
1. Инициализация: накопление простой суммы (`periodSub`) и взвешенной суммы (`periodSum`) для первого окна
2. На каждом шаге:
   - Добавление нового значения в `periodSub` и `periodSum` (с весом = период)
   - Вычитание старейшего значения из `periodSub`
   - Расчёт WMA: `periodSum / divider`
   - Коррекция `periodSum` вычитанием `periodSub` для подготовки к следующей итерации

## Интерпретация значений
- Значение WMA интерпретируется как динамическая поддержка/сопротивление
- Цена выше WMA → краткосрочный восходящий импульс
- Цена ниже WMA → краткосрочный нисходящий импульс
- Наклон линии WMA отражает ускорение/замедление тренда

## Практическое применение

✅ **Для чего использовать**
- Фильтрация ложных пробоев уровней поддержки/сопротивления
- Определение краткосрочного направления тренда в боковике
- Сглаживание ценовых данных для построения каналов
- Быстрый отклик на развороты при сочетании с осцилляторами

💡 **Идеи для стратегий**
1. **Пересечение ценой WMA:** покупка при закрытии выше WMA(10) в восходящем тренде, продажа — при закрытии ниже
2. **Двойная WMA:** сигнал на покупку при пересечении быстрой WMA(7) снизу вверх медленной WMA(21)
3. **Дивергенция:** расхождение между ценой (новый максимум) и WMA(14) (не обновляет максимум) — признак слабеющего импульса

⚠️ **Ограничения**
- Генерирует ложные сигналы в условиях сильного флэта
- Меньше подходит для долгосрочного анализа из-за повышенной чувствительности
- Требует подбора периода под волатильность инструмента

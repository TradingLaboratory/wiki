# MinMax (Min, Max) — Минимальные и максимальные значения (Lowest/Highest)

**Категория:** `OverlapStudies` • **Тип:** Канальный индикатор экстремумов

---
## Краткое описание
⚡ Индикатор вычисляет динамические минимумы (Lowest) и максимумы (Highest) входного ряда в скользящем окне заданной длины. Результаты отображаются поверх ценового графика, формируя адаптивный канал поддержки/сопротивления без сглаживания. Диапазон значений совпадает с диапазоном входных данных (не является осциллятором). Предпочтителен на средних и длинных таймфреймах (H1+), где экстремумы периода имеют статистическую значимость. Отличается от аналогов (например, полос Боллинджера) тем, что строится строго на реальных экстремальных значениях без использования стандартного отклонения.

## Особенности расчёта
Алгоритм оптимизирован для перекрывающихся окон: при сдвиге окна на один бар проверяются только новые значения и индексы предыдущих экстремумов. Поддерживает in-place вычисления (входные и выходные буферы могут совпадать).

## Автор индикатора
Базовая статистическая функция без конкретного автора. Используется в техническом анализе с момента появления первых скользящих окон (1970-е гг.) как элементарный метод выявления экстремумов периода.

## Формула расчёта
```
Lowest[t]  = MIN(inReal[i]), где i ∈ [t - (period - 1), t]
Highest[t] = MAX(inReal[i]), где i ∈ [t - (period - 1), t]
```
**Пояснение переменных:**
- `inReal` — входной ценовой ряд (обычно High/Low или Close)
- `period` — длина скользящего окна (`optInTimePeriod`)
- `t` — текущий бар

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной ряд: цены (Close/High/Low) или значения другого индикатора |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для обработки |
| `outMin` | `Span<T>` | — | Выходной массив минимальных значений (нижняя граница канала) |
| `outMax` | `Span<T>` | — | Выходной массив максимальных значений (верхняя граница канала) |
| `outRange` | `out Range` | — | Диапазон индексов с валидными значениями в исходных данных |
| `optInTimePeriod` | `int` | `30` | Длина окна поиска экстремумов. Минимум: 2. Увеличение периода снижает шум, но повышает запаздывание |

**Lookback-период:** `optInTimePeriod - 1` (первое валидное значение появляется на этом баре).

## Этапы расчёта
1. Для текущего бара `t` определяется окно `[t - period + 1, t]`
2. В окне ищется минимальное значение → сохраняется в `outMin`
3. В том же окне ищется максимальное значение → сохраняется в `outMax`
4. Окно сдвигается на следующий бар, процесс повторяется

## Интерпретация значений
- `outMin[i]` — уровень поддержки за последние `period` баров
- `outMax[i]` — уровень сопротивления за последние `period` баров
- Сужение канала (`outMax - outMin`) сигнализирует о снижении волатильности
- Касание цены верхней/нижней границы часто совпадает с локальными экстремумами

## Практическое применение
✅ **Для чего использовать**
• Определение динамических уровней поддержки/сопротивления
• Фильтрация ложных пробоев (цена должна закрыться за пределами канала)
• Измерение сжатия/расширения волатильности через ширину канала
• База для расчёта нормализованных осцилляторов (например, %R)

💡 **Идеи для стратегий**
1. **Пробой канала:** Покупка при закрытии выше `outMax`, продажа при закрытии ниже `outMin`
2. **Отскок от границ:** Продажа у `outMax` + RSI > 70, покупка у `outMin` + RSI < 30
3. **Сжатие перед импульсом:** Открытие позиции при пробое узкого канала (ширина < 20% от средней за месяц)

⚠️ **Ограничения**
• На коротких таймфреймах (M1-M5) генерирует много ложных сигналов из-за шума
• Не учитывает объёмы и силу движения — границы могут пробиваться без продолжения
• Запаздывание растёт с увеличением периода: при `period=50` границы отстают от текущей цены на ~25 баров

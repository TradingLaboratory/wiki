# HtTrendline — Мгновенная трендовая линия Гильберта (HT Trendline)

**Категория:** `CycleIndicators` • **Тип:** Адаптивное перекрытие (Overlap Study)

---
## Краткое описание

💡 **HtTrendline** строит сглаженную трендовую линию, автоматически адаптируясь к длине доминирующего рыночного цикла. В отличие от классических скользящих средних, индикатор не имеет фиксированного периода, что снижает запаздывание на меняющихся рынках. Значения не ограничены диапазоном (следуют за ценой). Предназначен для определения направления тренда и фильтрации рыночного шума. Лучше всего работает на таймфреймах от H1 и выше.

## Особенности расчёта

Алгоритм использует **трансформацию Гильберта** для выделения фазовой и квадратурной компонент, что позволяет динамически оценивать период цикла. В реализации TALib добавлена задержка (lookback) для совместимости с Tradestation.

## Автор - разработчик индикатора

- **Джон Эрлерс (John Ehlers)** — известный исследователь циклов в трейдинге.
- **Год:** Конец 1990-х.
- **Источник:** Книга *"Cybernetic Analysis for Stocks and Futures"*.

## Формула расчёта

Финальное сглаживание трендовой линии происходит по формуле взвешенного среднего:

```text
TrendLine = (4 * CurrentAvg + 3 * Prev1 + 2 * Prev2 + 1 * Prev3) / 10
```

- `CurrentAvg` — средняя цена за текущий доминирующий период.
- `Prev1..3` — предыдущие значения тренда.
- Веса (4,3,2,1) дают больший приоритет свежим данным.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные цены (обычно Close). |
| `inRange` | `Range` | Весь массив | Диапазон обрабатываемых данных. |
| `outReal` | `Span<T>` | — | Массив результатов (значения линии). |
| `outRange` | `out Range` | — | Диапазон валидных значений в `outReal`. |
| `T` | `generic` | `double`/`float` | Числовой тип данных. |

**Период запаздывания (Lookback):**  
`UnstablePeriod + 31 + 32`. Требуется пропустить минимум 63 бара + нестабильный период для первого валидного значения.

## Этапы расчёта

1. **Сглаживание:** Входные цены обрабатываются взвешенным скользящим средним (WMA).
2. **Трансформация:** Применяется преобразование Гильберта для получения компонент I и Q.
3. **Цикл:** Вычисляется доминирующий период цикла на основе фазовых данных.
4. **Тренд:** Рассчитывается средняя цена за найденный период.
5. **Финализация:** Применяется взвешенное сглаживание значений тренда.

## Интерпретация значений

- **Цена выше линии:** Восходящий тренд (бычий сигнал) 📈.
- **Цена ниже линии:** Нисходящий тренд (медвежий сигнал) 📉.
- **Пересечение:** Смена направления тренда.
- Линия выступает как динамический уровень поддержки/сопротивления.

## Практическое применение

✅ **Для чего использовать**
• Фильтрация тренда для входа в сторону движения.
• Динамический trailing stop (выход при пробое линии).
• Отсев ложных сигналов в боковике (частые пересечения).

💡 **Идеи для стратегий**
1. **Trend Follow:** Вход в Long, когда Close пересекает HtTrendline снизу вверх.
2. **Filter:** Использовать вместе с ADX. Торговать только если ADX > 25.
3. **Exit:** Закрытие позиции при обратном пересечении цены и линии.

⚠️ **Ограничения**
• Неэффективен на рынках без выраженного доминирующего цикла (хаотичный шум).
• Требует значительной истории данных для старта (lookback).
• Может давать ложные сигналы на очень коротких таймфреймах (M1-M5).

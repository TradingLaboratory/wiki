# HtSine (Sine, LeadSine) — Преобразование Хилберта - Синусоида (HT Sine)

**Категория:** `CycleIndicators` • **Тип:** Адаптивный осциллятор циклов

---

## Краткое описание

💡 **HtSine** идентифицирует циклическое поведение рынка, выделяя доминирующий цикл через преобразование Хилберта. Индикатор генерирует две линии: основную синусоиду и ведущую синусоиду (сдвинутую на 45°). Значения колеблются в диапазоне от **-1 до +1**. В отличие от фиксированных осцилляторов, период адаптивно подстраивается под текущую волатильность. Предназначен для определения точек разворота цикла на любых таймфреймах, но наиболее эффективен на боковых рынках.

## Особенности расчёта

Алгоритм использует **взвешенное скользящее среднее (WMA)** для сглаживания входных цен перед применением преобразования Хилберта. Это уменьшает шум. Период цикла вычисляется динамически (adaptive period), что снижает запаздывание по сравнению со статическими методами.

- **John Ehlers** (Джон Элерс)

## Формула расчёта

Основная логика базируется на вычислении фазы доминирующего цикла (DCPhase):

```text
DCPhase = Accumulate(Phase(I, Q))
outSine = Sin(DCPhase)
outLeadSine = Sin(DCPhase + 45°)
```
- **I, Q**: Синфазная и квадратурная компоненты (результат преобразования Хилберта).
- **DCPhase**: Накопленная фаза цикла в градусах.
- **45°**: Фазовый сдвиг для опережающей линии.

## Параметры метода

| Параметр      | Тип               | Значение по умолчанию | Описание                                      |
| ------------- | ----------------- | --------------------- | --------------------------------------------- |
| `inReal`      | `ReadOnlySpan<T>` | —                     | Входные данные (обычно цены закрытия Close)   |
| `inRange`     | `Range`           | Весь массив           | Диапазон индексов для обработки               |
| `outSine`     | `Span<T>`         | —                     | Основная синусоида (текущая фаза цикла)       |
| `outLeadSine` | `Span<T>`         | —                     | Ведущая синусоида (опережает основную на 45°) |
| `outRange`    | `out Range`       | —                     | Диапазон валидных данных в выходных массивах  |
| `RetCode`     | `Core.RetCode`    | —                     | Код результата (Success или ошибка)           |

**Период запаздывания (Lookback):**  
`HtSineLookback()` = `UnstablePeriod + 31 + 32`.  
Требуется пропустить минимум 63 бара + нестабильный период для получения первого валидного значения.

## Этапы расчёта

1. **Сглаживание:** Входные цены обрабатываются через WMA для удаления шума.
2. **Преобразование Хилберта:** Выделяются компоненты I (In-phase) и Q (Quadrature).
3. **Расчёт фазы:** На основе I и Q вычисляется текущая фаза доминирующего цикла (DCPhase).
4. **Генерация волн:** Вычисляются `Sin(DCPhase)` и `Sin(DCPhase + 45°)` для вывода.

## Интерпретация значений

📈 **Диапазон:** Значения строго ограничены интервалом `[-1.0; 1.0]`.  
🔄 **Сигналы:**  
- **Пересечение линий:** Когда `outSine` пересекает `outLeadSine`, это сигнализирует о завершении цикла (потенциальный разворот цены).  
- **Значения около 0:** Прохождение через нуль указывает на середину циклического движения.  
- **Пики/Впадины:** Экстремумы синусоиды соответствуют вершинам и основаниям ценового цикла.

## Практическое применение

✅ **Для чего использовать**
• Определение точек входа/выхода в рамках рыночного цикла.  
• Фильтрация трендовых стратегий (игнорировать сигналы в сильном тренде).  
• Визуализация длительности доминирующего цикла.

💡 **Идеи для стратегий**
1. **Разворот цикла:** Лонг, когда `outSine` пересекает `outLeadSine` снизу вверх в зоне отрицательных значений.  
2. **Подтверждение тренда:** Если синусоиды застревают в экстремумах и не пересекаются — рынок в тренде, использовать трендовые индикаторы.  
3. **Комбинация с HT DC Period:** Использовать период цикла для настройки тайминга сделок.

⚠️ **Ограничения**
• Даёт ложные сигналы на сильных трендовых движениях (whipsaws).  
• Чувствителен к шуму без предварительного сглаживания цен.  
• Требует значительного объема истории для старта (lookback > 60).

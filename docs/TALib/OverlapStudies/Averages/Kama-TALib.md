# Kama — Адаптивное скользящее среднее Кауфмана (KAMA)

**Категория:** `OverlapStudies` • **Тип:** Адаптивное скользящее среднее

---
## Краткое описание

💡 **Kaufman Adaptive Moving Average (KAMA)** — это трендовый индикатор, который автоматически подстраивает чувствительность под волатильность рынка. В отличие от классических средних (SMA/EMA), KAMA ускоряется во время сильных трендов и замедляется во время флэта, фильтруя рыночный шум.

Значения индикатора не ограничены диапазоном (следуют за ценой). Предназначен для определения направления тренда и динамического отслеживания цены. Возвращает одну коллекцию значений — линию среднего.

## Особенности расчёта индикатора

В отличие от классической версии, реализация в TALib использует фиксированные константы для быстрой и медленной границ сглаживания (2/3 и 2/31), возводя итоговый коэффициент в квадрат для усиления адаптивности. Алгоритм эффективно обновляет скользящую сумму изменений цены без пересчёта всего окна на каждом шаге.

## Автор - разработчик индикатора

- **[Perry Kaufman](kaufman-perry) (Перри Кауфман)**
- **Год:** 1998
- **Источник:** Книга *"Trading Systems and Methods"* (Торговые системы и методы)

## Формула расчёта
```math
1. ER = |Price - Price[n]| / Σ|Price[i] - Price[i-1]|
2. SC = [ER * (FastSC - SlowSC) + SlowSC]²
3. KAMA = PrevKAMA + SC * (Price - PrevKAMA)
```
**Пояснение:**
- `ER` — Коэффициент эффективности (0–1).
- `SC` — Сглаживающая константа.
- `FastSC` = 2/(2+1), `SlowSC` = 2/(30+1).
- `n` — период (`optInTimePeriod`).

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены Close) |
| `inRange` | `Range` | — | Диапазон индексов входных данных для обработки |
| `optInTimePeriod` | `int` | `30` | Период расчёта ER. Меньше = чувствительнее, больше = глаже |
| `outReal` | `Span<T>` | — | Массив результатов (валидные значения KAMA) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, соответствующих `outReal` |
| `RetCode` | `Enum` | — | Статус выполнения (Success/Error) |

**Период запаздывания (Lookback):**  
`optInTimePeriod + UnstablePeriod`. Первые бары до этого значения не имеют валидного сигнала.

## Этапы расчёта

1. **Инициализация:** Накопление суммы абсолютных изменений цены за период.
2. **Расчёт ER:** Отношение чистого изменения цены к сумме всех изменений за период.
3. **Расчёт SC:** Преобразование ER в коэффициент сглаживания (квадратичная зависимость).
4. **Рекурсия:** Обновление значения KAMA на основе предыдущего значения и текущей цены.

## Интерпретация значений

📈 **Направление:** Рост линии — восходящий тренд, падение — нисходящий.  
⚡ **Наклон:** Крутой наклон указывает на сильное трендовое движение (высокий ER).  
🛑 **Плоская линия:** Рынок во флэте (низкий ER), индикатор игнорирует шум.  
🔄 **Пересечение:** Цена выше KAMA — бычий сигнал, ниже — медвежий.

## Практическое применение

✅ **Для чего использовать**
• Фильтрация ложных сигналов в боковом движении.  
• Динамический трейлинг-стоп (линия адаптируется под волатильность).  
• Определение глобального направления тренда на старших таймфреймах.

💡 **Идеи для стратегий**
1. **Trend Follow:** Вход в позицию при развороте наклона KAMA + подтверждение объёмом.  
2. **KAMA Filter:** Использовать KAMA как фильтр для осцилляторов (торговать только по направлению KAMA).  
3. **Exit Signal:** Выход из сделки при пробое линии KAMA в обратную сторону.

⚠️ **Ограничения**
• Запаздывание на резких разворотах (V-shape).  
• Неэффективен в узких консолидациях с низкой волатильностью.  
• Требует настройки периода под конкретный актив.

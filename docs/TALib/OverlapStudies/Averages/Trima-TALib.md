# Trima — Треугольная скользящая средняя (TRIMA)

**Категория:** `OverlapStudies` • **Тип:** Взвешенная скользящая средняя с симметричным распределением весов

---
## Краткое описание
📈 **TRIMA** (Triangular Moving Average) — скользящая средняя, придающая максимальный вес ценам в центре расчётного периода. Веса формируют симметричный «треугольник» (для периода 5: 1-2-3-2-1), в отличие от EMA/WMA, акцентирующих внимание на последних данных. Обеспечивает глубокое сглаживание рыночного шума при сохранении трендовой структуры. Эффективна для фильтрации ложных пробоев на волатильных инструментах.

## Автор индикатора
Треугольная скользящая средняя не имеет единого автора в контексте финансового технического анализа. Это классический статистический метод сглаживания временных рядов, восходящий к работам по теории сигналов и эконометрике середины XX века. В отличие от индикаторов с чёткими авторами (например, RSI — Уэллс Уайлдер, 1978), TRIMA представляет собой математическую технику, постепенно интегрированную в трейдинг через учебную литературу по техническому анализу 1980–1990-х годов как альтернатива стандартным скользящим средним.

## Формула расчёта
Для нечётного периода `N`:
```math
TRIMA(x, N) = SMA(SMA(x, (N+1)/2), (N+1)/2)
```
Для чётного периода `N`:
```math
TRIMA(x, N) = SMA(SMA(x, N/2), N/2 + 1)
```
**Пояснение:**  
- `x` — входной ценовой ряд (обычно Close)  
- Пример для периода 5: `(1·a + 2·b + 3·c + 2·d + 1·e) / 9`  
- Сумма весов для нечётного периода: `((N+1)/2)²`; для чётного: `(N/2)·(N/2 + 1)`

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной ценовой ряд (рекомендуется Close) |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных |
| `outReal` | `Span<T>` | — | Выходной массив со значениями индикатора |
| `outRange` | `out Range` | — | Диапазон индексов с валидными значениями |
| `optInTimePeriod` | `int` | `30` | Период расчёта: увеличение → сильнее сглаживание, но больше запаздывание |

## Результат расчёта

- **Возврат:** `Core.RetCode` (статус выполнения)  
- **Выход:** `outReal` содержит сглаженные значения, соответствующие индексам `outRange`  
- **Lookback:** `optInTimePeriod - 1` баров (минимум для первого валидного значения)  
- **Особенность:** Последнее значение `outRange.End` всегда совпадает с последним индексом входных данных при успешном расчёте.

## Практическое применение

✅ **Для чего использовать** 

• Фильтрация шума на волатильных рынках (криптовалюты, сырьё)  
• Определение основного тренда на старших таймфреймах (H4/D1)  
• База для построения динамических каналов (TRIMA ± множитель ATR)  
• Сглаживание входных данных для других индикаторов

💡 **Идеи для стратегий**:

1. **Трендовый фильтр:** Вход в лонг при цене > TRIMA(50), фиксация при возврате под линию.  
2. **Двойная система:** Сигнал при пересечении быстрой TRIMA(14) сверху медленной TRIMA(30).  
3. **Подтверждение пробоя:** Пробой уровня подтверждается, если цена закрепляется за ним на фоне роста над TRIMA(20).  
4. **Комбинация с волатильностью:** Сужение канала (TRIMA ± 1.5·ATR) предшествует всплеску волатильности.

⚠️ **Ограничения**:

• Запаздывание растёт с увеличением периода — не подходит для краткосрочной торговли  
• Во флэте генерирует ложные сигналы из-за частых пересечений цены и линии индикатора  
• Требует подтверждения от объёмов или осцилляторов для повышения надёжности

## Сравнение с аналогами
| Индикатор | Запаздывание | Сглаживание | Акцент весов |
|-----------|--------------|-------------|--------------|
| **SMA**   | Среднее      | Слабое      | Равномерный  |
| **EMA**   | Низкое       | Умеренное   | На последних |
| **WMA**   | Низкое       | Умеренное   | На последних |
| **TRIMA** | Высокое      | Сильное     | В центре     |

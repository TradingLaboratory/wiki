# T3 — Скользящая средняя Тилсона (Tillson's T3)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор с адаптивным сглаживанием

---

## Краткое описание

⚡ **T3** (Tillson's T3) — сглаженная скользящая средняя с минимальным запаздыванием, разработанная для точного отслеживания тренда без излишней реакции на рыночный шум. В отличие от классических средних, использует шесть последовательных слоёв EMA с уникальным взвешиванием. Значения находятся в том же диапазоне, что и исходные цены (не осциллятор, нет фиксированных границ). Эффективна на любых таймфреймах, но особенно ценна на средних (H1–H4) для фильтрации ложных пробоев в трендовых рынках.

## Особенности расчёта индикатора

Алгоритм применяет не тройное (как в Triple EMA), а шестикратное последовательное сглаживание с последующим комбинированием результатов через весовые коэффициенты, производные от объёмного фактора. Это позволяет достичь лучшего баланса между отзывчивостью и шумоустойчивостью по сравнению с традиционными скользящими средними.

## Автор — разработчик индикатора

- **Тим Тилсон** ([Tim Tillson](tillson-tim), США)
- Впервые описан в январе 1998 г. в статье *«Smoothing Data with Faster Moving Averages»* (журнал *Technical Analysis of Stocks & Commodities*)

## Формула расчёта
```math
GD(x) = EMA1(x) × (1 + v) − EMA2(x) × v
T3 = GD(GD(GD(inReal)))
```
**Пояснение:**
- `inReal` — входной ряд (обычно Close)
- `v` — объёмный фактор (vFactor)
- `GD` — «Generalized Double» сглаживание
- Фактически расчёт требует 6 слоёв EMA с последующим взвешиванием через коэффициенты `c1…c4`

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (цены закрытия, объёмы или значения другого индикатора) |
| `optInTimePeriod` | `int` | `5` | Период базовой EMA (минимум 2). Увеличение → сильнее сглаживание, но больше лага |
| `optInVFactor` | `double` | `0.7` | Объёмный фактор (0.0–1.0). Ближе к 0 → выше отзывчивость; ближе к 1 → сильнее сглаживание |

**Возврат метода:**
- `outReal` — значения T3, соответствующие ценам входного ряда
- `outRange` — диапазон индексов с валидными значениями (`Start` = первый валидный индекс, `End` = последний индекс входных данных)
- `RetCode` — статус выполнения (`Success` при успехе)

**Lookback период:** `(optInTimePeriod - 1) × 6 + unstablePeriod`. Для периода 5 требуется минимум 24 бара для первого валидного значения.

## Этапы расчёта

1. Последовательное вычисление шести EMA (E1→E6), каждая строится на основе предыдущей
2. Расчёт весовых коэффициентов `c1…c4` на основе vFactor
3. Формирование итогового значения: `T3 = c1×E6 + c2×E5 + c3×E4 + c4×E3`
4. Пропуск нестабильного периода для стабилизации начальных значений

## Интерпретация значений

- **Направление линии T3** указывает на текущий тренд (вверх → бычий, вниз → медвежий)
- **Цена выше T3** — краткосрочный восходящий импульс; **цена ниже T3** — нисходящий
- **Пересечение цены и T3** может сигнализировать о смене краткосрочного импульса
- **Диапазон `outRange`**: значения `outReal[0]` соответствуют `inReal[outRange.Start]`, последнее значение — `inReal[outRange.End]`

## Практическое применение

✅ **Для чего использовать**
- Динамические уровни поддержки/сопротивления в тренде
- Фильтрация шума при работе с волатильными инструментами
- База для построения систем с минимальным запаздыванием

💡 **Идеи для стратегий**
1. Покупка при пересечении цены вверх через T3(8), продажа — при пересечении вниз
2. Подтверждение тренда: цена должна находиться выше T3(14) для лонговых позиций
3. Сглаживание осцилляторов: применение T3 к выходу RSI для уменьшения ложных сигналов

⚠️ **Ограничения**
- Слабая эффективность во флэте с частыми ложными пробоями
- Требует достаточной истории данных из-за большого lookback-периода
- При низком vFactor (<0.3) становится чувствительным к выбросам

# T3 — Скользящая средняя T3 (Tillson T3)

**Категория:** `OverlapStudies` • **Тип:** Адаптивная сглаженная скользящая средняя с уменьшенным лагом

---

## Краткое описание
💡 Разработан Тимом Тилсоном ([Tim Tillson](tillson-tim)) как улучшенная альтернатива классическим экспоненциальным скользящим средним (EMA). Основан на шести последовательных слоях EMA с комбинированием через объемный фактор (vFactor), что обеспечивает плавное сглаживание при меньшем запаздывании. Отличается от «Тройной EMA» (EMA3) принципиально иной математикой. Идеален для фильтрации рыночного шума в трендовых условиях.

## Формула расчёта
```math
E1 = EMA(inReal, Period)
E2 = EMA(E1, Period)
...
E6 = EMA(E5, Period)

T3 = C1·E6 + C2·E5 + C3·E4 + C4·E3

где:
C1 = -vFactor³
C2 = 3·(vFactor² - C1)
C3 = -6·vFactor² - 3·(vFactor - C1)
C4 = 1 + 3·vFactor - C1 + 3·vFactor²
```
**Пояснение:**  
- `E1…E6` — шесть последовательных слоёв EMA  
- `vFactor` — объёмный фактор (0.0–1.0), управляющий балансом между сглаживанием и отзывчивостью  
- Чем выше `vFactor`, тем сильнее сглаживание и больше лаг

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд: цены закрытия (Close), High/Low или значения другого индикатора |
| `optInTimePeriod` | `int` | `5` | Период расчёта базовой EMA. Увеличение периода повышает сглаживание, но усиливает лаг |
| `optInVFactor` | `double` | `0.7` | Объёмный фактор (0.0–1.0). Значения ближе к 1.0 дают плавную линию с большим лагом; ближе к 0.0 — более резкую реакцию на цену, но с шумом |

## Результат расчёта
- **`outReal`** — массив значений индикатора T3, соответствующих ценам входного ряда с учётом лага  
- **Период лага (lookback):** `(optInTimePeriod - 1) × 6 + unstablePeriod`  
  Пример: при `optInTimePeriod = 5` первый валидный результат появится на 24-м баре (без учёта нестабильного периода)  
- **`outRange`** — диапазон индексов входных данных, для которых рассчитаны корректные значения T3

## Практическое применение
✅ **Для чего использовать**
- Фильтрация краткосрочного шума в трендовых рынках
- Построение динамических уровней поддержки/сопротивления
- База для систем пересечений (с медленной MA или ценой)
- Сглаживание входных данных для других индикаторов

💡 **Идеи для стратегий**
1. **Пересечение цены и T3:** покупка при закрытии выше T3, продажа — ниже (для трендовых активов)
2. **Двойная T3:** быстрая T3 (Period=5, vFactor=0.6) × медленная T3 (Period=15, vFactor=0.8) — сигнал при пересечении
3. **Дивергенция:** расхождение между ценой и наклоном T3 как ранний сигнал разворота

⚠️ **Ограничения**
- В боковиках генерирует ложные сигналы из-за остаточного лага
- При низком `vFactor` (<0.5) теряет преимущество перед обычной EMA
- Требует достаточной истории данных (минимум 6× период)

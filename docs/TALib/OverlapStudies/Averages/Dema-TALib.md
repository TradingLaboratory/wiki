# Dema — Двойная экспоненциальная скользящая средняя (DEMA)

**Категория:** `OverlapStudies` • **Тип:** Сглаживающий трендовый индикатор с уменьшенным запаздыванием

---

## Краткое описание
💡 **DEMA** (Double Exponential Moving Average) — инновация Патрика Маллоя (1994), направленная на снижение лага классических скользящих средних. В отличие от простой EMA, DEMA комбинирует первую и вторую экспоненциальные средние по формуле `2×EMA − EMA(EMA)`, что даёт более быструю реакцию на развороты цен при сохранении сглаживания. Идеален для трендовых стратегий, где критична скорость сигнала.

## Формула расчёта
```math
DEMA = 2 × EMA(t, period) - EMA(EMA(t, period), period)
```
Где:
- `EMA(t, period)` — первая экспоненциальная скользящая средняя от исходного ряда
- `EMA(EMA(t, period), period)` — вторая EMA (EMA2), рассчитанная от первой
- `period` — период сглаживания (`optInTimePeriod`)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд: цены закрытия (Close), High/Low или значения другого индикатора |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для расчёта. Если не задан — обрабатывается весь `inReal` |
| `optInTimePeriod` | `int` | `30` | Период EMA: уменьшение повышает чувствительность (но добавляет шум), увеличение усиливает сглаживание и лаг |
| `outReal` | `Span<T>` | — | Выходной массив **только с валидными значениями** (длина = `outRange.End - outRange.Start + 1`) |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых получены валидные значения (`Start` — первый валидный индекс) |

## Результат расчёта
- **`outReal`** — массив значений DEMA, соответствующих ценам в диапазоне `outRange`
- **`outRange`** — гарантирует `End == inReal.Length - 1` при успехе; при недостатке данных возвращает `[0, -1]`
- **Lookback**: `DemaLookback = EmaLookback(period) × 2`  
  Первое валидное значение появится только после обработки `2 × period` баров (например, при `period=30` — с 60-го бара).

## Практическое применение

✅ **Для чего использовать**
- Фильтрация ложных пробоев при торговле в тренде
- Быстрое определение разворотов в условиях высокой волатильности
- База для динамических уровней поддержки/сопротивления
- Сглаживание шумных данных без потери реактивности

💡 **Идеи для стратегий**
1. **Пересечение с ценой**: сигнал на покупку при закрытии выше DEMA + рост объёмов; продажа — при закрытии ниже.
2. **Скользящий стоп**: размещение стоп-лосса под DEMA в лонг-позиции (с периодом 21) для трейлинга без преждевременного выхода.
3. **Комбинация с осциллятором**: вход в лонг при пересечении цены снизу вверх DEMA(14) + RSI > 50.
4. **Мультивременной анализ**: подтверждение тренда на старшем ТФ через расположение цены относительно DEMA(50).

⚠️ **Ограничения**
- В боковиках генерирует ложные сигналы из-за повышенной чувствительности
- Требует адаптации периода под волатильность актива (стандартный 30 не универсален)
- Не подходит для фильтрации краткосрочного шума на таймфреймах ниже M5

## Сравнение с аналогами
| Индикатор | Запаздывание | Шумоустойчивость | Скорость реакции | Лучшее применение |
|-----------|--------------|------------------|------------------|-------------------|
| **SMA**   | Высокое      | Средняя          | Низкая           | Долгосрочные тренды |
| **EMA**   | Среднее      | Средняя          | Средняя          | Универсальное сглаживание |
| **DEMA**  | Низкое       | Ниже EMA         | Высокая          | Быстрые трендовые сигналы |
| **TEMA**  | Минимальное  | Низкая           | Очень высокая    | Скальпинг, высокочастотные стратегии |

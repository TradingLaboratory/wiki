# Ema — Экспоненциальное скользящее среднее (EMA)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор наложения

---

## Краткое описание
💡 Экспоненциальное скользящее среднее (Exponential Moving Average) — взвешенный фильтр цен, придающий больший вес недавним данным. В отличие от простого скользящего среднего (SMA), EMA быстрее реагирует на ценовые изменения за счёт экспоненциального сглаживания. Диапазон значений совпадает с ценовым рядом (нет фиксированных границ), индикатор накладывается поверх графика цены. Подходит для любых таймфреймов, особенно эффективен на среднесрочных (H1–D1) для фильтрации шума и определения направления тренда.

## Особенности расчёта индикатора
Первое значение EMA рассчитывается как простое скользящее среднее (SMA) за указанный период. Последующие значения вычисляются рекурсивно по формуле экспоненциального сглаживания. Такой подход обеспечивает плавный переход от начального значения к экспоненциальному режиму.

## Автор — разработчик индикатора
Точного автора классического EMA в трейдинге нет — метод экспоненциального сглаживания восходит к статистическим работам 1940–1950-х гг. (включая труды Роберта Брауна). В техническом анализе популяризирован в 1970-х годах как альтернатива запаздывающему SMA. Широко применяется с выходом первых технических терминалов в 1980-х.

## Формула расчёта
```math
k = 2 / (N + 1)
EMA_t = (Price_t - EMA_{t-1}) × k + EMA_{t-1}
```
Где:  
- `k` — сглаживающий коэффициент (α)  
- `N` — период расчёта (`optInTimePeriod`)  
- `Price_t` — цена текущего бара (обычно Close)  
- `EMA_{t-1}` — значение EMA предыдущего бара  

Пример: при `N = 10` → `k = 2 / (10 + 1) ≈ 0.1818`. Новое значение формируется на 18.18% из разницы между текущей ценой и предыдущим EMA.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной ценовой ряд (обычно Close, но допустимы Open/High/Low/Volume) |
| `inRange` | `Range` | — | Диапазон обработки входных данных. Если не задан — обрабатывается весь массив |
| `outReal` | `Span<T>` | — | Выходной массив только с валидными значениями EMA |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны значения (`Start` — первый валидный индекс, `End` — последний) |
| `optInTimePeriod` | `int` | `30` | Период расчёта. Минимум: 2. Уменьшение периода ↑ чувствительность, но ↑ шум; увеличение ↓ запаздывание, но ↓ реактивность |

**Период запаздывания (Lookback):**  
`optInTimePeriod - 1 + unstablePeriod`  
Первое валидное значение появляется на баре с индексом `optInTimePeriod - 1` (с учётом нестабильного периода сглаживания).

## Этапы расчёта
1. Проверка корректности входных данных и периода (≥2)  
2. Расчёт сглаживающего коэффициента: `k = 2 / (Period + 1)`  
3. Вычисление первого значения как SMA за указанный период  
4. Рекурсивный расчёт последующих значений по формуле экспоненциального сглаживания  

## Интерпретация значений
- **Направление тренда:** цена выше EMA → восходящий тренд; ниже → нисходящий  
- **Динамика:** угол наклона линии отражает силу тренда (крутой наклон = сильное движение)  
- **Поддержка/сопротивление:** в тренде EMA часто выступает динамическим уровнем отскока  

## Практическое применение
✅ **Для чего использовать**  
• Фильтрация рыночного шума на волатильных инструментах  
• Определение основного направления тренда на выбранных таймфреймах  
• Построение динамических уровней поддержки/сопротивления  
• База для мультипериодных систем (например, пересечение быстрой и медленной EMA)  

💡 **Идеи для стратегий**  
1. **Пересечение двух EMA:** сигнал на покупку при пересечении быстрой EMA (период 9) снизу вверх медленной (период 21)  
2. **Отскок от EMA:** вход в тренд при откате цены к среднесрочной EMA (50) с последующим отскоком в направлении тренда  
3. **Фильтр тренда:** разрешать сделки только в направлении старшей EMA (200) на дневном графике  

⚠️ **Ограничения**  
• В боковике генерирует ложные сигналы из-за частых пересечений цены и линии  
• Запаздывает на резких разворотах (хотя меньше, чем SMA)  
• Требует подбора периода под волатильность инструмента и таймфрейм  

## Сравнение с аналогами
| Критерий | EMA | SMA | WMA |
|----------|-----|-----|-----|
| **Реакция на цену** | ⚡ Быстрая | 🐢 Медленная | ⚡⚡ Наиболее быстрая |
| **Запаздывание** | Среднее | Высокое | Низкое |
| **Шумоустойчивость** | Средняя | Высокая | Низкая |
| **Вес недавних данных** | Экспоненциальный | Равный | Линейный убывающий |

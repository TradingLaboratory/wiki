# Sar — Параболический SAR (Parabolic Stop and Reverse)

**Категория:** `OverlapStudies` • **Тип:** Трендовый индикатор наложения с динамическим трейлинг-стопом

---

## Краткое описание
💡 **SAR** (Stop and Reverse) — трендовый индикатор, отображающий серию точек выше или ниже ценовых баров для определения направления тренда и потенциальных точек разворота. Значения индикатора находятся в ценовом диапазоне (не осциллятор), формируя «параболическую» траекторию приближения к цене. Оптимально работает на трендовых рынках с умеренной волатильностью; в боковых диапазонах генерирует ложные сигналы. Измеряет **направление и силу тренда**, одновременно выполняя функцию динамического стоп-лосса.

## Особенности расчёта индикатора
Реализация максимально приближена к оригинальной логике Уэллса Уайлдера и совпадает с Metastock: начальное значение SAR устанавливается как минимум/максимум первого бара, а экстремальная точка (EP) берётся из второго бара. После разворота SAR сбрасывается на значение предыдущей EP и корректируется относительно ценовых экстремумов двух последних баров — это исключает проникновение точек в ценовой диапазон.

## Автор — разработчик индикатора
Разработан **Уэллсом Уайлдером** ([Welles Wilder Jr.](wilder-welles)) и впервые описан в 1978 году в книге *«New Concepts in Technical Trading Systems»*. Индикатор стал одним из ключевых инструментов технического анализа для управления рисками.

## Формула расчёта
```math
SARₙ = SARₙ₋₁ + AF × (EP - SARₙ₋₁)
```
Где:
- `SARₙ` — текущее значение индикатора
- `SARₙ₋₁` — предыдущее значение
- `AF` (Acceleration Factor) — коэффициент ускорения (стартует с `optInAcceleration`, растёт до `optInMaximum`)
- `EP` (Extreme Point) — экстремальная точка: максимум цены при длинной позиции, минимум — при короткой

Пример: При восходящем тренде с `SARₙ₋₁ = 100`, `EP = 110`, `AF = 0.02` → `SARₙ = 100 + 0.02 × (110 - 100) = 100.2`

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимальных цен (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимальных цен (Low) |
| `inRange` | `Range` | весь массив | Диапазон обрабатываемых данных (начальный/конечный индексы) |
| `optInAcceleration` | `double` | `0.02` | Стартовый коэффициент ускорения: чем выше — тем чувствительнее индикатор, но больше ложных сигналов |
| `optInMaximum` | `double` | `0.2` | Максимальное значение ускорения: ограничивает скорость приближения точек к цене |
| `outReal` | `Span<T>` | — | Выходной массив со значениями SAR (точки ниже цены = тренд вверх, выше = тренд вниз) |
| `outRange` | `Range` | — | Диапазон индексов с валидными значениями (Start = первый расчётный бар, End = последний бар входных данных) |
| *Возврат* | `RetCode` | — | Код успешности расчёта (`Success` при успехе) |

**Lookback:** `1` — для расчёта требуется только один предыдущий ценовой бар.

## Этапы расчёта
1. Определение начального направления через сравнение направленного движения (+DM/-DM) между первым и вторым барами
2. Инициализация SAR: минимум первого бара для длинной позиции, максимум — для короткой
3. На каждом баре расчёт нового значения по формуле с учётом текущей EP и AF
4. Коррекция SAR относительно минимумов/максимумов двух предыдущих баров (защита от проникновения в ценовой диапазон)
5. При пробитии цены через SAR — разворот позиции, сброс AF и установка новой EP

## Интерпретация значений
- **Точки ниже цены (Low):** восходящий тренд (позиция Long) — SAR выступает как поддержка
- **Точки выше цены (High):** нисходящий тренд (позиция Short) — SAR выступает как сопротивление
- **Пересечение цены и SAR:** сигнал разворота тренда
- Чем ближе точки к цене — тем сильнее ускорение тренда (растущий AF)

## Практическое применение
✅ **Для чего использовать**
- Определение текущего направления тренда без запаздывания
- Автоматическая установка динамического трейлинг-стопа для фиксации прибыли
- Фильтрация боковых движений (когда точки «скачут» вокруг цены)
- Подтверждение силы тренда в связке с ADX (>25)

💡 **Идеи для стратегий**
1. **Трендовая система:** покупка при формировании точки SAR ниже цены, продажа — при переходе точек выше цены
2. **Трейлинг-стоп:** удержание позиции до пересечения цены с SAR, затем разворот позиции
3. **Фильтрация сигналов:** вход в сделку только при совпадении направления SAR и показаний ADX (>25)
4. **Волатильность-адаптивный стоп:** комбинация SAR с ATR для расширения стоп-зоны в периоды высокой волатильности

⚠️ **Ограничения**
- Генерирует серию ложных сигналов во флэте (боковом тренде)
- Не подходит для скальпинга на младших таймфреймах из-за «зубчатости» точек
- Требует подтверждения другими индикаторами при работе на волатильных активах

# MidPrice — Средняя цена за период (Midpoint Price)

**Категория:** `OverlapStudies` • **Тип:** Индикатор перекрытия, отражающий центр диапазона на основе экстремумов за период

---

## Краткое описание
⚡ Индикатор **не рассчитывает середину отдельного бара** (в отличие от Typical Price или Median Price). Вместо этого он анализирует **всё окно из `N` баров** и вычисляет центральную точку между **глобальными экстремумами** этого окна:
```
MidPrice = (Максимальный High за период + Минимальный Low за период) / 2
```
Результат — линия в ценовых единицах, отображаемая поверх графика. Чем больше период, тем сильнее сглаживание и запаздывание. Оптимален для выявления равновесного уровня в диапазонных рынках на таймфреймах H1–D1.

## Отличие от похожих индикаторов
| Индикатор | Формула | База расчёта | Окно |
|-----------|---------|--------------|------|
| **MidPrice** | `(Highest High + Lowest Low) / 2` | Экстремумы **всех баров** в окне периода | Скользящее окно из `N` баров |
| **Median Price** | `(High + Low) / 2` | Экстремумы **одного текущего** бара | 1 бар |
| **Typical Price** | `(High + Low + Close) / 3` | Все компоненты **одного** бара | 1 бар |
| **MidPoint** (встречается в других библиотеках) | `(Highest Close + Lowest Close) / 2` | Только цены закрытия в окне | Скользящее окно из `N` баров |

⚠️ **Ключевое различие:** При `optInTimePeriod = 14` MidPrice анализирует 14 последовательных баров, находит среди них **абсолютный максимум по всем High** и **абсолютный минимум по всем Low**, затем делит их сумму пополам. Это не усреднение середин отдельных баров!

## Автор индикатора
Конкретный автор неизвестен — метод относится к базовым техникам диапазонного анализа, применяемым с середины XX века. Упоминается в классических работах по техническому анализу как элемент построения ценовых каналов.

## Формула расчёта
```math
MidPrice_t = \frac{\max\limits_{i=t-n+1}^{t}(High_i) + \min\limits_{i=t-n+1}^{t}(Low_i)}{2}
```
**Пояснение:**
- `max(High_i)` — наибольшее значение High среди `n` последних баров (включая текущий)
- `min(Low_i)` — наименьшее значение Low среди тех же `n` баров
- `n` — период (`optInTimePeriod`), минимум 2

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Максимальные цены (High) каждого периода |
| `inLow` | `ReadOnlySpan<T>` | — | Минимальные цены (Low) каждого периода |
| `optInTimePeriod` | `int` | `14` | Размер окна поиска экстремумов. Минимум 2. Увеличение → сильнее сглаживание, больше запаздывание |
| `inRange` | `Range` | — | Диапазон обработки входных данных (опционально) |
| `outReal` | `Span<T>` | — | Выходной массив: центр диапазона для каждого бара |
| `outRange` | `out Range` | — | Диапазон индексов с валидными значениями |

**Lookback период:** `optInTimePeriod - 1` баров.

## Этапы расчёта
1. Для текущего бара `t` определить окно: `[t - period + 1 ... t]`
2. Найти **максимальный High** среди всех баров в окне
3. Найти **минимальный Low** среди всех баров в окне
4. Вычислить полусумму этих двух значений → значение индикатора для бара `t`
5. Сдвинуть окно на 1 бар вправо, повторить

## Интерпретация значений
- Значение = центр коридора, образованного экстремумами за период
- Цена выше MidPrice → давление покупателей в рамках диапазона
- Цена ниже MidPrice → давление продавцов
- Горизонтальный тренд индикатора → консолидация (сужение диапазона)

## Практическое применение
✅ **Для чего использовать**
• Определение центральной оси консолидации при боковом движении
• Фильтрация ложных пробоев: пробой подтверждается при выходе цены за пределы диапазона ±1.5×(High-Low) от MidPrice
• Базовый уровень для построения адаптивных каналов (например, ±2% от MidPrice(20))

💡 **Идеи для стратегий**
1. **Пробой диапазона:** лонг при закрытии выше `MidPrice(14) + (HighestHigh - LowestLow)/2`, шорт — при закрытии ниже `MidPrice(14) - (HighestHigh - LowestLow)/2`
2. **Отскок от границ:** вход при возврате цены к MidPrice(20) после касания границы диапазона
3. **Дивергенция тренда:** цена обновляет максимум, но MidPrice(50) не подтверждает → сигнал ослабления тренда

⚠️ **Ограничения**
• Сильно запаздывает в тренде с постоянным обновлением экстремумов
• Не реагирует на внутреннюю структуру движения (только на границы диапазона)
• Требует комбинации с трендовыми индикаторами (например, EMA) для фильтрации ложных сигналов в волатильных условиях

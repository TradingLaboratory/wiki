# Bbands (UpperBand, MiddleBand, LowerBand) - Полосы Боллинджера (BB)

**Категория:** `OverlapStudies` • **Тип:** Индикатор волатильности с перекрытием цены

---

## Краткое описание 💡

**Bollinger Bands (BB)** — индикатор волатильности, разработанный Джоном Боллинджером. Строит три линии вокруг цены: среднюю (скользящая средняя) и две граничные полосы на расстоянии стандартных отклонений. Полосы расширяются при росте волатильности и сужаются при её падении.

**Диапазон значений:** Не ограничен, полосы следуют за ценой. Не является осциллятором в классическом понимании.

**Предпочтительный таймфрейм:** Любые (от минутных до недельных), стандартный период — 20 баров.

**Что измеряет:** Волатильность рынка, потенциальные зоны перекупленности/перепроданности, силу тренда.

**Возвращает три индикатора:**
- 📈 `outRealUpperBand` — Верхняя полоса
- 📊 `outRealMiddleBand` — Средняя полоса (скользящая средняя)
- 📉 `outRealLowerBand` — Нижняя полоса

---

## Особенности расчёта ⚡

В данной реализации предусмотрена **оптимизация для SMA**: при использовании простой скользящей средней расчёт стандартного отклонения выполняется через специализированный метод `CalcStandardDeviation`, который переиспользует уже вычисленные значения MA для ускорения. При других типах MA вызывается стандартный `StdDevImpl`.

Также реализована **логика оптимизации памяти** с временными буферами для предотвращения конфликтов при наложении входных и выходных массивов.

## Формула расчёта 📐

```
Middle Band = MA(inReal, TimePeriod)
Standard Deviation = StdDev(inReal, TimePeriod)
Upper Band = Middle Band + (Standard Deviation × NbDevUp)
Lower Band = Middle Band - (Standard Deviation × NbDevDn)
```

**Пояснение переменных:**
| Переменная | Описание |
|------------|----------|
| `MA` | Скользящая средняя (тип задаётся в `optInMAType`) |
| `StdDev` | Стандартное отклонение за период |
| `NbDevUp` | Множитель для верхней полосы (по умолчанию 2.0) |
| `NbDevDn` | Множитель для нижней полосы (по умолчанию 2.0) |

**Пример расчёта (период = 20, множители = 2.0):**
- Средняя полоса = SMA₂₀(Close)
- Верхняя полоса = SMA₂₀ + (2 × StdDev₂₀)
- Нижняя полоса = SMA₂₀ − (2 × StdDev₂₀)

## Параметры метода ⚙️

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные: обычно цены закрытия (`Close`), могут быть High/Low/Volume |
| `inRange` | `Range` | Весь массив | Диапазон индексов для обработки во входном массиве |
| `outRealUpperBand` | `Span<T>` | — | Массив для значений верхней полосы (валидные данные) |
| `outRealMiddleBand` | `Span<T>` | — | Массив для значений средней полосы (скользящая средняя) |
| `outRealLowerBand` | `Span<T>` | — | Массив для значений нижней полосы (валидные данные) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных с валидными значениями (Start/End) |
| `optInTimePeriod` | `int` | `5` | Период расчёта MA и StdDev: меньше = чувствительнее, больше = сглаженнее |
| `optInNbDevUp` | `double` | `2.0` | Множитель StdDev для верхней полосы: ↑ значение = шире полосы = меньше сигналов |
| `optInNbDevDn` | `double` | `2.0` | Множитель StdDev для нижней полосы: ↑ значение = шире полосы = меньше сигналов |
| `optInMAType` | `Core.MAType` | `Sma` | Тип скользящей средней: Sma, Ema, Wma, etc. Влияет на сглаживание средней полосы |

**Период запаздывания (Lookback):**
```
Lookback = MaLookback(TimePeriod, MAType)
```
Возвращает количество баров, необходимых для первого валидного значения. При `TimePeriod < 2` возвращает `-1`.

---

## Этапы расчёта 🔢

1. **Валидация параметров** — проверка диапазонов и корректности входных данных
2. **Расчёт средней полосы** — вычисление скользящей средней за указанный период
3. **Расчёт стандартного отклонения** — для того же периода (оптимизировано для SMA)
4. **Расчёт верхней полосы** — Middle + (StdDev × NbDevUp)
5. **Расчёт нижней полосы** — Middle − (StdDev × NbDevDn)
6. **Формирование outRange** — определение диапазона валидных выходных значений

---

## Интерпретация значений 📊

| Ситуация | Интерпретация |
|----------|---------------|
| Цена у **верхней полосы** | Возможная перекупленность, риск коррекции ⚠️ |
| Цена у **нижней полосы** | Возможная перепроданность, потенциал роста 📈 |
| **Сужение полос** | Низкая волатильность, ожидается прорыв ⚡ |
| **Расширение полос** | Высокая волатильность, тренд подтверждается 📈 |
| Цена **выше средней** | Бычий тренд (между Middle и Upper) |
| Цена **ниже средней** | Медвежий тренд (между Middle и Lower) |

**Диапазоны выходных данных:**
- `outRange.Start` — индекс первого бара с валидным значением
- `outRange.End` — индекс последнего бара (гарантированно = последний элемент входных данных)

## Практическое применение 🎯

### ✅ Для чего использовать
• **Определение зон перекупленности/перепроданности** — касание полос как сигнал разворота
• **Идентификация прорывов** — сужение полос предшествует сильным движениям
• **Оценка силы тренда** — цена, удерживающаяся у одной из полос, указывает на сильный тренд
• **Динамические уровни поддержки/сопротивления** — полосы адаптируются к волатильности

### 💡 Идеи для стратегий
1. **Отскок от полос** — покупка при касании нижней полосы + подтверждение разворота, продажа при касании верхней
2. **Прорыв сжатия** — вход в позицию при расширении полос после периода сужения (Squeeze)
3. **Трендовая стратегия** — покупка, когда цена закрепляется выше средней полосы, продажа — ниже
4. **Двойное подтверждение** — BBands + RSI для фильтрации ложных сигналов в боковике
5. **Стоп-лосс по полосам** — размещение стопов за противоположной полосой

### ⚠️ Ограничения
• **Боковой рынок (флэт)** — частые ложные сигналы при отсутствии тренда
• **Запаздывание** — как все индикаторы на MA, реагирует с задержкой
• **Минимум данных** — требуется `TimePeriod` баров для первого валидного значения
• **Сильные тренды** — цена может долго двигаться вдоль полосы, давая ложные сигналы разворота

## Сравнение с аналогами 🔄

| Критерий | Bollinger Bands | Keltner Channels | Donchian Channels |
|----------|-----------------|------------------|-------------------|
| **Основа расчёта** | SMA + StdDev | EMA + ATR | High/Low за период |
| **Скорость реакции** | Средняя | Быстрее | Медленнее |
| **Чувствительность к волатильности** | Высокая | Средняя | Низкая |
| **Шумоустойчивость** | Средняя | Высокая | Низкая |
| **Лучшее применение** | Прорывы, развороты | Трендовые стратегии | Пробойные стратегии |

---

> 📌 **Совет разработчику:** Для снижения количества ложных сигналов комбинируйте BBands с индикаторами импульса (RSI, MACD) или объёма. При использовании в алгоритмических стратегиях учитывайте lookback-период для корректного выравнивания данных.

# Ln — Векторный натуральный логарифм (LN)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Ln** применяет функцию натурального логарифма к каждому элементу входного временного ряда. Это не классический осциллятор, а утилита для предобработки данных. Индикатор преобразует ценовые ряды в логарифмический масштаб, что делает процентные изменения сопоставимыми на разных уровнях цены. Диапазон значений не ограничен сверху, но входные данные должны быть строго положительными. Предпочтительный таймфрейм зависит от задачи (часто дневной для анализа доходности). Используется для расчета логарифмической доходности и стабилизации волатильности.

## Особенности расчёта индикатора

В отличие от сглаживающих индикаторов, **Ln** не использует исторические данные для усреднения. Преобразование выполняется поэлементно (point-wise), поэтому запаздывание отсутствует. Реализация поддерживает обобщённые числовые типы (`float`, `double`) через интерфейс `IFloatingPointIeee754`.

## Автор - разработчик индикатора

*   **Автор:** Фундаментальная математическая функция (исторически связана с Джоном Непером).
*   **Год:** Не применимо (базовая математика).
*   **Источник:** Стандартные математические библиотеки, интегрированные в TALib.

## Формула расчёта
```math
outReal[i] = ln(inReal[i])
```
*   `ln` — натуральный логарифм (по основанию *e* ≈ 2.718).
*   `inReal[i]` — значение цены или данных в момент *i*.
*   `outReal[i]` — преобразованное значение.

**Пример:** Если `inReal` = 100, то `outReal` ≈ 4.605.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены Close). Должны быть > 0. |
| `inRange` | `Range` | — | Диапазон индексов в `inReal` для обработки. Если не указан — весь массив. |
| `outReal` | `Span<T>` | — | Массив для записи результатов. Длина должна соответствовать ожидаемому объёму. |
| `outRange` | `out Range` | — | Возвращает диапазон валидных индексов в `outReal`. |
| `T` | `struct` | — | Числовой тип (float/double). |

**Возвращаемое значение:** `Core.RetCode` (статус выполнения).  
**Период запаздывания (Lookback):** `LnLookback()` возвращает **0**. Расчёт возможен с первого бара.

## Этапы расчёта

1.  Валидация входного диапазона `inRange`.
2.  Итерация по каждому элементу в пределах диапазона.
3.  Вычисление натурального логарифма для текущего элемента.
4.  Запись результата в `outReal` и формирование `outRange`.
5.  Возврат кода успеха `Success`.

## Интерпретация значений

*   **Значения:** Сами по себе логарифмы цен не имеют прямого торгового смысла.
*   **Индексы:** `outRange` гарантирует, что вы знаете, каким входным данным соответствуют выходные.
*   **Смысл:** Разница между соседними значениями логарифмов (`ln(P_t) - ln(P_{t-1})`) равна процентному изменению цены (логарифмическая доходность).

## Практическое применение

✅ **Для чего использовать**
• Расчет логарифмической доходности для бэк тестирования стратегий.
• Стабилизация дисперсии волатильности в статистических моделях.
• Нормализация данных перед подачей в нейросети или ML-алгоритмы.

💡 **Идеи для стратегий**
1.  **Стационарность:** Используйте разницу `Ln(Close) - Ln(Close[1])` для получения стационарного ряда доходностей.
2.  **Волатильность:** Рассчитывайте стандартное отклонение логарифмических доходностей для оценки риска.
3.  **Сравнение активов:** Логарифмический масштаб позволяет корректно сравнивать рост активов с разной ценой (например, акция $10 и $1000).

⚠️ **Ограничения**
• Не работает с отрицательными числами или нулём (вернёт ошибку или `-inf`).
• Не генерирует прямые сигналы на покупку/продажу без дополнительной логики.

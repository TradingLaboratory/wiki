# Log10 — Логарифм по основанию 10 (LOG10)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Log10** выполняет десятичное логарифмирование входных данных. Это не осциллятор и не имеет фиксированных границ (может принимать отрицательные значения при входных данных < 1). Индикатор используется для нормализации масштаба данных, сжимая экспоненциально растущие ряды (цены, объёмы) в линейную форму. Подходит для любых таймфреймов. Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

Расчёт производится поэлементно без использования скользящих окон или исторических данных. В отличие от классических индикаторов (RSI, MA), здесь отсутствует сглаживание или запаздывание. Преобразование применяется мгновенно к каждому бару в указанном диапазоне.

## Автор - разработчик индикатора

📜 **Автор:** Фундаментальная математическая функция (не является авторским торговым индикатором).
📅 **Год:** Математическая основа заложена Джоном Непером (XVII век), в TALib реализована как стандартная утилита.
📚 **Источник:** Стандартная математическая библиотека .NET / TALib Core.

## Формула расчёта
```math
outReal[i] = log₁₀(inReal[i])
```
**Пояснение:**
*   `inReal[i]` — значение входного ряда (например, цена закрытия) на шаге `i`.
*   `outReal[i]` — результирующее логарифмированное значение.
*   **Пример:** `log₁₀(100) = 2`, `log₁₀(1000) = 3`.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (Close, Volume и т.д.). Должны быть > 0. |
| `inRange` | `Range` | Весь массив | Диапазон индексов входных данных для обработки. |
| `outReal` | `Span<T>` | — | Массив для записи результатов. Длина должна совпадать с диапазоном. |
| `outRange` | `out Range` | — | Возвращает индексы входных данных, для которых расчёт успешен. |
| `RetCode` | `Enum` | — | Код возврата: `Success` или ошибка (например, `OutOfRangeParam`). |

## Результат расчёта

📤 **Вывод:** Массив `outReal` содержит преобразованные значения.
⏱ **Период запаздывания (Lookback):** `Log10Lookback()` всегда возвращает **0**. Валидное значение доступно для первого же элемента входных данных, так как история не требуется.

## Этапы расчёта

1.  **Валидация:** Проверка корректности `inRange` относительно длины `inReal`.
2.  **Итерация:** Цикл по каждому элементу в пределах диапазона.
3.  **Преобразование:** Применение функции `T.Log10()` к текущему значению.
4.  **Запись:** Сохранение результата в `outReal` и установка `outRange`.

## Интерпретация значений

📊 **Значения:** Прямая зависимость от входа. Рост цены в 10 раз увеличивает значение индикатора на 1.
📉 **Диапазоны:** Нет фиксированных уровней перекупленности/перепроданности. Значения зависят от масштаба входных данных.
⚠️ **Важно:** Входные данные должны быть строго положительными (`> 0`), иначе результат будет неопределённым или отрицательным (для дробных чисел).

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных для нейросетей и статистических моделей.
• Построение логарифмических графиков цены вручную.
• Снижение влияния выбросов (экстремальных значений) в волатильных активах.

💡 **Идеи для стратегий**
1.  **Стабилизация волатильности:** Используйте `Log10(Close)` вместо цены для расчёта регрессий.
2.  **Сравнение активов:** Приведение активов с разной ценой (например, BTC и ETH) к сопоставимому масштабу.
3.  **Фильтр объёмов:** Логарифмирование объёмов для выравнивания всплесков ликвидности.

⚠️ **Ограничения**
• Не генерирует торговые сигналы самостоятельно.
• Бесполезен для данных, содержащих ноль или отрицательные значения.
• Требует дополнительной обработки для интерпретации трейдером.

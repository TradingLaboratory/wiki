# Cos — Косинус (Cos)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Cos** применяет тригонометрическую функцию косинуса к каждому значению входного ряда. Это не классический торговый индикатор, а математический оператор для построения custom-моделей. Диапазон значений строго ограничен **[-1, 1]**. Запаздывание (lookback) отсутствует, так как расчёт производится по текущему значению независимо от истории. Используется для циклического анализа или нормализации данных в сложных алгоритмах.

## Особенности расчёта индикатора

Расчёт производится поэлементно без накопления истории. В отличие от сглаживающих индикаторов (EMA, SMA), здесь нет памяти о предыдущих барах. Входные данные должны быть корректны для тригонометрии (обычно радианы), иначе смысл значений теряется.

## Автор - разработчик индикатора

📜 **Стандартная математическая функция** (автор не применим).  
Фундаментальная функция тригонометрии, известная с древности. В контексте TA-Lib реализована как часть библиотеки математических трансформаций.

## Формула расчёта
```math
out[i] = cos(in[i])
```
— `in[i]`: Входное значение (например, цена или фаза цикла).  
— `out[i]`: Результат вычисления косинуса.  
⚠️ **Важно:** В стандартной математике аргумент косинуса подразумевается в **радианах**.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной массив данных (цены, значения осцилляторов) |
| `inRange` | `Range` | — | Диапазон индексов для обработки внутри `inReal` |
| `outReal` | `Span<T>` | — | Выходной массив для записи результатов (валидные значения) |
| `outRange` | `out Range` | — | Возвращает диапазон индексов, где записаны валидные данные |
| `Return` | `RetCode` | — | Код статуса: `Success` или ошибка (например, `OutOfRangeParam`) |

## Результат расчёта

Метод возвращает код состояния (`RetCode`) и заполняет массив `outReal`.  
🔄 **Период запаздывания (Lookback):** `CosLookback()` всегда возвращает **0**. Это означает, что для первого значения не требуется предыдущая история, сигнал доступен мгновенно.

## Этапы расчёта

1. Валидация входного диапазона `inRange`.
2. Итерация по каждому элементу в пределах диапазона.
3. Применение функции `Math.Cos()` к текущему элементу.
4. Запись результата в `outReal` и установка `outRange`.

## Интерпретация значений

📈 **Диапазон:** Значения всегда находятся в интервале от **-1 до 1**.  
📉 **Смысл:** Отражает фазу циклического процесса. Если входные данные — это фаза угла, то выход показывает проекцию на горизонтальную ось. Сами по себе значения не являются сигналами покупки/продажи.

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных к диапазону [-1, 1].  
• Создание собственных циклических индикаторов.  
• Математическое моделирование фаз рынка.

💡 **Идеи для стратегий**
1. **Фазовый анализ:** Преобразование времени или цены в угол -> расчёт Cos для выявления циклов.  
2. **Фильтрация шума:** Комбинация с Sin для создания круговых траекторий цены.  
3. **Custom Oscillator:** Использование как части формулы сложного осциллятора.

⚠️ **Ограничения**
• Бесполезен на raw-ценах без предварительной нормализации в радианы.  
• Не имеет встроенной логики тренда.

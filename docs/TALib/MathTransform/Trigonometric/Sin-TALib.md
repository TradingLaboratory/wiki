# Sin — Синус (Math Transform)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Sin** применяет стандартную тригонометрическую функцию синуса к каждому элементу входного массива. Это не классический торговый индикатор, а математическая утилита для преобразования данных. Значения результата строго ограничены диапазоном **[-1, 1]**. Чаще используется как строительный блок для сложных индикаторов или циклического анализа, чем как самостоятельный сигнал. Предпочтительный таймфрейм зависит от входных данных (обычно требует нормализации цен в радианы).

## Особенности расчёта индикатора

⚡ **Отсутствие запаздывания:** В отличие от скользящих средних, `Sin` не использует исторические данные. Каждый выходной элемент зависит только от текущего входного значения. Это обеспечивает мгновенную реакцию на изменения входного ряда, но не сглаживает шум.

## Автор - разработчик индикатора

📜 **Автор:** Стандартная математическая функция (древнее происхождение).  
**В контексте TALib:** Реализация в библиотеке TALib (оригинальный автор библиотеки — Mario Fortier).  
**Год:** Библиотека TALib опубликована около 2004 года.  
**Источник:** Стандартная математическая библиотека IEEE 754.

## Формула расчёта

```math
outReal[i] = sin(inReal[i])
```
**Пояснение:**
- `inReal[i]` — входное значение (рекомендуется в радианах для корректной тригонометрии).
- `outReal[i]` — результат вычисления синуса.
- **Пример:** Если `inReal[i] = 1.57` (≈π/2), то `outReal[i] ≈ 1.0`.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (цены, углы, нормализованные значения). |
| `inRange` | `Range` | Весь массив | Диапазон индексов во входных данных для обработки. |
| `outReal` | `Span<T>` | — | Массив для записи результатов (значения от -1 до 1). |
| `outRange` | `out Range` | — | Возвращает диапазон валидных данных в `outReal`. |
| `RetCode` | `Core.RetCode` | — | Код состояния: `Success` или ошибка (например, `OutOfRangeParam`). |

## Результат расчёта

- **Период запаздывания (Lookback):** `0` (метод `SinLookback()` возвращает 0).
- **Вывод:** Массив `outReal` содержит преобразованные значения. Поскольку история не требуется, валидные данные начинаются с первого элемента обработанного диапазона.

## Этапы расчёта

1. **Валидация:** Проверка корректности `inRange` относительно длины `inReal`.
2. **Итерация:** Последовательный проход по каждому элементу в указанном диапазоне.
3. **Преобразование:** Применение функции `T.Sin()` к текущему элементу.
4. **Запись:** Сохранение результата в `outReal` и установка `outRange`.

## Интерпретация значений

📈 **Диапазон:** Все значения лежат в интервале **[-1, 1]**.
- **1.0:** Пик синусоиды (максимум).
- **-1.0:** Минимум синусоиды.
- **0.0:** Пересечение средней линии.
**Важно:** Если на вход подаются цены (например, 100, 101), результат будет хаотичным, так как функция ожидает радианы. Входные данные часто требуют предварительной нормализации (например, через фазовый угол).

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных к единому диапазону [-1, 1].
• Создание собственных циклических индикаторов (например, преобразование фазы в амплитуду).
• Математическая обработка рядов перед подачей в нейросети.

💡 **Идеи для стратегий**
1. **Циклический вход:** Использовать `Sin` на выходе индикатора фазы (например, Hilbert Transform) для получения гладкого осциллятора.
2. **Фильтр амплитуды:** Если `Sin(нормализованная_цена) > 0.8`, считать рынок перекупленным.
3. **Комбинирование:** Перемножение `Sin` и `Cos` преобразований для выделения специфических гармоник.

⚠️ **Ограничения**
• Бесполезен на «сырых» ценах без предварительной обработки в радианы.
• Не сглаживает шум, а трансформирует его.
• Не показывает направление тренда напрямую.

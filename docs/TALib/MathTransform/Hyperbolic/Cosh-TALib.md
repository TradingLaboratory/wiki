# Cosh — Гиперболический косинус (Cosh)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

🧮 **Cosh** применяет функцию гиперболического косинуса к каждой точке входного временного ряда. В отличие от классических осцилляторов (RSI, Stochastic), значения индикатора не ограничены сверху и всегда больше или равны 1. 

Индикатор не предназначен для самостоятельной генерации торговых сигналов. Он используется преимущественно для продвинутого математического моделирования, нормализации данных в нейросетях или как составная часть сложных пользовательских формул. Предпочтительный таймфрейм зависит от входных данных, так как функция мгновенно преобразует любое значение.

## Особенности расчёта индикатора

Алгоритм представляет собой поэлементное преобразование без использования исторических данных. Это означает отсутствие запаздывания (lag) относительно входного ряда. Функция работает с любыми числовыми типами, реализующими `IFloatingPointIeee754` (float, double), что обеспечивает высокую точность вычислений.

## Автор - разработчик индикатора

- **Автор:** Стандартная математическая функция (не имеет конкретного автора в контексте трейдинга).
- **Год упоминания:** Определена в рамках гиперболической тригонометрии (XVII–XVIII вв.).
- **Источник:** Фундаментальные труды по математическому анализу (Эйлер, Ламберт). В TALib реализована как утилита для разработчиков.

## Формула расчёта
```math
cosh(x) = (e^x + e^(-x)) / 2
```
**Пояснение переменных:**
- `x` — значение входного ряда (например, цена или нормализованное значение).
- `e` — число Эйлера (~2.71828).
- `cosh(x)` — результирующее значение (всегда ≥ 1).

**Пример:** Если `x = 0`, то `cosh(0) = (1 + 1) / 2 = 1`. Если `x = 2`, то `cosh(2) ≈ 3.76`.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (цены Close, объёмы или данные другого индикатора) |
| `inRange` | `Range` | Весь массив | Диапазон индексов во входном массиве для обработки |
| `outReal` | `Span<T>` | — | Массив для записи результатов преобразования |
| `outRange` | `out Range` | — | Возвращает диапазон валидных индексов в выходном массиве |
| `Return` | `RetCode` | — | Код состояния: `Success` при успехе или ошибка валидации |

**Результат расчёта:**
- **Период запаздывания (Lookback):** `0`. Индикатор не требует исторических данных для начала расчёта.
- **Выходные данные:** Массив `outReal` содержит преобразованные значения, соответствующие входным индексам.

## Этапы расчёта

1. **Валидация:** Проверка корректности входного диапазона `inRange`.
2. **Итерация:** Последовательный проход по каждому элементу входного массива в указанном диапазоне.
3. **Преобразование:** Применение функции `Math.Cosh()` к текущему элементу.
4. **Запись:** Сохранение результата в выходной массив `outReal`.
5. **Финализация:** Установка `outRange` и возврат кода успеха.

## Интерпретация значений

- **Диапазон:** Значения всегда положительны и находятся в интервале `[1, +∞)`.
- **Симметрия:** Функция чётная, `cosh(x) = cosh(-x)`. Отрицательные и положительные входные данные дают одинаковый результат.
- **Рост:** При удалении от нуля функция растёт экспоненциально. Большие отклонения входных данных усиливаются на выходе.

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных перед подачей в модели машинного обучения.
• Создание пользовательских математических формул в составе сложных стратегий.
• Сглаживание отрицательных значений (перевод в положительную область).

💡 **Идеи для стратегий**
1. **Фильтр волатильности:** Применять к нормализованным отклонениям цены для усиления сигналов при сильных движениях.
2. **Комбинированный осциллятор:** Использовать как функцию активации внутри кастомного индикатора на основе нейросети.
3. **Преобразование лог-доходности:** Обработка логарифмических доходностей для приведения к симметричному виду.

⚠️ **Ограничения**
• Не генерирует готовые сигналы покупки/продажи.
• Экспоненциальный рост может искажать масштаб данных при больших входных значениях.
• Бесполезен на сырых ценах без предварительной нормализации.

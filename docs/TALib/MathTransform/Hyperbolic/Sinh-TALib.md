# Sinh — Гиперболический синус (SINH)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование временного ряда

---

## Краткое описание

💡 Применяет функцию гиперболического синуса `sinh(x) = (eˣ - e⁻ˣ) / 2` к каждому элементу входного массива. Не является классическим торговым индикатором — это чисто математическое преобразование, используемое в экспериментальных или проприетарных моделях анализа. Предназначен для нелинейной трансформации ценовых данных или значений других индикаторов с целью выявления скрытых паттернов в специфических алгоритмических стратегиях.

## Формула расчёта
```math
sinh(x) = (e^x - e^{-x}) / 2
```
Где:
- `x` — текущее значение входного ряда (цена, объём, значение индикатора)
- `e` — основание натурального логарифма (~2.71828)

Пример: для `x = 1.0` → `sinh(1.0) ≈ (2.718 - 0.368) / 2 ≈ 1.175`

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд: цены закрытия, объёмы или значения другого индикатора |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для обработки. Если не указан — обрабатывается весь массив |
| `outReal` | `Span<T>` | — | Выходной массив с результатами преобразования. Длина = количеству обработанных элементов |
| `outRange` | `out Range` | — | Диапазон индексов исходных данных, для которых получены валидные значения (обычно совпадает с `inRange`) |

## Результат расчёта

Метод возвращает:
- **`outReal`** — массив значений гиперболического синуса для каждого элемента входного диапазона
- **`outRange`** — диапазон индексов исходных данных, соответствующих выходным значениям (`Start` = начало обработки, `End` = конец массива при успехе)
- **`RetCode`** — код статуса выполнения (`Success` или ошибка)
- **Lookback = 0** — расчёт не требует исторических данных, значение генерируется для каждой точки мгновенно

## Практическое применение

✅ **Для чего использовать**
• Нелинейная нормализация экстремальных значений в проприетарных моделях
• Подготовка данных для нейросетей, требующих специфических функций активации
• Экспериментальные преобразования волатильности для выявления асимметрии движений
• Комбинирование с другими математическими преобразованиями (например, `Cosh`, `Tanh`) в кастомных алгоритмах

💡 **Идеи для стратегий**
1. Трансформация значений индикатора волатильности (например, `StdDev`) через `Sinh` для усиления реакции на экстремальные движения
2. Создание синтетического осциллятора: `Sinh(RSI - 50)` для нелинейного усиления зон перекупленности/перепроданности
3. Фильтрация шума: комбинация `Sinh` + скользящая средняя для сглаживания нелинейно преобразованных данных

⚠️ **Ограничения**
• Не имеет интерпретируемой рыночной логики (в отличие от RSI, MACD)
• Результаты сложно визуализировать и интерпретировать без математической подготовки
• Экспоненциальный рост значений при больших `x` может приводить к переполнению
• Не рекомендуется для самостоятельного использования в ручной торговле

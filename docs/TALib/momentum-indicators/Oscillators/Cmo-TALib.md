# Cmo — Осциллятор импульса Чанде (CMO)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса с нормализацией

---

## Краткое описание
💡 **CMO** (Chande Momentum Oscillator) — осциллятор, измеряющий чистый импульс как разницу между суммой приростов и убытков, нормализованную по их общей сумме. В отличие от RSI, CMO учитывает восходящий и нисходящий импульс в единой формуле, что исключает смещение в положительную область. Значения строго ограничены диапазоном **[-100, +100]**, где 0 — нейтральная зона. Предпочтителен на таймфреймах от H1 до D1 для фильтрации шума краткосрочных колебаний.

## Автор
Разработан **Тушаром Чанде** ([Tushar Chande](chande-tushar.md)) в 1994 году. Впервые описан в журнале *Technical Analysis of Stocks & Commodities* и позже детализирован в книге *«The New Technical Trader»* (в соавторстве с С. Кроли).

## Формула расчёта
```math
CMO = 100 × (ΣGains - ΣLosses) / (ΣGains + ΣLosses)
```
Где:
- `ΣGains` — сумма положительных изменений цен за период (`Close[t] - Close[t-1] > 0`)
- `ΣLosses` — сумма абсолютных значений отрицательных изменений (`|Close[t] - Close[t-1]|` при падении)
- Применяется сглаживание по Уайлдеру (рекурсивное среднее) после начального периода.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inRange` | `Range` | весь массив | Диапазон индексов входных данных для обработки |
| `optInTimePeriod` | `int` | `14` | Период расчёта: уменьшение повышает чувствительность, но усиливает шум; увеличение сглаживает сигналы |
| `outReal` | `Span<T>` | — | Выходной массив со значениями индикатора в диапазоне [-100, +100] |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых получены валидные значения |

## Этапы расчёта
1. Вычислить изменения цены между соседними барами: `Delta = Close[t] - Close[t-1]`
2. Разделить изменения на приросты (`Gains`, если `Delta > 0`) и убытки (`Losses`, модуль `Delta` при `Delta < 0`)
3. Накопить суммы `Gains` и `Losses` за начальный период
4. Применить сглаживание по Уайлдеру: `NewAvg = (PrevAvg × (Period-1) + TodayValue) / Period`
5. Рассчитать CMO по нормализованной формуле для каждого бара после периода запаздывания

## Результат расчёта
- **Выходные значения**: массив `outReal` с числами в диапазоне **[-100, +100]**
- **Период запаздывания**: `lookback = optInTimePeriod` (14 баров при стандартных настройках). В режиме совместимости с MetaStock: `lookback = optInTimePeriod - 1`
- **Интерпретация**: положительные значения — преобладание покупательского импульса, отрицательные — продавецкого; модуль значения отражает силу импульса.

## Интерпретация значений
- **> +50**: сильный бычий импульс (риск перекупленности)
- **< -50**: сильный медвежий импульс (риск перепроданности)
- **Пересечение 0 снизу вверх**: смена медвежьего импульса на бычий (потенциальный сигнал покупки)
- **Пересечение 0 сверху вниз**: смена бычьего импульса на медвежий (потенциальный сигнал продажи)

## Практическое применение
✅ **Для чего использовать**
• Фильтрация ложных пробоев при подтверждении импульса
• Выявление экстремальных зон перекупленности/перепроданности (±50)
• Поиск дивергенций между ценой и импульсом для прогноза разворотов
• Оценка силы текущего тренда (модуль значения > 40 = устойчивый тренд)

💡 **Идеи для стратегий**
1. **Сигнал на пересечении нуля**: покупка при переходе из отрицательной в положительную зону + подтверждение ростом объёмов.
2. **Экстремумы + возврат**: продажа при выходе из зоны > +50 обратно к нулю; покупка при выходе из < -50.
3. **Дивергенция**: рост цены при падающем CMO (медвежья дивергенция) → сигнал на продажу.
4. **Фильтр тренда**: разрешать сделки только в направлении знака CMO (положительный = только лонг).

⚠️ **Ограничения**
• Слабо работает во флэте с частыми пересечениями нуля (ложные сигналы)
• Запаздывает на резких разворотах из-за сглаживания Уайлдера
• Требует подтверждения другими индикаторами (объёмы, трендовые инструменты)

## Сравнение с аналогами
| Критерий | CMO | RSI | Stochastic |
|----------|-----|-----|------------|
| **Диапазон** | [-100, +100] | [0, 100] | [0, 100] |
| **Нейтраль** | 0 | 50 | 50 |
| **Чувствительность** | Средняя | Средняя | Высокая |
| **Смещение** | Нет (симметричный) | Вверх (из-за формулы) | Зависит от настроек |
| **Шум во флэте** | Умеренный | Высокий | Очень высокий |

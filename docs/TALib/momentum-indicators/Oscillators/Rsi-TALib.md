# Rsi — Индекс относительной силы (RSI)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса в диапазоне 0–100

---

## Краткое описание
💡 **RSI (Relative Strength Index)** измеряет скорость и величину ценовых изменений, отражая баланс между покупательским и продавецким давлением. Значения ограничены диапазоном 0–100, что делает его классическим осциллятором. Стандартный период расчёта — 14 баров; на коротких периодах индикатор чувствительнее, но шумнее. Предпочтителен для анализа трендовых рынков на таймфреймах от 15 минут до дневного графика. Основное назначение — выявление зон перекупленности/перепроданности, дивергенций и оценка силы текущего движения.

## Особенности расчёта индикатора
Реализация использует оригинальный метод сглаживания по Уайлдеру: первые значения рассчитываются простым усреднением за период, последующие — экспоненциальным сглаживанием с коэффициентом `(период - 1) / период`. Поддерживается режим совместимости с Metastock (lookback уменьшается на 1 бар) и настраиваемый нестабильный период для повышения точности начальных значений.

## Автор — разработчик индикатора
Уэллс Уайлдер ([Welles Wilder Jr.](wilder-welles.md)), американский инженер и трейдер. Впервые описан в 1978 году в книге *«Новые концепции технической торговли»* («New Concepts in Technical Trading Systems»). Стал одним из самых популярных индикаторов технического анализа благодаря простоте интерпретации и универсальности.

## Формула расчёта
```math
Gain = max(Close_t - Close_{t-1}, 0)
Loss = max(Close_{t-1} - Close_t, 0)

AvgGain = (AvgGain_{prev} × (n - 1) + Gain) / n
AvgLoss = (AvgLoss_{prev} × (n - 1) + Loss) / n

RS = AvgGain / AvgLoss
RSI = 100 - (100 / (1 + RS)) = 100 × (AvgGain / (AvgGain + AvgLoss))
```
**Пояснение переменных:**
- `Gain` — положительное изменение цены за бар
- `Loss` — абсолютное значение отрицательного изменения
- `AvgGain`, `AvgLoss` — сглаженные средние по методу Уайлдера
- `n` — период расчёта (`optInTimePeriod`)
- `RS` — относительная сила (отношение средних приростов к убыткам)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Цены закрытия (`Close`) или другой временной ряд |
| `inRange` | `Range` | весь массив | Диапазон индексов входных данных для обработки |
| `outReal` | `Span<T>` | — | Массив валидных значений RSI (диапазон 0–100) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны значения |
| `optInTimePeriod` | `int` | `14` | Период расчёта. Минимум: 2. Уменьшение повышает чувствительность, но увеличивает шум |

## Этапы расчёта
1. Вычисление приростов (`Gain`) и убытков (`Loss`) между соседними барами
2. Инициализация: простое усреднение `Gain`/`Loss` за первые `n` баров
3. Сглаживание по Уайлдеру: каждое новое значение = `(предыдущее × (n-1) + текущее изменение) / n`
4. Расчёт `RS` как отношения средних приростов к убыткам
5. Преобразование в шкалу 0–100 по финальной формуле

## Результат расчёта
Метод возвращает значения в диапазоне **0–100** через параметр `outReal`. Период запаздывания (lookback):  
`lookback = optInTimePeriod + нестабильный_период`  
(при стандартных настройках и `optInTimePeriod=14` → 14 баров). Первое валидное значение появляется на баре с индексом `lookback`.

## Интерпретация значений
- **> 70** — зона перекупленности, возможен откат
- **< 30** — зона перепроданности, возможен отскок
- **≈ 50** — нейтральная зона, отсутствие явного импульса
- **Дивергенции** (расхождение ценового графика и RSI) часто сигнализируют о развороте тренда

## Практическое применение
✅ **Для чего использовать**
• Поиск точек входа в зонах экстремальных значений (30/70)
• Выявление скрытых дивергенций при обновлении ценовых максимумов/минимумов
• Подтверждение силы тренда: устойчивое нахождение выше 50 — бычий тренд, ниже 50 — медвежий
• Фильтрация ложных пробоев уровней поддержки/сопротивления

💡 **Идеи для стратегий**
1. **Классический вход по зонам**: покупка при выходе из зоны <30 вверх, продажа при выходе из >70 вниз
2. **Дивергенция + пробой**: вход при бычьей дивергенции + пробое локального максимума цены
3. **Центральная линия 50**: покупка при отскоке от 50 вверх в восходящем тренде, продажа при отскоке от 50 вниз в нисходящем
4. **Комбинация с трендовым индикатором**: сигналы RSI учитываются только в направлении основного тренда (например, по скользящей средней)

⚠️ **Ограничения**
• На сильных трендах может долго находиться в зоне перекупленности/перепроданности без разворота
• На флэтах генерирует ложные сигналы из-за частых пересечений уровней 30/70
• Менее эффективен на очень коротких таймфреймах (<5 минут) из-за рыночного шума

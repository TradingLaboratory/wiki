# Cci — Индекс Товарного Канала (CCI)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса на основе типичной цены

---

## Краткое описание
💡 **CCI** (Commodity Channel Index) измеряет отклонение типичной цены от её скользящего среднего, нормализованное относительно среднего абсолютного отклонения. Теоретически не имеет жёстких границ, но ~70–80% значений сосредоточены в диапазоне **[-100, +100]** благодаря коэффициенту 0.015. Значения за пределами этих уровней сигнализируют о сильном импульсе. Универсален для любых таймфреймов, но наиболее эффективен на дневных и 4-часовых графиках при сочетании с трендовыми индикаторами.

## Автор
Дональд Ламберт ([Donald Lambert](lambert-donald.md)), 1980 год. Впервые опубликован в журнале *Commodities* (ныне *Futures Magazine*) для анализа циклических движений товарных рынков.

## Формула расчёта
```text
TP = (High + Low + Close) / 3
SMA = SMA(TP, period)
MeanDev = Σ|TP - SMA| / period
CCI = (TP - SMA) / (0.015 × MeanDev)
```
- **TP** — типичная цена бара  
- **SMA** — простое скользящее среднее типичной цены за период  
- **MeanDev** — среднее абсолютное отклонение от SMA  
- **0.015** — нормализующий коэффициент (подобран эмпирически для удержания 70–80% значений в [-100, +100])

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Максимальные цены (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Минимальные цены (Low) |
| `inClose` | `ReadOnlySpan<T>` | — | Цены закрытия (Close) |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных (опционально) |
| `optInTimePeriod` | `int` | `14` | Период расчёта: уменьшение повышает чувствительность (но добавляет шум), увеличение сглаживает сигналы |

## Результат расчёта
- **`outReal`** — массив значений CCI, где каждый элемент отражает силу и направление импульса относительно среднего уровня.
- **Lookback period**: `optInTimePeriod - 1` (для периода 14 → 13 баров). Первое валидное значение появляется на 14-м баре.
- **`outRange`** — диапазон индексов исходных данных, для которых рассчитаны валидные значения.

## Практическое применение
✅ **Для чего использовать**
- Выявление экстремальных состояний рынка (>+100 — перекупленность, <-100 — перепроданность)
- Обнаружение дивергенций (расхождение ценового движения и индикатора)
- Подтверждение силы тренда (устойчивое нахождение выше/ниже нуля)
- Фильтрация ложных пробоев при работе в диапазоне

💡 **Идеи для стратегий**
1. **Пробой зон экстремумов**: вход при выходе CCI из зоны [-100, +100] с возвратом внутрь (подтверждение разворота).
2. **Нулевая линия как фильтр**: длинные позиции только при CCI > 0 в восходящем тренде (по скользящей средней).
3. **Дивергенция + объём**: бычья дивергенция при росте объёмов → сигнал на покупку.
4. **Циклический отскок**: на 15-минутном таймфрейме вход при пересечении -100 снизу вверх во время коррекции в тренде.

⚠️ **Ограничения**
- Даёт ложные сигналы во флэте при частых пересечениях ±100
- Чувствителен к всплескам волатильности («шум» на младших ТФ)
- Требует подтверждения трендовыми индикаторами для фильтрации ложных пробоев

## Сравнение с аналогами
| Индикатор | Тип цены | Границы | Сглаживание | Чувствительность |
|-----------|----------|---------|-------------|------------------|
| **CCI** | Типичная (H+L+C)/3 | Условные (±100) | Среднее отклонение | Высокая |
| **RSI** | Close | Жёсткие (0–100) | Экспоненциальное | Средняя |
| **Stochastic** | Close | Жёсткие (0–100) | Двойное сглаживание | Очень высокая |

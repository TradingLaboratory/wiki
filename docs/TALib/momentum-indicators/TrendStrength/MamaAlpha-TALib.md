# MamaAlpha — Коэффициент адаптивности MAMA (MESA Adaptive Moving Average)

**Категория:** `CycleIndicators` • **Тип:** Адаптивный коэффициент

---

## Краткое описание

💡 **MamaAlpha** вычисляет динамический коэффициент сглаживания (Alpha), используемый внутри индикатора **MAMA**. Он измеряет скорость изменения фазы рыночного цикла, определяя, насколько быстро скользящее среднее должно реагировать на цену. Значения находятся в диапазоне [`optInSlowLimit`, `optInFastLimit`]. Не является самостоятельным осциллятором, а служит параметром адаптивности. Предназначен для выделения трендовых фаз рынка.

## Особенности расчёта индикатора

В отличие от классических скользящих средних с фиксированным периодом, `MamaAlpha` использует **преобразование Хилберта** для оценки доминирующего цикла рынка в реальном времени. Коэффициент меняется на каждом баре, обеспечивая минимальное запаздывание на тренде и максимальное сглаживание во флэте.

## Автор - разработчик индикатора

- **John F. Ehlers** (Джон Ф. Эрлерс)
- Впервые упомянут в конце 1990-х — начале 2000-х годов.
- Источник: Концепция **MESA** (Maximum Entropy Spectral Analysis), описана в книге *"Cybernetic Analysis for Stocks and Futures"* (2004).

## Формула расчёта
```csharp
DeltaPhase = prevPhase - currentPhase
if (DeltaPhase > 1) 
    Alpha = FastLimit / DeltaPhase
else 
    Alpha = FastLimit

// Ограничение снизу
if (Alpha < SlowLimit) 
    Alpha = SlowLimit
```
**Пояснение:**  
- `DeltaPhase` — разница фаз цикла (скорость изменения).  
- `FastLimit` — максимальная скорость реакции (по умолчанию 0.5).  
- `SlowLimit` — минимальная скорость реакции (по умолчанию 0.05).  
- `Alpha` — итоговый коэффициент сглаживания.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены **Close**). |
| `inRange` | `Range` | — | Диапазон индексов входных данных для обработки. |
| `outAlpha` | `Span<T>` | — | Массив для записи рассчитанных значений Alpha. |
| `outRange` | `out Range` | — | Возвращает диапазон валидных значений в `outAlpha`. |
| `optInFastLimit` | `double` | `0.5` | Верхняя граница Alpha. Уменьшение снижает чувствительность к тренду. |
| `optInSlowLimit` | `double` | `0.05` | Нижняя граница Alpha. Увеличение уменьшает сглаживание во флэте. |

**Период запаздывания (Lookback):**  
Вычисляется через `MamaAlphaLookback()`. Требуется достаточное количество баров для стабилизации преобразования Хилберта (аналогично основному индикатору MAMA).

## Этапы расчёта

1. **Сглаживание:** Входная цена обрабатывается взвешенным скользящим средним (WMA).  
2. **Преобразование Хилберта:** Вычисляются квадратурные компоненты (I, Q) для оценки фазы.  
3. **Расчёт фазы:** Определяется текущая фаза цикла и разница фаз (`DeltaPhase`).  
4. **Адаптация:** Вычисляется `Alpha` на основе `DeltaPhase` и лимитов.  
5. **Ограничение:** Значение `Alpha` приводится к диапазону [`SlowLimit`, `FastLimit`].

## Интерпретация значений

- **Высокий Alpha (ближе к FastLimit):** Рынок в тренде, фаза меняется быстро. Индикатор должен реагировать мгновенно.  
- **Низкий Alpha (ближе к SlowLimit):** Рынок в цикле/флэте, фаза стабильна. Требуется сильное сглаживание шума.  
- **Диапазон:** Значения всегда ограничены параметрами `optInFastLimit` и `optInSlowLimit`.

## Практическое применение

✅ **Для чего использовать**  
• Построение собственных адаптивных скользящих средних.  
• Фильтрация рыночного шума в торговых системах.  
• Определение силы тренда через скорость адаптации.  

💡 **Идеи для стратегий**  
1. **Переключение режимов:** Если `Alpha > 0.3` — торговля по тренду, если `< 0.1` — диапазонная торговля.  
2. **Динамический стоп:** Использовать значение Alpha для настройки ширины трейлинг-стопа.  
3. **Фильтр входа:** Открывать позиции только когда Alpha растет (ускорение тренда).  

⚠️ **Ограничения**  
• Не генерирует прямые сигналы покупки/продажи.  
• Требует настройки лимитов под конкретный актив.  
• Может запаздывать на резких новостных импульсах из-за фазы расчёта цикла.

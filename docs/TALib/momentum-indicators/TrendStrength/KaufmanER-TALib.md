# KaufmanER — Коэффициент эффективности Кауфмана (ER)

**Категория:** `MomentumIndicators` • **Тип:** Индикатор эффективности тренда

---
## Краткое описание

Коэффициент эффективности (Efficiency Ratio — ER) оценивает отношение полезного движения цены к общему шуму (волатильности) за период. 📈 Значения индикатора находятся в диапазоне от **0 до 1**. Не является осциллятором в классическом смысле, но имеет жесткие границы. Подходит для любых таймфреймов. Измеряет **эффективность тренда** (направленность vs хаотичность). Возвращает одну коллекцию значений (`outReal`). Предназначен для фильтрации рыночных режимов. 💡

## Особенности расчёта индикатора

В отличие от адаптивного скользящего среднего (KAMA), ER не использует рекурсивное сглаживание. Это «сырой» коэффициент, рассчитываемый напрямую через отношение чистого изменения цены к сумме абсолютных изменений. Это делает его более отзывчивым, но потенциально более шумным без дополнительной фильтрации.

## Формула расчёта

```math
ER = |Price[i] - Price[i-n]| / Σ(|Price[j] - Price[j-1]|)
```
**Где:**
- `n` — период (`optInTimePeriod`)
- `|Price[i] - Price[i-n]|` — чистое изменение цены за период (числитель)
- `Σ(...)` — сумма абсолютных изменений цен за каждый шаг периода (знаменатель)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (обычно цены Close) |
| `inRange` | `Range` | — | Диапазон индексов входных данных для обработки |
| `optInTimePeriod` | `int` | `30` | Период расчёта. Минимум 2. Больше = сглаживание, меньше = чувствительность |
| `outReal` | `Span<T>` | — | Массив результатов (значения ER от 0 до 1) |
| `outRange` | `out Range` | — | Диапазон валидных индексов во входном массиве |
| `RetCode` | `Core.RetCode` | — | Код возврата (Success или ошибка) |

**Период запаздывания (Lookback):** `optInTimePeriod`.  
Первые `n` баров не имеют валидного значения, так как недостаточно истории для расчёта суммы изменений.

## Этапы расчёта

1. Инициализация суммы абсолютных изменений (волатильности) за период.
2. Вычисление чистого изменения цены (текущая цена минус цена `n` баров назад).
3. Деление чистого изменения на сумму абсолютных изменений.
4. Скользящее обновление суммы для следующего бара (добавление нового, вычитание старого значения).

## Интерпретация значений

- **ER ≈ 1**: Сильный тренд. Цена движется направленно с минимальным шумом. ✅
- **ER ≈ 0**: Флэт (боковик). Высокая волатильность без направления.
- **Индексы**: `outRange` указывает, каким барам входных данных соответствуют значения в `outReal`.

## Практическое применение

✅ **Для чего использовать**
• Фильтрация сигналов: торговать трендовыми стратегиями только при высоком ER.
• Определение режима рынка (тренд vs консолидация).
• Входной параметр для адаптивных индикаторов (например, KAMA).

💡 **Идеи для стратегий**
1. **Фильтр тренда**: Вход в позицию только если ER > 0.5.
2. **Пробой волатильности**: Если ER резко растёт с низких значений — начало тренда.
3. **Адаптация стопов**: Увеличивать стоп-лосс при низком ER (шум), сужать при высоком.

⚠️ **Ограничения**
• Не показывает направление тренда (только эффективность).
• Может давать ложные сигналы на резких новостных всплесках.

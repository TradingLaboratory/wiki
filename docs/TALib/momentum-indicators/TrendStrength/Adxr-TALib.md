# Adxr — Индекс рейтинга среднего направленного движения (ADXR)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор силы тренда (не указывает направление)

---

## Краткое описание
💡 **ADXR** (Average Directional Movement Index Rating) — сглаженная версия индикатора ADX, разработанная для более стабильной оценки силы тренда. Рассчитывается как среднее арифметическое текущего значения ADX и значения ADX, полученного `optInTimePeriod` периодов назад. Как и базовый ADX, является осциллятором в диапазоне 0–100 и измеряет только силу тренда, игнорируя его направление (вверх/вниз). Меньше реагирует на краткосрочные колебания, чем ADX, что делает его предпочтительным для долгосрочного анализа.

## Автор
Разработан **Уэллсом Уайлдером** (Welles Wilder) в 1978 году. Впервые описан в книге *«New Concepts in Technical Trading Systems»*, где представлены основы системы направленного движения (Directional Movement System), включающей индикаторы +DI, -DI, ADX и их модификации.

## Формула расчёта
```math
ADXR[t] = (ADX[t] + ADX[t - n]) / 2
```
Где:
- `ADX[t]` — текущее значение индикатора ADX
- `ADX[t - n]` — значение ADX `n` периодов назад (`n = optInTimePeriod`)
- Результат — усреднённая оценка силы тренда за два периода

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимальных цен (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимальных цен (Low) |
| `inClose` | `ReadOnlySpan<T>` | — | Массив цен закрытия (Close) |
| `inRange` | `Range` | весь массив | Диапазон обрабатываемых данных (начальный/конечный индексы) |
| `optInTimePeriod` | `int` | `14` | Период расчёта: увеличение снижает чувствительность, но повышает стабильность сигнала |
| `outReal` | `Span<T>` | — | Выходной массив со значениями ADXR (только валидные данные) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны значения |

## Результат расчёта
- **Возврат:** `Core.RetCode` — код статуса выполнения (`Success` при успехе)
- **`outReal`:** значения индикатора ADXR в диапазоне 0–100. Чем выше значение — тем сильнее тренд.
- **Lookback period:** `optInTimePeriod + AdxLookback(optInTimePeriod) - 1`. Для периода 14 требуется минимум 37 баров истории для первого валидного значения.
- **Интерпретация:** значения >25 — сильный тренд, <20 — слабый тренд/флэт.

## Практическое применение
✅ **Для чего использовать**
- Фильтрация сигналов входа: разрешать сделки только при ADXR > 25
- Определение фазы рынка: тренд (значения растут) против флэта (значения падают ниже 20)
- Подтверждение разворотов: рост ADXR после периода низких значений сигнализирует об усилении нового тренда
- Сравнение силы трендов на разных таймфреймах

💡 **Идеи для стратегий**
1. **Трендовый фильтр:** открывать позиции по сигналам других индикаторов только при `ADXR > 25`
2. **Выход из тренда:** закрывать позиции при падении ADXR ниже 20 (ослабление тренда)
3. **Дивергенция силы:** цена обновляет максимум, но ADXR формирует более низкий пик — признак ослабления тренда
4. **Мультивременной анализ:** использовать быстрый ADX (период 7) для входа и медленный ADXR (период 28) для подтверждения силы тренда

⚠️ **Ограничения**
- Не указывает направление тренда (требуется комбинация с +DI/-DI или ценовыми паттернами)
- Запаздывает при резких разворотах из-за двойного сглаживания
- Менее эффективен на боковиках с частыми ложными пробоями

## Сравнение с аналогами
| Индикатор | Сглаживание | Запаздывание | Шумоустойчивость | Лучшее применение |
|-----------|-------------|--------------|------------------|-------------------|
| **ADX** | Одинарное | Среднее | Средняя | Краткосрочный анализ силы тренда |
| **ADXR** | Двойное | Высокое | Высокая | Долгосрочное подтверждение тренда |
| **ATR** | Одинарное | Низкое | Средняя | Измерение волатильности (не силы тренда) |

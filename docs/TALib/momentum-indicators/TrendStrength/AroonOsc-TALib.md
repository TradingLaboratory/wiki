# AroonOsc — Осциллятор Арун (Aroon Oscillator)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор силы тренда

---

## Краткое описание
💡 Осциллятор Арун измеряет разницу между компонентами *Aroon Up* и *Aroon Down* для оценки доминирования восходящего или нисходящего тренда. Значения колеблются в диапазоне **[-100, +100]**: положительные — признак восходящего движения, отрицательные — нисходящего. При значениях около нуля рынок находится в боковом диапазоне. В отличие от классических осцилляторов (RSI, Stochastic), Aroon Osc фокусируется не на импульсе цены, а на *времени достижения экстремумов* за заданный период.

## Автор
Разработан **Тушаром Чанде** (Tushar Chande) в **1995 году**. Впервые описан в книге *«Beyond Technical Analysis: How to Develop and Implement a Winning Trading System»* как часть семейства индикаторов Арун для анализа «возраста» тренда.

## Формула расчёта
```text
Aroon Up   = 100 × (Period - DaysSinceHighestHigh) / Period
Aroon Down = 100 × (Period - DaysSinceLowestLow) / Period
Aroon Osc  = Aroon Up - Aroon Down
```
Упрощённая реализация (как в коде):
```text
AroonOsc = (100 / Period) × (highestIdx - lowestIdx)
```
Где:
- `highestIdx` — индекс бара с максимальным **High** в окне периода
- `lowestIdx` — индекс бара с минимальным **Low** в окне периода
- `Period` — входной параметр `optInTimePeriod`

*Пример:* При периоде 14, если максимум достигнут 2 бара назад, а минимум — 10 баров назад:  
Aroon Up = 100 × (14-2)/14 ≈ 85.7, Aroon Down = 100 × (14-10)/14 ≈ 28.6 → Osc = 57.1 (сильный восходящий тренд).

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Массив максимумов цены (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Массив минимумов цены (Low) |
| `inRange` | `Range` | весь массив | Диапазон входных данных для обработки |
| `optInTimePeriod` | `int` | `14` | Период расчёта: чем меньше — выше чувствительность к разворотам, но больше ложных сигналов; стандарт 14–25 периодов |
| `outReal` | `Span<T>` | — | Выходной массив значений осциллятора (диапазон [-100, +100]) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны валидные значения |

## Результат расчёта
- **Выходные данные:** Значения `outReal` в диапазоне **[-100, +100]**. Положительные → восходящий тренд, отрицательные → нисходящий.
- **Lookback period:** `optInTimePeriod` баров. Первое валидное значение появляется на баре с индексом `= optInTimePeriod`.
- **Интерпретация:** Каждый элемент `outReal[i]` соответствует ценовому бару `inHigh[outRange.Start + i]` / `inLow[outRange.Start + i]`.

## Практическое применение
✅ **Для чего использовать**
- Определение силы и направления текущего тренда
- Выявление ослабления тренда (приближение к нулевой линии)
- Фильтрация ложных пробоев в боковиках
- Подтверждение разворотов при пересечении нулевой линии

💡 **Идеи для стратегий**
1. **Трендовый фильтр:** Открывать длинные позиции только при значениях > +20, короткие — при < -20.
2. **Сигнал разворота:** Покупка при пересечении нулевой линии снизу вверх + подтверждение ростом объёмов.
3. **Дивергенция:** Расхождение между ценой (новый максимум) и осциллятором (более низкий максимум) — предупреждение о развороте.
4. **Комбинация с трендовыми индикаторами:** Использовать вместе с скользящими средними — вход в тренд при совпадении направлений.

⚠️ **Ограничения**
- Слабо работает на флэтовых рынках (частые ложные пересечения нуля)
- Запаздывает при резких разворотах из-за зависимости от периода
- Требует подтверждения другими инструментами для надёжных сигналов

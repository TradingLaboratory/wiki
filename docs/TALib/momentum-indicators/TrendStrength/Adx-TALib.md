# Adx — Индекс среднего направленного движения (ADX)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор силы тренда

---

## Краткое описание

💡 **ADX (Average Directional Movement Index)** измеряет силу рыночного тренда без указания его направления. Значения колеблются в диапазоне 0–100: выше 25 указывают на сильный тренд, ниже 20 — на боковое движение или отсутствие тренда. В отличие от +DI/-DI (которые показывают направление), ADX фокусируется исключительно на интенсивности движения. Применяется для фильтрации ложных сигналов в трендовых стратегиях и определения фаз рынка.

## Автор
Разработан **Дж. Уэллсом Уайлдером (J. Welles Wilder Jr)** и впервые описан в книге *«New Concepts In Technical Trading Systems»* (1978 г.). Метод сглаживания Уайлдера (Wilder's Smoothing) является ключевым элементом расчёта.

## Формула расчёта
```text
TR  = max(High - Low, |High - PrevClose|, |Low - PrevClose|)
+DM = High - PrevHigh (если > |Low - PrevLow| и > 0, иначе 0)
-DM = PrevLow - Low (если > |High - PrevHigh| и > 0, иначе 0)

+DI = 100 × (+DM сглаженный) / (TR сглаженный)
-DI = 100 × (-DM сглаженный) / (TR сглаженный)

DX  = 100 × |+DI - -DI| / (+DI + -DI)
ADX = Скользящее среднее DX за период (сглаживание Уайлдера)
```
*Сглаживание Уайлдера: `Сегодня = Вчера - Вчера/N + Сегодняшнее_значение`*

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inHigh` | `ReadOnlySpan<T>` | — | Цены максимумов (High) |
| `inLow` | `ReadOnlySpan<T>` | — | Цены минимумов (Low) |
| `inClose` | `ReadOnlySpan<T>` | — | Цены закрытия (Close) |
| `inRange` | `Range` | весь массив | Диапазон обработки входных данных |
| `optInTimePeriod` | `int` | `14` | Период сглаживания: чем больше — тем сильнее фильтрация шума, но выше запаздывание |
| `outReal` | `Span<T>` | — | Выходной массив значений ADX (только валидные данные) |
| `outRange` | `out Range` | — | Диапазон индексов входных данных, для которых рассчитаны значения |

## Результат расчёта
Метод возвращает массив `outReal` со значениями силы тренда (0–100). Первое валидное значение появляется после периода **lookback = `optInTimePeriod × 2 + unstablePeriod - 1`** (минимум 27 баров при period=14). Выходной диапазон `outRange` указывает, для каких баров входных данных рассчитаны значения.

## Практическое применение
✅ **Для чего использовать**
- Фильтрация сигналов: входить в сделку только при ADX > 25
- Определение фазы рынка: тренд (ADX > 25) vs диапазон (ADX < 20)
- Подтверждение пробоев уровней: рост ADX после пробоя усиливает сигнал
- Выход из трендовых позиций при падении ADX ниже 20

💡 **Идеи для стратегий**
1. **Трендовый фильтр**: покупать при пересечении +DI над -DI **и** ADX > 25; продавать при обратном пересечении с тем же условием по ADX.
2. **Разворот после усталости тренда**: вход против тренда при падении ADX с максимума (>40) ниже 25.
3. **Комбинация с волатильностью**: игнорировать сигналы осцилляторов (RSI, Stochastic), когда ADX < 20.

⚠️ **Ограничения**
- Не показывает направление тренда (требует комбинации с +DI/-DI)
- Запаздывает на разворотах из-за двойного сглаживания
- Может давать ложные сигналы «усиления тренда» в условиях высокой волатильности без чёткого направления

# MacdExt  (Macd, MacdSignal, MacdHist) - Схождение-расхождение скользящих средних с расширенными настройками (MACD)

**Категория:** `MomentumIndicators` • **Тип:** Осциллятор импульса с трендовой составляющей

---

## Краткое описание
Индикатор **MACD** (Moving Average Convergence Divergence — схождение/расхождение скользящих средних) измеряет динамику изменения импульса цены через разницу между быстрой и медленной скользящими средними. В отличие от классической версии, `MacdExt` позволяет независимо задавать тип скользящей средней (SMA, EMA, WMA и др.) для всех трёх компонентов: быстрой линии, медленной линии и сигнальной линии. Индикатор не имеет фиксированных границ значений — линия MACD колеблется вокруг нулевой отметки, гистограмма отражает расстояние между линией MACD и сигнальной линией. Предпочтителен для среднесрочных таймфреймов (H1–D1), но применим на любых периодах. Возвращает три временных ряда: линию MACD, сигнальную линию и гистограмму.

## Автор индикатора
Разработан **Джеральдом Аппелем** ([Gerald Appel](appel-gerald.md)) в конце 1970-х годов. Впервые описан в его работах по техническому анализу фондового рынка. Расширенная версия с настраиваемыми типами скользящих средних реализована в библиотеке TA-Lib как улучшение классического алгоритма.

## Формула расчёта
```math
FastMA = MA(inReal, fastPeriod, fastMAType)
SlowMA = MA(inReal, slowPeriod, slowMAType)
MACD = FastMA - SlowMA
Signal = MA(MACD, signalPeriod, signalMAType)
MACDHist = MACD - Signal
```
**Пояснение:**
- `MA` — скользящая средняя заданного типа (SMA, EMA и др.)
- `FastMA` — быстрая скользящая средняя (обычно 12 периодов)
- `SlowMA` — медленная скользящая средняя (обычно 26 периодов)
- `Signal` — сигнальная линия (обычно 9-периодная средняя от MACD)

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной временной ряд (обычно цены закрытия `Close`) |
| `inRange` | `Range` | весь массив | Диапазон индексов во входных данных для расчёта |
| `optInFastPeriod` | `int` | `12` | Период быстрой скользящей средней. Меньше значение → выше чувствительность, больше шум |
| `optInFastMAType` | `MAType` | `Sma` | Тип скользящей средней для быстрой линии (EMA делает индикатор реактивнее) |
| `optInSlowPeriod` | `int` | `26` | Период медленной скользящей средней. Должен быть больше `fastPeriod` |
| `optInSlowMAType` | `MAType` | `Sma` | Тип скользящей средней для медленной линии |
| `optInSignalPeriod` | `int` | `9` | Период сигнальной линии. Управляет сглаживанием гистограммы |
| `optInSignalMAType` | `MAType` | `Sma` | Тип скользящей средней для сигнальной линии |

## Этапы расчёта
1. Рассчитывается медленная скользящая средняя (`SlowMA`) на расширенном диапазоне данных (с учётом будущего расчёта сигнальной линии)
2. Рассчитывается быстрая скользящая средняя (`FastMA`) на том же диапазоне
3. Линия `MACD` = разница `FastMA - SlowMA`
4. Сигнальная линия `Signal` = скользящая средняя от линии `MACD`
5. Гистограмма `MACDHist` = разница `MACD - Signal`

## Результат расчёта
Метод возвращает три выходных массива одинаковой длины:
- `outMACD` — значения линии MACD (разница быстрой и медленной средних)
- `outMACDSignal` — значения сигнальной линии
- `outMACDHist` — значения гистограммы (расстояние между линией и сигналом)

**Период запаздывания (lookback):**  
`lookback = max(MaLookback(fast), MaLookback(slow)) + MaLookback(signal)`  
Например, при стандартных настройках (12/26/9 с EMA): ~33 бара. Первое валидное значение появится только после накопления этого количества баров.

## Интерпретация значений
- **Линия MACD выше нуля** — бычий импульс (быстрая средняя выше медленной)
- **Линия MACD ниже нуля** — медвежий импульс
- **Гистограмма растёт** — ускорение импульса в текущем направлении
- **Гистограмма сжимается к нулю** — ослабление импульса, возможный разворот
- **Пересечение линий** — кросс: бычий (MACD → Signal снизу вверх), медвежий (сверху вниз)

## Практическое применение
✅ **Для чего использовать**
- Выявление смены импульса до разворота цены
- Фильтрация ложных пробоев трендовых уровней
- Подтверждение силы тренда через положение относительно нулевой линии
- Оценка дивергенций (расхождений между ценой и индикатором)

💡 **Идеи для стратегий**
1. **Классический кросс:** покупка при пересечении MACD сигнальной линии снизу вверх + подтверждение выше нулевой линии
2. **Дивергенция:** поиск медвежьей дивергенции (цена → новый максимум, MACD → более низкий максимум) для входа в шорт
3. **Гистограммный импульс:** вход при первом столбце гистограммы, выросшем после серии сжатых значений
4. **Адаптивная настройка:** использование EMA для быстрой линии и SMA для сигнальной — повышает реактивность при сохранении фильтрации шума

⚠️ **Ограничения**
- Запаздывает в боковиках, генерируя ложные кроссы
- Не оптимален для очень коротких таймфреймов (M1–M5) без дополнительной фильтрации
- Чувствителен к экстремальным всплескам волатильности («шипы»)

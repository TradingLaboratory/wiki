# Floor — Векторное округление вниз (FLOOR)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

🧮 **Floor** — это функция математического преобразования, которая округляет каждое значение входного временного ряда вниз до ближайшего целого числа. Индикатор не является осциллятором и не имеет фиксированных границ значений (диапазон зависит от входных данных). 

Предназначен для предварительной обработки данных, нормализации или дискретизации непрерывных величин. Не генерирует прямых торговых сигналов, но полезен при разработке пользовательских алгоритмов. Работает на любом таймфрейме, так как оперирует исключительно значениями данных, а не временем. Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

В отличие от классических торговых индикаторов, `Floor` не использует скользящие средние или периоды сглаживания. Это детерминированная математическая операция над каждым элементом массива независимо от соседей. Запаздывание отсутствует полностью.

## Автор - разработчик индикатора

- **Автор:** Стандартная математическая функция (IEEE 754).
- **Год:** Не применимо (фундаментальная операция).
- **Источник:** Реализована в библиотеке TALib как часть группы математических трансформаций.

## Формула расчёта

```math
outReal[i] = ⌊ inReal[i] ⌋
```
**Пояснение:**
- `inReal[i]` — текущее значение входного ряда (цена, объем, значение другого индикатора).
- `⌊ x ⌋` — операция округления вниз до ближайшего целого числа (например, `⌊ 3.9 ⌋ = 3`, `⌊ -2.1 ⌋ = -3`).
- `outReal[i]` — результирующее значение.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (цены Close, High, значения осцилляторов и т.д.) |
| `inRange` | `Range` | Весь массив | Диапазон индексов во входных данных для обработки |
| `outReal` | `Span<T>` | — | Выходной массив для записи рассчитанных значений |
| `outRange` | `out Range` | — | Возвращает диапазон валидных индексов во входных данных |
| `T` | `Type` | `float`/`double` | Числовой тип данных, реализующий `IFloatingPointIeee754` |

**Результат расчёта:**
- Метод возвращает `Core.RetCode` (статус выполнения).
- **Период запаздывания (Lookback):** `0`. Валидное значение доступно сразу для первого элемента входных данных.

## Этапы расчёта

1. Валидация входного диапазона `inRange`.
2. Итерация по каждому элементу входного массива в пределах диапазона.
3. Применение функции округления вниз `T.Floor()` к текущему элементу.
4. Запись результата в выходной массив `outReal`.
5. Установка `outRange` для указания границ валидных данных.

## Интерпретация значений

- **Значения:** Всегда меньше или равны входным данным. Дробная часть отбрасывается в сторону уменьшения.
- **Индексы:** Соответствуют индексам входных данных (сдвиг отсутствует).
- **Использование:** Позволяет привести данные к целочисленному виду, например, для группировки ценовых уровней по целым числам.

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных перед передачей в системы, требующие целочисленных значений.
• Создание ценовых сеток (price grids) на основе целых чисел.
• Устранение мелкого шума в данных ниже единицы измерения.

💡 **Идеи для стратегий**
1. **Фильтр уровней:** Торговля только когда цена пересекает целочисленный уровень (`Floor(Price) != Floor(PrevPrice)`).
2. **Дискретизация объема:** Группировка объемов торгов по целым лотам для анализа кластеров.
3. **Кастомные индикаторы:** Использование как вспомогательной функции внутри сложных формул для приведения типов.

⚠️ **Ограничения**
• Не подходит для прямого анализа тренда или импульса.
• Потеря точности данных (дробная часть исчезает).

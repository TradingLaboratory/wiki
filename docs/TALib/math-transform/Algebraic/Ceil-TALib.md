# Ceil — Векторное округление вверх (CEIL)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование данных

---

## Краткое описание

💡 **Ceil** (от англ. *Ceiling* — потолок) — это функция математического преобразования, которая округляет каждое значение входного временного ряда вверх до ближайшего целого числа. Индикатор не имеет ограничений по диапазону значений (зависит от входных данных) и не является осциллятором.

Предпочтительный таймфрейм — любой, так как операция мгновенная. В отличие от торговых индикаторов (RSI, MACD), **Ceil** не измеряет силу тренда или волатильность. Он предназначен для **предобработки данных** и разработки пользовательских алгоритмов. Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

Алгоритм работает поэлементно без использования исторических данных. Это означает отсутствие запаздывания (lag). В реализации TALib для C# используется обобщённый тип `T`, что позволяет обрабатывать как `float`, так и `double` с высокой точностью.

## Автор - разработчик индикатора

- **Автор:** Стандартная математическая функция (IEEE 754).
- **Год внедрения в TA-Lib:** ~2000 (в составе оригинальной библиотеки Mario Fortier).
- **Источник:** Включена в ядро библиотеки TA-Lib как базовая утилита для математических операций.

## Формула расчёта

```math
out[i] = ⌈in[i]⌉
```
**Пояснение переменных:**
- `in[i]` — значение входного ряда (например, цена) в момент `i`.
- `⌈x⌉` — функция округления вверх до ближайшего целого (например, `⌈10.1⌉ = 11.0`, `⌈10.0⌉ = 10.0`).
- `out[i]` — результирующее значение.

**Пример:** Вход `[10.1, 10.9, 11.0]` → Выход `[11.0, 11.0, 11.0]`.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входной массив данных (Close, High, Volume или др.) |
| `inRange` | `Range` | — | Диапазон индексов в `inReal` для обработки (начало и конец) |
| `outReal` | `Span<T>` | — | Выходной массив для записи результатов округления |
| `outRange` | `out Range` | — | Возвращает диапазон валидных индексов в `inReal`, соответствующих `outReal` |
| `T` | `typeof` | `float/double` | Числовой тип данных, реализующий `IFloatingPointIeee754` |

**Результат расчёта:**
- Метод возвращает `RetCode` (статус выполнения).
- **Период запаздывания (Lookback):** `CeilLookback()` всегда возвращает **0**. Исторические данные не требуются.

## Этапы расчёта

1. Валидация входного диапазона `inRange`.
2. Итерация по каждому элементу `inReal` в пределах диапазона.
3. Применение математической функции округления вверх `T.Ceiling()`.
4. Запись результата в `outReal` и формирование `outRange`.

## Интерпретация значений

📈 **Значения:** Выходные данные всегда представляют собой целые числа (в формате плавающей точки). Дробная часть отбрасывается с увеличением целой части на единицу (если дробная часть > 0).
📈 **Диапазоны:** `outRange` показывает, какие именно входные данные были обработаны. Если данных недостаточно, диапазон будет пустым.

## Практическое применение

✅ **Для чего использовать**
• **Нормализация данных:** Приведение цен к целым шагам (тикам) для бэктестинга.
• **Создание ступенчатых функций:** Преобразование плавных линий в дискретные уровни.
• **Разработка custom-индикаторов:** Как промежуточный этап в сложных математических цепочках.

💡 **Идеи для стратегий**
1. **Фильтрация шума:** Округление волатильности для игнорирования микро-движений цены.
2. **Расчёт лота:** Округление вверх размера позиции до целого числа лотов.
3. **Визуализация:** Построение гистограмм с целочисленными значениями для отчётов.

⚠️ **Ограничения**
• Не генерирует торговые сигналы сам по себе.
• Может искажать данные при использовании на низких таймфреймах без необходимости.

## Сравнение с аналогами

| Критерий | Ceil | Floor | Round |
|----------|------|-------|-------|
| **Направление** | Вверх | Вниз | К ближайшему |
| **Запаздывание** | 0 баров | 0 баров | 0 баров |
| **Шумоустойчивость** | Низкая | Низкая | Средняя |
| **Тип** | Математика | Математика | Математика |
| **Пример (10.1)** | 11.0 | 10.0 | 10.0 |

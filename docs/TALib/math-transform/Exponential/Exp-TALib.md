# Exp — Экспоненциальная функция (EXP)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Exp** вычисляет экспоненту (e^x) для каждого элемента входного временного ряда. Это не классический торговый индикатор, а математическая утилита для нелинейного преобразования данных. Диапазон значений: от 0 до +∞ (всегда положительно). Не имеет предпочтительного таймфрейма. Используется для масштабирования волатильности или создания пользовательских осцилляторов. Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

⚡ Расчёт производится поэлементно без использования предыдущих значений (stateless). В отличие от сглаживающих индикаторов (EMA, SMA), здесь отсутствует накопление ошибки или запаздывание. Преобразование резко усиливает большие положительные значения и сжимает отрицательные в диапазон (0; 1).

## Автор - разработчик индикатора

👤 Стандартная математическая функция (экспонента). Реализация в библиотеке TALib поддерживается сообществом (оригинальная C-версия — Mario Fortier). Впервые стандартизирована в математическом анализе (Эйлер, XVIII век), в контексте TALib доступна с момента создания библиотеки (2000-е годы). Источник: документация TALib и стандарты IEEE 754.

## Формула расчёта

```math
outReal[i] = e^(inReal[i])
```
**Пояснение:**
*   `e` — основание натурального логарифма (~2.71828)
*   `inReal[i]` — текущее значение входного ряда (цена, индикатор)
*   `outReal[i]` — результирующее экспоненциальное значение

**Пример:** Если `inReal` = 1, то `outReal` ≈ 2.718. Если `inReal` = -1, то `outReal` ≈ 0.368.

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (Close, Volume, значения другого индикатора) |
| `inRange` | `Range` | — | Диапазон индексов в `inReal` для обработки (начало и конец) |
| `outReal` | `Span<T>` | — | Буфер для записи результатов (должен быть достаточного размера) |
| `outRange` | `out Range` | — | Возвращает диапазон валидных данных в `outReal` (Start/End) |
| `Return` | `RetCode` | — | Статус выполнения (Success или ошибка параметров) |

## Результат расчёта

📊 Метод возвращает код состояния (`RetCode`). Основной результат записывается в `outReal`. 
*   **Период запаздывания (Lookback):** `ExpLookback()` возвращает **0**. Для расчёта не требуется история, валидное значение доступно сразу для первого элемента.
*   **outRange:** Гарантирует, что `End` соответствует последнему обработанному элементу входа.

## Этапы расчёта

1.  Валидация входного диапазона `inRange` относительно длины `inReal`.
2.  Инициализация переменных цикла и индекса вывода.
3.  Проход по каждому элементу в пределах диапазона.
4.  Применение функции `T.Exp()` к текущему элементу.
5.  Запись результата в `outReal` и формирование `outRange`.

## Интерпретация значений

📈 Значения растут экспоненциально при увеличении входа. 
*   **Отрицательный вход:** Результат в диапазоне (0; 1) — сжатие.
*   **Нулевой вход:** Результат равен 1.
*   **Положительный вход:** Быстрый рост (>1) — усиление амплитуды.
Индексы выходных данных соответствуют индексам входных (с учётом `outRange.Start`).

## Практическое применение

✅ **Для чего использовать**
• Нелинейная нормализация данных перед подачей в нейросеть.
• Моделирование сложных зависимостей волатильности.
• Создание пользовательских математических формул в стратегиях.

💡 **Идеи для стратегий**
1.  **Усиление сигналов:** Применить к осциллятору (например, RSI-50), чтобы усилить отклонения от середины.
2.  **Фильтр волатильности:** Использовать на логарифмических доходах для оценки экспоненциального риска.
3.  **Кастомный вес:** Назначать экспоненциальные веса событиям в зависимости от их силы.

⚠️ **Ограничения**
• Не генерирует готовые сигналы покупки/продажи.
• При больших положительных входах может быстро достичь переполнения типа данных.
• Бесполезна без контекста другой торговой логики.

# Asin — Арксинус (ASIN)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование

---

## Краткое описание

💡 **Asin** применяет функцию арксинуса (обратного синуса) к каждому элементу входного временного ряда. Это не классический торговый индикатор, а математический инструмент для преобразования данных. Входные значения строго ограничены диапазоном **[-1, 1]**, результат возвращается в радианах в диапазоне **[-π/2, π/2]** (примерно от -1.57 до 1.57).

Индикатор не имеет предпочтительного таймфрейма, так как работает с уже подготовленными данными. Используется для нормализации значений или как составная часть сложных формул (например, в циклическом анализе). Возвращает одну коллекцию значений (`outReal`).

## Особенности расчёта индикатора

В отличие от статистических индикаторов, **Asin** не использует скользящие окна или историю. Это поэлементная операция (vectorized operation). Критическая особенность — строгая валидация входа: значения за пределами [-1, 1] математически не определены для реального арксинуса.

## Автор - разработчик индикатора

*   **Автор:** Стандартная математическая функция (не имеет конкретного автора-трейдера).
*   **Год упоминания:** Известна с древности, в программировании стандартизирована в IEEE 754.
*   **Источник:** Реализована в библиотеке TA-Lib (автор библиотеки Mario Fortier) как обёртка над системной математической функцией.

## Формула расчёта

```math
outReal[i] = arcsin(inReal[i])
```
*   `inReal[i]` — входное значение (нормализованное ценами или другим индикатором).
*   `outReal[i]` — угол в радианах.
*   **Пример:** `arcsin(0.5) ≈ 0.5236 радиан` (30 градусов).

## Параметры метода

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (Close, normalized values). **Должны быть в диапазоне [-1, 1]** |
| `inRange` | `Range` | Весь массив | Диапазон индексов во входном массиве для обработки |
| `outReal` | `Span<T>` | — | Массив для записи результатов (радианы) |
| `outRange` | `out Range` | — | Возвращает диапазон валидных данных в выходном массиве |
| `T` | `generic` | `double/float` | Числовой тип, реализующий `IFloatingPointIeee754` |

**Период запаздывания (Lookback):** `AsinLookback()` всегда возвращает **0**. Валидное значение доступно сразу для первого элемента входа.

## Этапы расчёта

1.  Валидация входного диапазона `inRange`.
2.  Итерация по каждому элементу `inReal` в пределах диапазона.
3.  Применение функции `Math.Asin()` к текущему элементу.
4.  Запись результата в `outReal` и формирование `outRange`.

## Интерпретация значений

*   **Диапазон:** Результаты лежат в интервале **[-1.5708, 1.5708]**.
*   **Значение 0:** Входное значение было 0.
*   **Границы:** Приближение к ±1.57 означает, что входное значение близко к ±1.
*   **Индексы:** `outRange` показывает, какие элементы входного массива были успешно обработаны.

## Практическое применение

✅ **Для чего использовать**
• Нормализация данных для нейросетей (приведение к углу).
• Построение собственных циклических индикаторов (фаза волны).
• Преобразование значений других осцилляторов (например, нормализованного RSI) для нелинейного масштабирования.

💡 **Идеи для стратегий**
1.  **Фильтр экстремумов:** Использовать выход Asin как вход для другой функции (например, sin) для проверки циклических свойств.
2.  **Нелинейное масштабирование:** Применять к данным, распределённым по синусоиде, чтобы линейно раскрыть экстремумы.
3.  **Композитный индикатор:** Часть формулы типа `Fisher Transform` (где используется `atan`, но логика схожа).

⚠️ **Ограничения**
• **Критично к входу:** Подача цен (например, 100.5) без нормализации даст некорректный результат (NaN).
• **Не генерирует сигналы:** Сам по себе не показывает покупку/продажу.
• **Шум:** Усиливает шум near границ [-1, 1] из-за крутизны функции арксинуса.

## Сравнение с аналогами
| Критерий | Asin | Atan (Арктангенс) | RSI |
|----------|------|-------------------|-----|
| **Входные данные** | Строго [-1, 1] | Любые числа | Цены (0-100) |
| **Выход** | Радианы [-π/2, π/2] | Радианы [-π/2, π/2] | Индекс 0-100 |
| **Запаздывание** | 0 баров | 0 баров | Зависит от периода |
| **Назначение** | Мат. преобразование | Мат. преобразование | Импульс/Тренд |
| **Шумоустойчивость** | Низкая (без фильтра) | Средняя | Высокая (сглаживание) |

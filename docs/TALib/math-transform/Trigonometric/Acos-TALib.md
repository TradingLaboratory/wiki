# Acos — Арккосинус (ACOS)

**Категория:** `MathTransform` • **Тип:** Математическое преобразование (Тригонометрия)

---

## Краткое описание
💡 **ACos** применяет функцию арккосинуса к каждому элементу входного временного ряда. Это не классический торговый индикатор, а математическая утилита для преобразования данных. Входные значения должны находиться в диапазоне от **-1 до 1**, результат возвращается в радианах от **0 до π**. Не является осциллятором в традиционном понимании и не имеет предпочтительного таймфрейма. Используется для нормализации данных или как часть сложных алгоритмов (например, спектрального анализа).

## Особенности расчёта индикатора
Расчёт производится поэлементно без зависимости от предыдущих значений (stateless). В отличие от сглаживающих индикаторов (EMA, SMA), здесь отсутствует накопление ошибки или запаздывание due to calculation logic. Критически важна валидация входных данных: значения вне диапазона [-1, 1] могут привести к ошибке域 или NaN в зависимости от реализации типа данных.

## Автор - разработчик индикатора
- **Автор:** Фундаментальная математическая функция (не имеет конкретного автора в контексте трейдинга).
- **Год упоминания:** Древняя математика (тригонометрия).
- **Источник:** Стандартные математические библиотеки (System.Math, IEEE 754).

## Формула расчёта
```math
outReal[i] = acos(inReal[i])
```
- `inReal[i]` — входное значение (косинус угла), диапазон [-1, 1].
- `outReal[i]` — выходное значение (угол в радианах), диапазон [0, π].
- **Пример:** `acos(1) = 0`, `acos(0) = π/2`, `acos(-1) = π`.

## Параметры метода
| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|------------------------|----------|
| `inReal` | `ReadOnlySpan<T>` | — | Входные данные (цены, нормализованные значения). **Строго [-1, 1]** |
| `inRange` | `Range` | Весь массив | Диапазон индексов во входном массиве для обработки |
| `outReal` | `Span<T>` | — | Массив для записи результатов (радианы) |
| `outRange` | `out Range` | — | Возвращает диапазон валидных данных в выходном массиве |
| `T` | `IFloatingPointIeee754` | `double`/`float` | Числовой тип данных (должен поддерживать плавающую точку) |

**Период запаздывания (Lookback):** `0` (метод `AcosLookback()`). Первое значение рассчитывается мгновенно для первого элемента входа.

## Этапы расчёта
1. Валидация входного диапазона (`inRange`) относительно длины массива.
2. Инициализация индекса выхода (`outIdx = 0`).
3. Цикл по каждому элементу входа от `startIdx` до `endIdx`.
4. Применение нативной функции `T.Acos()` к текущему элементу.
5. Запись результата в `outReal` и формирование `outRange`.

## Интерпретация значений
📈 **Диапазон:** Выходные значения лежат в пределах `[0, 3.14159...]` (0 до π).
- **Близко к 0:** Входное значение близко к **1**.
- **Близко к π:** Входное значение близко к **-1**.
- **Близко к π/2:** Входное значение близко к **0**.
Индексы выходных данных соответствуют индексам входных данных с учётом `outRange.Start`.

## Практическое применение
✅ **Для чего использовать**
• Нормализация данных перед подачей в нейросети или сложные модели.
• Часть расчётов фазовых индикаторов (например, Hilbert Transform).
• Преобразование корреляционных коэффициентов в углы.

💡 **Идеи для стратегий**
1. **Фильтр корреляции:** Если вход — коэффициент корреляции двух активов, ACos покажет «угол расхождения».
2. **Циклический анализ:** Использование в связке с Sin/Cos для выделения доминирующего цикла.
3. **Ограничитель:** Проверка валидности данных перед другими тригонометрическими операциями.

⚠️ **Ограничения**
• Не генерирует торговые сигналы самостоятельно.
• Требует предварительной нормализации входа в диапазон [-1, 1].
• Бессмысленно применять к «сырым» ценам без масштабирования.

## Сравнение с аналогами
| Критерий | Acos | Sin / Cos | Atan |
|----------|------|-----------|------|
| **Вход** | [-1, 1] | Любое (углы) | Любое |
| **Выход** | [0, π] | [-1, 1] | [-π/2, π/2] |
| **Запаздывание** | 0 | 0 | 0 |
| **Шумоустойчивость** | Низкая (зависит от входа) | Низкая | Средняя |
| **Назначение** | Обратная тригонометрия | Периодические функции | Угол наклона |

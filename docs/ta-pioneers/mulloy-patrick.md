# Patrick G. Mulloy

*Патрик Г. Маллой*

> «Сглаживание данных с меньшим запаздыванием»  
> *«Smoothing Data with Less Lag»*

## Основной вклад

- Разработал концепцию двойного и тройного экспоненциального сглаживания для радикального уменьшения лага в скользящих средних при сохранении фильтрации шума.
- Предложил математически элегантные формулы DEMA и TEMA, которые компенсируют запаздывание за счёт комбинации нескольких уровней экспоненциального сглаживания.
- Показал практическую применимость ускоренных средних в классических индикаторах (например, MACD на основе DEMA даёт меньше, но более качественных сигналов).
- Его подход стал основой для дальнейших разработок адаптивных и фазово-скорректированных индикаторов в техническом анализе.

## Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|----------------------|------------|----------------|
| DEMA | Double Exponential Moving Average<br>Двойная экспоненциальная скользящая средняя | Трекинг тренда с минимальным лагом | 20 |
| TEMA | Triple Exponential Moving Average<br>Тройная экспоненциальная скользящая средняя | Сглаживание с ещё меньшим запаздыванием, чем у DEMA | 20 |

## Предупреждение для программистов

Формула DEMA: `DEMA = 2 × EMA(N) − EMA(EMA(N))` — критически важно вычислять вторую EMA именно от первой EMA, а не от исходных данных. Ошибка в порядке вычислений приводит к некорректным значениям и потере преимущества по лагу. Для TEMA формула: `TEMA = 3×EMA − 3×EMA(EMA) + EMA(EMA(EMA))`.

## Практическое применение в стратегиях

| Задача | Решение через индикаторы Маллоя |
|--------|--------------------------------|
| Снижение ложных сигналов при развороте тренда | Использовать пересечение цены с DEMA вместо SMA/EMA для более раннего входа |
| Фильтрация шума в боковике без потери реактивности | Применять TEMA с периодом 10–15 для сохранения чувствительности к цене |
| Улучшение MACD | Заменить стандартные EMA в MACD на DEMA для получения более чистых дивергенций |
| Динамическая поддержка/сопротивление | Использовать канал на основе DEMA (±1.5×ATR) вместо канала Боллинджера |
| Адаптивный стоп-лосс | Привязывать стоп к TEMA с коротким периодом (7–9) для минимизации просадки |
| Скользящие средние в высокочастотной торговле | Применять DEMA с периодом 5–8 для снижения лага при сохранении сглаживания |

## Философия

- **Лаг и сглаживание — противоречивые свойства**: увеличение периода улучшает фильтрацию шума, но ухудшает реактивность; задача — найти математический компромисс
- **Скорость важнее абсолютной точности**: в трейдинге критична реакция на изменение тренда, даже если цена временно отклоняется от индикатора
- **Простота формулы ≠ простота эффекта**: элегантные математические преобразования (вычитание сглаженных рядов) могут радикально улучшить поведение индикатора

## Кратко для разработчика

```
# Базовые правила использования индикаторов Маллоя

1. ПЕРИОДЫ:
   - Для трендового трейдинга: DEMA(20), TEMA(20)
   - Для скальпинга: DEMA(8), TEMA(10)
   - Не использовать периоды < 5 — теряется смысл сглаживания

2. КОМБИНАЦИИ:
   - Быстрая/медленная система: DEMA(10) + DEMA(30)
   - Фильтр тренда: цена > TEMA(50) → только лонги

3. ОСОБЕННОСТИ:
   - При резких движениях индикатор может «пробиваться» ценой — это нормально
   - Не использовать для оценки перекупленности/перепроданности (нет границ 0–100)
   - Лучше всего работает в трендовых рынках, в боковике — много ложных пробоев

4. ОПТИМИЗАЦИЯ:
   - Коэффициенты (2× и 3×) фиксированы — не изменять
   - Единственный настраиваемый параметр — период исходной EMA
```

# Gerald Appel (1933–2023)  
*Джеральд Аппель*

## Основной вклад
- Создал **MACD (Moving Average Convergence Divergence)** — гибридный индикатор, объединяющий трендовый анализ и осцилляторный подход для выявления импульса, тренда и дивергенций.
- Разработал **PPO (Percentage Price Oscillator)** — нормализованную версию MACD, позволяющую объективно сравнивать силу трендов у активов с разной ценой.
- Внедрил концепцию **гистограммы MACD** как визуального инструмента оценки ускорения/замедления импульса, что упростило интерпретацию сигналов.
- Заложил основы системного подхода к построению стратегий на базе скользящих средних с четкими правилами входа, выхода и фильтрации шума.

## Индикаторы, используемые до сих пор
| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|------------------------|------------|----------------|
| MACD | Moving Average Convergence Divergence<br>Схождение-расхождение скользящих средних | Выявление тренда, импульса, дивергенций, генерация сигналов | 12, 26, 9 |
| PPO | Percentage Price Oscillator<br>Процентный осциллятор цены | Нормализованный анализ импульса для сравнения активов | 12, 26, 9 |
| MACD Histogram | MACD Histogram<br>Гистограмма MACD | Визуализация изменения импульса через разницу линий | 12, 26, 9 |

## Предупреждение для программистов
- **Тип скользящей средней критичен**: для всех индикаторов Аппеля используется **только EMA**. Применение SMA или других типов приведет к искажению сигналов.
- При расчете PPO деление на медленную EMA требует обработки деления на ноль (теоретически возможно для некоторых инструментов).
- Гистограмма MACD = MACD Line − Signal Line. Не путать с гистограммой объема или другими визуализациями.
- Сигнальная линия рассчитывается как EMA от самой линии MACD (не от цены).

## Практическое применение в стратегиях
| Задача | Решение через индикаторы Аппеля |
|--------|----------------------------------|
| Фиксация разворота тренда | Пересечение линии MACD и сигнальной линии: бычий сигнал — снизу вверх, медвежий — сверху вниз |
| Выявление скрытой слабости тренда | Снижение высоты столбиков гистограммы при росте цены (бычья дивергенция) |
| Сравнение силы трендов у разных активов | Анализ значений PPO: более высокое значение = относительно сильнее тренд |
| Фильтрация ложных пробоев в боковике | Торговля только при расположении MACD/PPO выше/ниже нулевой линии в соответствии с направлением |
| Оценка динамики импульса | Увеличение высоты столбиков гистограммы = ускорение движения; уменьшение = замедление |
| Подтверждение пробоя уровня | Сигнал MACD (пересечение линий) в момент пробоя ключевого уровня цены |

## Философия
- **Реагируй, не предсказывай**: Успешная торговля строится на подтвержденных рыночных сигналах, а не на прогнозах. Доверяй цене и индикаторам, а не интуиции.
- **Простота — залог надежности**: Эффективные стратегии основаны на проверенных, понятных механизмах. Избегай избыточной сложности и «переоптимизации».
- **Адаптируй, не игнорируй**: Параметры индикаторов должны учитывать волатильность и специфику актива. Универсальные настройки — миф.

## Кратко для разработчика
```
# Индикаторы Аппеля: ключевые правила для реализации

## MACD
MACD_Line = EMA(12) - EMA(26)
Signal_Line = EMA(9) от MACD_Line
Histogram = MACD_Line - Signal_Line
→ Сигнал: пересечение линий. Дивергенция: расхождение экстремумов цены и индикатора.

## PPO
PPO = ((EMA(12) - EMA(26)) / EMA(26)) * 100
Signal = EMA(9) от PPO
→ Используй для сравнения активов. Сигналы аналогичны MACD, но в %.

## Важно
- ВСЕГДА используй EMA, не SMA.
- Проверяй деление на ноль в PPO (медленная EMA).
- Гистограмма — разница между линиями, а не отдельный расчет.
- Для волатильных активов: рассмотри корректировку периодов (напр., 5, 35, 5).
- Комбинируй с фильтром тренда (например, цена выше/ниже EMA(200)) для снижения ложных сигналов.
```

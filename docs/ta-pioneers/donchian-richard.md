# Richard Donchian (1905–1993)
*Ричард Дончиан*

> «Покупайте на новых максимумах четырёх недель и продавайте на новых минимумах двух недель»  
> *«Buy on four-week new highs and sell on two-week new lows»*

## Основной вклад

- Создал первую в мире систему механического трейдинга на основе ценовых каналов, положив начало дисциплинированной торговле без эмоциональных решений.
- Основал в 1949 году фонд Futures, Inc. — первый публично управляемый фонд фьючерсов, став пионером индустрии управляемых фьючерсов.
- Разработал концепцию «трендового следования» (trend following) как системного подхода, став признанным «отцом трендового следования».
- Внедрил практику еженедельных технических бюллетеней (Commodity Trend Timing, 1960–1979), популяризировав количественный анализ среди розничных трейдеров.

## Предупреждение для программистов

При реализации канала Дончиана критически важно учитывать тип бара для расчёта экстремумов: на дневных графиках используются `High`/`Low`, на тиковых — необходимо агрегировать данные до баров. При расчёте 52-недельного канала на дневном графике период = 260 (5 торговых дней × 52 недели), а не 365. Избегайте перерисовки — значения должны фиксироваться на закрытии бара.

## Практическое применение в стратегиях

| Задача | Решение через индикаторы Дончиана |
|--------|-----------------------------------|
| Определение начала тренда | Пробой верхней линии 20-периодного канала → сигнал на покупку |
| Фильтрация ложных пробоев | Требовать закрытия бара выше верхней линии, а не только касание интрабаром |
| Выход из тренда | Пробой нижней линии 10-периодного канала (половина входного периода) |
| Оценка силы тренда | Расширение ширины канала → рост волатильности и силы движения |
| Долгосрочное позиционирование | Использовать 52-недельный канал для определения макротрендов |
| Фильтрация по времени | Комбинировать 4-недельный вход с 1-недельным подтверждением для избежания «встрясок» |

## Философия

- **Механичность превыше интуиции**: правила должны выполняться автоматически, без эмоциональных исключений
- **Тренд — ваш друг**: прибыль формируется за счёт удержания позиции в устойчивом тренде, а не за счёт частых входов/выходов
- **Диверсификация обязательна**: одновременная торговля множеством инструментов снижает риск и сглаживает результаты

## Кратко для разработчика

```
// Базовые правила системы Дончиана
ВХОД_ЛОНГ  = Цена_закрытия > Highest(High, 20)
ВХОД_ШОРТ = Цена_закрытия < Lowest(Low, 20)
ВЫХОД     = Цена_закрытия < Lowest(Low, 10)  // для лонг-позиции

// Для 52-недельного сканера на дневном графике:
ПЕРИОД = 260  // 5 дней × 52 недели

// Важно: 
// 1. Использовать именно закрытие бара для подтверждения сигнала
// 2. Не комбинировать разные таймфреймы в одном расчёте канала
// 3. Для фильтрации — требовать подтверждения на младшем периоде
```

# George Lane (1921–2011)  
*Джордж Лейн*

> Стохастик измеряет импульс цены.  
> *Stochastics measures the momentum of price.*

## Основной вклад
- Создал стохастический осциллятор — первый широко применяемый осциллятор, нормализующий цену закрытия относительно диапазона максимум/минимум за период, что позволило объективно оценивать рыночный импульс.
- Внедрил концепцию многоуровневой интерпретации: комбинация пересечения линий (%K/%D), зон экстремумов (20/80) и дивергенций как единой системы сигналов.
- Обосновал приоритет цены закрытия как отражения финального баланса сил покупателей и продавцов в баре, повлияв на методологию последующих осцилляторов.
- Сделал осцилляторы доступными для массового применения через публикации и лекции, заложив основу для интеграции в торговые платформы.

## Индикаторы, используемые до сих пор
| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|------------------------|------------|----------------|
| Fast Stochastic | Stochastic Oscillator (Fast)<br>Быстрая стохастика | Измерение текущего импульса: %K — положение цены закрытия в диапазоне периода, %D — сигнальная линия (SMA от %K). | 14 |
| Slow Stochastic | Stochastic Oscillator (Slow)<br>Медленная стохастика | Сглаженная версия (обычно %K сглаживается SMA(3)) для снижения шума и повышения надёжности сигналов. | 14 |

## Предупреждение для программистов
При расчёте %K обязательно обрабатывайте случай, когда `Highest(High, period) == Lowest(Low, period)` (деление на ноль). Рекомендуется возвращать предыдущее значение индикатора или 50. Учитывайте: в исторических реализациях %D рассчитывается как простая скользящая средняя (SMA), но в некоторых платформах может использоваться экспоненциальная (EMA) — уточняйте спецификацию.

## Практическое применение в стратегиях
| Задача | Решение через индикаторы Лейна |
|--------|-------------------------------|
| Фиксация зон перекупленности/перепроданности | Сигнал при выходе из зоны: пересечение уровня 20 снизу вверх (покупка), уровня 80 сверху вниз (продажа). |
| Выявление скрытых разворотов | Бычья дивергенция: цена формирует новый минимум, стохастика — более высокий минимум (сигнал на рост). |
| Фильтрация ложных пробоев | Требовать подтверждения пересечением %K и %D в зоне экстремума (например, пересечение в зоне <20 для покупки). |
| Адаптация к волатильности | На высоковолатильных активах использовать медленную стохастику (сглаживание 3) вместо быстрой. |
| Подтверждение трендовой силы | В восходящем тренде — удержание стохастики выше 50; в нисходящем — ниже 50. |
| Комбинация с трендовыми фильтрами | Торговать сигналы стохастики только в направлении скользящей средней (например, EMA(50)). |

## Философия
- **Цена закрытия — голос рынка**: Отражает окончательное согласие участников за период и несёт больше информации, чем открытие, максимум или минимум.
- **Импульс опережает цену**: Изменение скорости движения цены предвещает разворот раньше, чем сама цена формирует экстремум.
- **Контекст определяет сигнал**: Уровни 20/80 работают иначе в тренде и во флэте — интерпретация требует учёта рыночной структуры.

## Кратко для разработчика
```
// Базовые параметры
k_period = 14   // Период расчёта %K
d_period = 3    // Период сигнальной линии %D (SMA от %K)
slowing = 3     // Сглаживание %K для медленной версии

// Расчёт %K (Fast)
range = highest(high, k_period) - lowest(low, k_period)
%K = (range != 0) ? ((close - lowest(low, k_period)) / range * 100) : prev_%K

// Fast Stochastic
%D_fast = sma(%K, d_period)

// Slow Stochastic
%K_slow = sma(%K, slowing)
%D_slow = sma(%K_slow, d_period)

// Ключевые уровни
OVERSOLD = 20
OVERBOUGHT = 80

// Типовые условия:
// - Покупка: %K пересекает %D снизу вверх И %K < 20
// - Продажа: %K пересекает %D сверху вниз И %K > 80
// - Дивергенция: расхождение экстремумов цены и %K/%D
// Важно: обрабатывать деление на ноль при расчёте %K
```

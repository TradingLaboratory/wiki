# J. Welles Wilder Jr. (1935–2021)  
*Дж. Уэллс Уайлдер-младший*

> «Лучшая торговая система в мире ничего не стоит без дисциплины»  
> *«The best trading system in the world is worthless without discipline»*

## 🔑 Основной вклад

Создал первую систему **стандартизованных количественных индикаторов** с единым математическим подходом. До Уайлдера многие методы теханализа были субъективными или не имели точных правил расчёта. Его новаторство:

- Ввёл единый базовый период **14 баров** для большинства индикаторов
- Разработал формулу **«сглаживания по Уайлдеру»**:  
  `новое = предыдущее + (1 / период) × (текущее − предыдущее)`  
  (отличается от простого скользящего среднего!)
- Задал чёткие правила интерпретации: уровни 30/70 для RSI, 25 для силы тренда по ADX
- Связал индикаторы в единую систему: импульс (RSI) + сила тренда (ADX) + волатильность (ATR)

Его индикаторы стали **стандартом де-факто** — реализованы во всех профессиональных платформах и библиотеках.

## 📊 Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|----------------------|------------|----------------|
| **RSI** | Relative Strength Index<br>Индекс относительной силы | Импульс, зоны перекупленности/перепроданности | 14 |
| **ADX** | Average Directional Index<br>Индекс среднего направленного движения | Сила тренда (не направление!) | 14 |
| **+DI** | Positive Directional Indicator<br>Положительный индикатор направленного движения | Подтверждение восходящего движения | 14 |
| **-DI** | Negative Directional Indicator<br>Отрицательный индикатор направленного движения | Подтверждение нисходящего движения | 14 |
| **ATR** | Average True Range<br>Средний истинный диапазон | Волатильность в пунктах цены | 14 |
| **SAR** | Parabolic SAR<br>Параболическая система «стоп и разворот» | Динамические точки разворота, траллинг-стоп | 0.02 / 0.2 |

> ⚠️ **Важно для программистов:** При реализации используйте именно **Wilder's Smoothing**, а не SMA или EMA. Иначе значения будут отличаться от эталонных (как в MetaTrader, TradingView).

## ⚙️ Практическое применение в стратегиях

| Задача                | Решение с индикаторами Уайлдера                                                                                         |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Фильтр силы тренда    | Входить только при **ADX(14) > 25**. При ADX < 20 — избегать трендовых стратегий (рынок во флэте).                      |
| Адаптивный стоп-лосс  | `Стоп = Цена входа ± 2 × ATR(14)`. Ширина стопа масштабируется под текущую волатильность.                               |
| Фильтр ложных пробоев | Комбинация: `+DI > -DI` **И** `ADX > 25` → подтверждённый восходящий тренд.                                             |
| Выход по тренду       | Использовать **Parabolic SAR** как динамический траллинг: выход при пробое точки SAR.                                   |
| Торговля в диапазоне  | При `ADX < 20` использовать **RSI**: покупать при пересечении 30 снизу вверх, продавать при пересечении 70 сверху вниз. |
| Расчёт размера позиции| **Размер = (Риск в деньгах) / (ATR × стоимость пункта)**. При высокой волатильности позиция автоматически уменьшается.  |

> 💡 Уайлдер одним из первых связал **управление капиталом с волатильностью**. Его принцип: «Рискуйте фиксированной суммой в деньгах, а не в процентах от цены». Это защищает капитал в периоды высокой волатильности.

## 💎 Философия

- **Простота побеждает сложность:** «Чем проще система, тем легче следовать ей в периоды убытков».
- **Дисциплина важнее прогноза:** Правила должны выполняться механически, без эмоций.
- **Риск — первое, что считается:** Размер позиции определяется через волатильность (ATR), а не через желаемую прибыль.

```
Если нужно измерить:
• Импульс → RSI(14), уровни 30/70
• Силу тренда → ADX(14), порог 25
• Волатильность → ATR(14), для стопов и позиций
• Направление → +DI / -DI пересечение
• Траллинг → Parabolic SAR

Все индикаторы используют одно сглаживание — проверяйте реализацию!
```

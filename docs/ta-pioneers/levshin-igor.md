# Igor Levshin (1960 - )

*Игорь Левшин*

> «Сила тренда определяется не только направлением цены, но и тем, насколько уверенно покупатели или продавцы контролируют ценовой диапазон внутри бара»  
> *«Trend strength is determined not only by price direction, but by how confidently buyers or sellers control the price range within a single bar»*

## Основной вклад
- Ввёл концепцию **мгновенного измерения баланса сил** без запаздывания (lookback = 0), что позволило оценивать рыночную динамику на уровне отдельного бара
- Предложил **нормализованную формулу** `(Close - Open) / (High - Low)`, устраняющую зависимость от абсолютных ценовых уровней и позволяющую сравнивать силу движения между разными инструментами
- Сфокусировал внимание на **внутрибаровой структуре** как источнике информации, а не только на последовательности цен закрытия
- Создал индикатор, применимый на любом таймфрейме без перепараметризации — принцип «один алгоритм под все условия»

## Предупреждение для программистов
При реализации необходимо обрабатывать ситуацию `High == Low` (нулевой диапазон бара): деление на ноль недопустимо. Стандартное решение — возвращать значение `0.0` для таких баров. Индикатор не требует буферизации исторических данных: первое значение рассчитывается для первого же бара входной последовательности (`outBegIdx = inStartIdx`).

## Практическое применение в стратегиях
| Задача | Решение через индикаторы автора |
|--------|-------------------------------|
| Фильтрация ложных пробоев | Пробой уровня + BOP < 0.2 → отклонить сигнал как слабый |
| Раннее обнаружение разворота | Дивергенция: цена обновляет минимум, BOP формирует более высокий минимум |
| Оценка силы тренда на коротком ТФ | Устойчивые значения BOP > 0.6 (лонг) или < -0.6 (шорт) подтверждают импульс |
| Торговля в диапазоне | Пересечение нулевой линии BOP как триггер для входа при отсутствии тренда |
| Комбинация с объёмом | Рост объёма + резкий скачок BOP → подтверждение силы движения |
| Адаптация к волатильности | Нормализация через диапазон бара делает индикатор устойчивым к изменению волатильности |

## Философия
- **Микроструктура важнее макродвижения**: сила тренда проявляется в деталях каждого бара, а не только в последовательности цен закрытия
- **Простота без упрощения**: эффективный индикатор должен использовать минимальный набор входных данных без потери информативности
- **Адаптивность через нормализацию**: универсальность достигается не подстройкой параметров, а математической нормализацией сигнала

## Кратко для разработчика
```
// Расчёт BOP для одного бара
double CalculateBOP(double open, double high, double low, double close)
{
    double range = high - low;
    return (range == 0) ? 0.0 : (close - open) / range;
}

// Правила применения:
// 1. Запаздывание = 0 баров — первое значение с индекса 0
// 2. Диапазон значений: [-1.0, +1.0]
// 3. |BOP| > 0.6 — сильное давление стороны
// 4. |BOP| < 0.2 — баланс сил, неопределённость
// 5. Пересечение нуля — смена контроля бара
// 6. На доджи (High≈Low) значения шумные — фильтровать
// 7. Комбинировать с объёмом для подтверждения силы сигнала
```

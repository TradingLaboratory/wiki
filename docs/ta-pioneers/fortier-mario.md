# Mario Fortier (1970s–)

*Марио Фортье*

> «Библиотека создана, чтобы собрать проверенные алгоритмы технического анализа в единую надёжную реализацию для разработчиков»  
> *«The library was created to gather proven technical analysis algorithms into a single reliable implementation for developers»*

## Роль в техническом анализе

Марио Фортье — **разработчик**, а не автор торговых индикаторов. В конце 1990-х годов он создал библиотеку **TA-Lib** (Technical Analysis Library) — эталонную open-source реализацию на языке C более 150 функций технического анализа, изначально разработанных другими исследователями (Уайлдер, Аппель, Элдер, Шредер и др.).

Его вклад — **инженерная систематизация**: превращение разрозненных формул и алгоритмов в единый, математически точный и кроссплатформенный инструмент. TA-Lib стала «концентратом» знаний поколения трейдеров-теоретиков, доступным для программистов без искажений при ручной реализации.

## Почему это важно для разработчиков стратегий

- **Единый стандарт расчётов**: одна и та же функция `TA_RSI()` даёт идентичный результат в Python, C#, Java и нативном C — критично для валидации бэктеста и продакшена
- **Защита от ошибок реализации**: сглаживание Уайлдера, смещения при «прогреве», обработка экстремальных значений — всё реализовано по оригинальным спецификациям
- **Ускорение экспериментов**: вместо недель на отладку формул — часы на комбинирование готовых функций для генерации новых идей
- **Мост между теорией и кодом**: книги Уайлдера «Новые концепции технической торговли» мгновенно превращаются в рабочий код через вызов `TA_ADX()`, `TA_ATR()`

## Предупреждение для программистов

- Функции возвращают `outBegIdx` — индекс первого валидного значения. Первые `период` баров содержат `NaN` (например, для RSI(14) первые 14 значений невалидны)
- Для индикаторов Уайлдера используется специфическое сглаживание `Wilder's Smoothing`, не эквивалентное стандартному EMA — ручная замена формул нарушит логику автора
- Библиотека **не содержит торговых правил** — только расчёт индикаторов. Логику входов/выходов, фильтрацию сигналов разрабатывает трейдер
- В Python-обёртках (`import talib`) требуется предварительная установка нативной библиотеки `libta_lib` — чистый `pip install` часто завершается ошибкой

## Как библиотека генерирует новые идеи

| Подход | Пример через TA-Lib |
|--------|---------------------|
| Комбинирование «несовместимых» индикаторов | `ATR` для позиционирования + `RSI` для тайминга + `ADX` для фильтрации боковика |
| Мультивременной анализ без дублирования кода | Вызов `TA_SMA()` с разными периодами на одном массиве цен для построения иерархии трендов |
| Валидация гипотез за часы | Тестирование 20 вариантов комбинации `MACD` + `Stochastic` вместо недель ручного кодирования |
| Перенос стратегий между платформами | Бэктест в Python (`backtrader`) → продакшен в .NET (TSLab) без пересчёта индикаторов |

## Реализация в торговых платформах

| Платформа | Статус |
|-----------|--------|
| TA-Lib (нативная) | Оригинальная реализация на C |
| Python (`talib`, `TA-Lib`) | Официальные обёртки |
| TSLab | Интеграция через .NET-обёртку |
| MetaTrader 4/5 | Через DLL-импорт нативной библиотеки |
| Wealth-Lab | Встроенная поддержка |
| TradingView | Не используется (собственная реализация индикаторов) |

## Философия проекта

- **Точность формулы = точность торговли**: ошибка в третьем знаке после запятой при расчёте `ATR` может исказить стоп-лосс на сотни пунктов при масштабировании
- **Инструмент, а не оракул**: библиотека даёт числа, а не сигналы — интерпретация остаётся за трейдером
- **Стоя на плечах гигантов**: как писал Ньютон, «если я видел дальше других, то потому, что стоял на плечах гигантов» — TA-Lib систематизирует знания Уайлдера, Аппеля и других, позволяя следующему поколению строить новые стратегии

## Кратко для разработчика

```
// Стандартный паттерн вызова (C API)
TA_RetCode ret = TA_RSI(0, closeSize-1, closeArray, 14,
                        &outBegIdx, &outNbElement, outRSI);

// Правила работы:
// 1. Всегда проверяйте ret == TA_SUCCESS
// 2. outBegIdx = индекс первого валидного значения (обычно = период)
// 3. Не заменяйте формулы «для оптимизации» — нарушите логику автора индикатора
// 4. Для бэктеста: рассчитывайте индикатор один раз на всём массиве, не по барам
// 5. Помните: библиотека даёт данные, а не стратегию — логику входов пишете сами
```

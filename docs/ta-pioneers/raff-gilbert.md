# Gilbert L. Raff (1930s–2010s)

*Гилберт Л. Рафф*

> «Канал линейной регрессии предоставляет точный количественный способ определить ценовой тренд и его границы»  
> *«The regression channel provides a precise quantitative way to define a price trend and its boundaries»*

## Основной вклад

- Разработал **Raff Regression Channel** (1991) — метод построения канала на основе линейной регрессии, где центральная линия представляет равновесную цену, а границы отстоят на расстояние, пропорциональное стандартной ошибке регрессии.
- Впервые систематизировал применение статистической линейной регрессии для определения границ тренда в техническом анализе, заменив субъективные каналы (например, ценовые каналы Шредера) объективным математическим подходом
- Автор книги *«Trading the Regression Channel: Defining and Predicting Stock Price Trends»* (1996) — первого практического руководства по использованию регрессионных каналов в торговле.
- Применил междисциплинарный подход: как кардиолог с образованием в области физики, перенёс статистические методы анализа временных рядов из медицины в финансовые рынки.

## Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|---|---|---|---|
| Linear Regression Channel | Linear Regression Channel<br>Канал линейной регрессии | Определение границ тренда через статистическое отклонение от линии регрессии | 20 / 50 / 100 |
| Raff Regression Channel | Raff Regression Channel<br>Регрессионный канал Раффа | Адаптивный канал с границами, рассчитанными через стандартную ошибку регрессии | 20 |

⚠️
**Важно для программистов:**  
Стандартный Linear Regression Channel строится через среднеквадратичное отклонение (STD) от линии регрессии. Канал Раффа использует **стандартную ошибку регрессии (Standard Error of Estimate)**, которая учитывает количество точек в выборке: `SEE = SQRT(SSE / (n-2))`. Это даёт более узкие границы при коротких периодах и более адаптивное поведение [[116]].

## Практическое применение в стратегиях

| Задача | Решение с индикаторами Раффа |
|---|---|
| Определение силы тренда | Угол наклона линии регрессии: крутой наклон + цена удерживается внутри канала → сильный тренд |
| Поиск точек разворота | Касание верхней/нижней границы канала + расширение канала (увеличение ширины) → возможный разворот |
| Фильтрация ложных пробоев | Пробой границы без подтверждения объёмом + возврат цены внутрь канала в течение 1–2 баров → ложный пробой |
| Адаптивный стоп-лосс | Размещение стопа за внешней границей канала на противоположной стороне от цены |
| Определение флета | Горизонтальная линия регрессии (наклон ≈ 0) + узкий канал → рынок во флэте, избегать трендовых стратегий |
| Подтверждение тренда | Цена последовательно касается верхней границы при восходящем наклоне → подтверждённый восходящий тренд |

## Философия

- **Объективность вместо субъективности:** Границы тренда должны определяться математически, а не «на глаз» — это устраняет эмоциональную составляющую при определении уровней поддержки/сопротивления
- **Статистика как основа:** Рынок следует законам статистики — цена возвращается к линии регрессии (среднему) с вероятностью, обратно пропорциональной отклонению
- **Адаптивность периода:** Длина периода регрессии должна соответствовать временному горизонту торговли — краткосрочные трейдеры используют 20 баров, свинг-трейдеры — 50–100

## Кратко для разработчика

```
Если нужно измерить:
• Тренд → наклон линии регрессии (положительный/отрицательный)
• Границы тренда → ±2× стандартная ошибка регрессии от центральной линии
• Силу тренда → абсолютное значение наклона + ширина канала (узкий = сильный)
• Разворот → касание границы + расширение канала (увеличение ширины)

Важно: стандартная ошибка регрессии ≠ стандартное отклонение.
Формула: SEE = SQRT( Σ(yᵢ - ŷᵢ)² / (n - 2) ), где ŷᵢ — прогноз по регрессии.
```

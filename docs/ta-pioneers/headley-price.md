# Price Headley

*Прайс Хедли*

> «Тренды — это не просто направление цены, это история о том, как рынок реагирует на информацию.»
> *«Trends are not just about price direction; they are a story of how the market reacts to information.»*

## Основной вклад

- **Разработка индикатора Acceleration Bands** — новаторский подход к измерению волатильности через ускорение цены, а не только через стандартное отклонение
- **Систематизация трендового анализа** — создание структурированной методологии для определения и торговли трендами на разных таймфреймах
- **Интеграция волатильности в торговые решения** — продвижение идеи, что волатильность является ключевым фактором для определения точек входа и выхода

## Предупреждение для программистов

При реализации индикатора **Acceleration Bands** важно учитывать следующие нюансы:

- **Формула использует ускорение цены**, а не просто среднее отклонение — верхняя и нижняя полосы рассчитываются через процентное изменение цены относительно скользящей средней
- **Параметр ускорения (ускоритель)** — стандартно 0.01 (1%), но может варьироваться в зависимости от волатильности актива
- **Верхняя полоса** = SMA × (1 + ускоритель × ((максимум - закрытие) / закрытие))
- **Нижняя полоса** = SMA × (1 - ускоритель × ((закрытие - минимум) / закрытие))
- **Пробой полосы** интерпретируется как сильный сигнал тренда, а не просто волатильности

## Практическое применение в стратегиях

| Задача | Решение через индикаторы |
|--------|--------------------------|
| Определение начала тренда | Пробой верхней/нижней полосы Acceleration Bands с подтверждением объемом |
| Фильтрация ложных пробоев | Использование ширины полос как фильтра — узкие полосы предшествуют всплеску волатильности |
| Определение точек разворота | Цена возвращается в диапазон полос после сильного движения |
| Управление рисками | Стоп-лосс размещается за противоположной полосой |
| Подтверждение силы тренда | Расширение полос указывает на растущую волатильность и силу движения |
| Определение бокового рынка | Цена консолидируется внутри полос без пробоев |

## Философия

- **Тренды длятся дольше, чем кажется** — важнее не пытаться предсказать разворот, а следовать устойчивому движению
- **Волатильность — друг трейдера** — она создает возможности, а не просто риск
- **Простота превыше сложности** — эффективные системы основаны на немногих, но проверенных принципах

## Кратко для разработчика

```
// Параметры по умолчанию
period = 20
acceleration = 0.01

// Сигналы
BUY_SIGNAL: цена > верхняя полоса + подтверждение (объем/таймфрейм)
SELL_SIGNAL: цена < нижняя полоса + подтверждение
EXIT_SIGNAL: цена возвращается в диапазон полос

// Фильтры
- Ширина полос < средняя → ожидаем всплеск волатильности
- Ширина полос расширяется → тренд усиливается
- Цена внутри полос → боковое движение

// Риски
- Ложные пробои в низковолатильных активах
- Требуется подтверждение (объем, второй таймфрейм)
```

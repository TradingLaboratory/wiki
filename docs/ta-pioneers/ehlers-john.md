# John F. Ehlers (1933–)

*Джон Ф. Элерс*

> «Истина и наука побеждают невежество и суеверие»  
> *«Truth and science triumph over ignorance and superstition»*

## Основной вклад

- Применил методы цифровой обработки сигналов (DSP) к финансовому анализу, создав математически строгую основу для адаптивных индикаторов вместо эмпирических подходов
- Разработал концепцию измерения доминантного цикла рынка в реальном времени, позволившую индикаторам автоматически подстраиваться под меняющуюся рыночную структуру
- Создал семейство адаптивных скользящих средних (MAMA/FAMA), где период сглаживания динамически изменяется на основе фазового сдвига цены, а не волатильности
- Внёс вклад в теорию спектрального анализа рынка через MESA (Maximum Entropy Spectral Analysis), ставшую стандартом для измерения рыночных циклов

## Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|----------------------|------------|----------------|
| MAMA | MESA Adaptive Moving Average<br>Адаптивная скользящая MESA | Адаптивное сглаживание с динамическим периодом на основе фазы | FastLimit: 0.5 / SlowLimit: 0.05 |
| FAMA | Following Adaptive Moving Average<br>Следящая адаптивная средняя | Сигнальная линия для MAMA, снижающая ложные сигналы | Рассчитывается от MAMA |
| CYCLE | Cyber Cycle<br>Киберцикл | Выделение циклической компоненты из цены, устранение тренда | 10 (альфа) |
| FISHER | Fisher Transform<br>Преобразование Фишера | Нормализация осцилляторов в гауссовское распределение для чётких сигналов | 10 (период преобразования) |
| IFT | Inverse Fisher Transform<br>Обратное преобразование Фишера | Сжатие значений осциллятора в диапазон [-1; +1] для резких сигналов | Применяется к другим индикаторам |
| INSTANTANEOUS | Instantaneous Trendline<br>Мгновенная трендовая линия | Трендовый индикатор с минимальным лагом через фазовую коррекцию | 10 (период) |

## Предупреждение для программистов

При реализации MAMA критически важно корректно вычислять фазу через арктангенс (atan) с учётом квадрантов (atan2). Ошибка в фазовом расчёте приводит к «разрывам» индикатора. Cyber Cycle требует предварительной фильтрации цены через двухполюсный фильтр. Все индикаторы Элерса чувствительны к шуму — на тиковых данных обязательна предварительная фильтрация. Параметры FastLimit/SlowLimit в MAMA ограничивают скорость адаптации: превышение 0.5 вызывает нестабильность.

## Философия

- **Рынок — сигнал, а не случайность**: цена содержит измеримые циклы, которые можно выделить математическими методами, а не интуицией
- **Адаптация важнее оптимизации**: индикатор должен сам подстраиваться под текущие условия, а не требовать постоянной ручной настройки параметров
- **Минимизация лага — ключ к прибыли**: задержка индикатора разрушает прибыльность — все разработки направлены на её сокращение без увеличения шума

## Кратко для разработчика

```
# MAMA core logic
Smooth = (Price + 2*Price[1] + 2*Price[2] + Price[3]) / 6
Detrender = (0.0962*Smooth + 0.5769*Smooth[2] - 0.5769*Smooth[4] - 0.0962*Smooth[6]) * (0.075*Period[1] + 0.54)
Q1 = (0.0962*Detrender + 0.5769*Detrender[2] - 0.5769*Detrender[4] - 0.0962*Detrender[6]) * (0.075*Period[1] + 0.54)
I1 = Detrender[3]
Phase = atan(Q1 / I1) * 360 / (2*π)  # критично: использовать atan2 для квадрантов
DeltaPhase = Phase[1] - Phase
IF DeltaPhase < 1 THEN DeltaPhase = 1
Period = FastLimit / DeltaPhase IF DeltaPhase > FastLimit ELSE SlowLimit / DeltaPhase
Period = clamp(Period, 6, 50)
MAMA = α * Price + (1-α) * MAMA[1]  where α = 2 / (Period + 1)

# Cyber Cycle
α = (cos(2*π/10) + sin(2*π/10) - 1) / cos(2*π/10)
Smooth = (Price + 2*Price[1] + 2*Price[2] + Price[3]) / 6
Cycle = (1 - 0.5*α)^2 * (Smooth - 2*Smooth[1] + Smooth[2]) + 2*(1-α)*Cycle[1] - (1-α)^2*Cycle[2]

# Fisher Transform
X = 0.33 * 2 * (Price - Min(Low,9)) / (Max(High,9) - Min(Low,9)) - 1
X = clamp(X, -0.999, 0.999)
Fisher = 0.5 * log((1+X)/(1-X))

# Правила использования
• Все индикаторы требуют предварительной фильтрации шума (минимум 4-бара сглаживания)
• Период доминантного цикла измеряется в барах, а не в календарных единицах
• FastLimit/SlowLimit в MAMA — границы скорости адаптации, а не периоды
• Fisher Transform применяется ТОЛЬКО к нормализованным данным в диапазоне [-1; +1]
• Избегать использования на инструментах с низкой ликвидностью — шум искажает фазу
```

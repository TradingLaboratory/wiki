# Donald R. Lambert

*Дональд Р. Ламберт*

> «Индекс товарного канала измеряет отклонение текущей цены от средней цены за период, нормализованное относительно волатильности. Это позволяет выявлять экстремальные рыночные условия и циклические повороты»  
> *«The Commodity Channel Index measures the current price level relative to an average price level over a given period of time, normalized for volatility. This allows identification of extreme market conditions and cyclical turns»*

## Основной вклад

- Создал **Индекс товарного канала (CCI)** в 1980 году — первый осциллятор, использующий статистическое отклонение от среднего с нормализацией по среднему абсолютному отклонению вместо стандартного отклонения.
- Ввёл концепцию **условных границ** (±100) вместо жёстких границ 0–100, характерных для других осцилляторов того времени, что позволило индикатору адаптироваться к различным рыночным условиям.
- Разработал методику применения одного индикатора для анализа **циклических трендов** на товарных рынках без привязки к конкретному активу, заложив основы универсального подхода к техническому анализу.
- Предложил коэффициент нормализации **0.015**, эмпирически подобранный для удержания 70–80% значений в диапазоне [-100, +100], что стало стандартом для последующих модификаций индикатора.

## Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|----------------------|------------|----------------|
| CCI | Commodity Channel Index<br>Индекс товарного канала | Выявление экстремальных состояний рынка, дивергенций и силы тренда через отклонение типичной цены от скользящего среднего | 14 |
| CCI (модифицированный) | Modified CCI<br>Модифицированный CCI | Адаптация оригинального индикатора для краткосрочной торговли с изменённым периодом и фильтрацией шума | 6–10 |

## Предупреждение для программистов

При реализации CCI критически важно использовать **среднее абсолютное отклонение (Mean Deviation)**, а не стандартное отклонение (Standard Deviation). Ошибка в выборе типа отклонения приводит к искажению масштаба значений и нарушению свойства «70–80% значений в диапазоне ±100». Коэффициент 0.015 применяется именно к среднему абсолютному отклонению. Для периода 14 первое валидное значение появляется на 14-м баре (lookback = period - 1).

## Практическое применение в стратегиях

| Задача | Решение через индикаторы Ламберта |
|--------|-----------------------------------|
| Фильтрация ложных пробоев в диапазоне | Использовать выход CCI за ±100 как подтверждение силы движения перед входом в позицию |
| Обнаружение разворотов в коррекции тренда | Комбинировать пересечение нулевой линии CCI с трендовым фильтром (например, 200-периодной SMA) |
| Торговля дивергенций на младших ТФ | Применять 6-периодный CCI для выявления бычьих/медвежьих дивергенций с подтверждением по объёмам |
| Определение силы тренда | Устойчивое нахождение CCI выше 0 в восходящем тренде (или ниже 0 в нисходящем) как фильтр для входов по тренду |
| Выход из позиции при ослаблении импульса | Фиксировать прибыль при возврате CCI из зоны экстремумов (>+100 или <-100) обратно в диапазон [-100, +100] |
| Адаптация к волатильности | Использовать динамический период CCI (увеличение при росте волатильности, уменьшение при её снижении) |

## Философия

- **Универсальность через статистику**: Рыночные циклы подчиняются статистическим закономерностям независимо от актива — достаточно измерить отклонение от среднего с нормализацией по текущей волатильности
- **Экстремумы как сигналы**: Ключевые торговые решения принимаются не на средних уровнях, а при выходе цены в экстремальные зоны, где вероятность разворота или продолжения резко возрастает
- **Простота расчёта ≠ простота интерпретации**: Математическая формула должна быть прозрачной для верификации, но торговые правила требуют контекстной адаптации под текущую рыночную структуру

## Кратко для разработчика

```
# Правила использования CCI от Ламберта
1. Базовый период = 14 для дневных графиков; 6–10 для внутридневной торговли
2. Сигналы:
   • Выход выше +100 → перекупленность / сильный восходящий импульс
   • Выход ниже -100 → перепроданность / сильный нисходящий импульс
   • Пересечение 0 снизу вверх → подтверждение восходящего движения
   • Пересечение 0 сверху вниз → подтверждение нисходящего движения
3. Фильтрация:
   • В тренде: игнорировать сигналы против основного направления
   • Во флэте: использовать возврат в диапазон [-100, +100] как подтверждение разворота
4. Lookback period = period - 1 (для периода 14 → 13 баров)
5. Критично: использовать Mean Deviation, а не Standard Deviation в формуле
```

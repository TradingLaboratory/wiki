# Marc Chaikin (род. 1943)
*Марк Чайкин*

> «Объём — это двигатель рынка. Цена показывает, куда движется рынок, а объём — насколько сильно»  
> *"Volume is the engine of the market. Price shows where the market is going, volume shows how strong it is going there"*

## Основной вклад
- Разработал **связку цена‑объём** как основу анализа денежных потоков: закрытие цены в дневном диапазоне умножается на объём для оценки давления покупателей/продавцов [[1]]
- Создал **кумулятивную линию накопления/распределения (ADL)** — первую систему измерения совокупного денежного потока, преодолевшую ограничения индикатора OBV Джо Гранвилла [[52]]
- Ввёл **Chaikin Money Flow (CMF)** — нормализованный показатель за фиксированный период (обычно 21 день), позволяющий сравнивать силу накопления/распределения между разными инструментами [[63]]
- Разработал **многоуровневую систему анализа**: от краткосрочного осциллятора (Chaikin Oscillator) до долгосрочной кумулятивной линии (ADL), что позволяет фильтровать сигналы по временным горизонтам [[21]]

## Индикаторы, используемые до сих пор
| Индикатор | Общепринятое название | Назначение | Базовый период |
|---|---|---|---|
| ADL | Accumulation/Distribution Line<br>Линия накопления/распределения | Кумулятивный денежный поток, подтверждение тренда | — |
| CMF | Chaikin Money Flow<br>Денежный поток Чайкина | Сила накопления/распределения за период | 21 |
| Chaikin Oscillator | Chaikin Oscillator<br>Осциллятор Чайкина | Моментум линии ADL (разница между быстрой и медленной EMA от ADL) | 3 / 10 |
| CLV | Close Location Value<br>Значение положения закрытия | Промежуточный расчёт: где закрылась цена в дневном диапазоне | — |

⚠️ **Важно для программистов**:  
При расчёте ADL используйте формулу `CLV = ((Close – Low) – (High – Close)) / (High – Low)`, затем `Money Flow Volume = CLV × Volume`. CMF = сумма Money Flow Volume за период / сумма объёмов за тот же период. Не путайте ADL (кумулятивная линия) с простым индикатором «A/D» — это разные расчёты.

## Практическое применение в стратегиях
| Задача | Решение с индикаторами Чайкина |
|---|---|
| Подтверждение тренда | Цена растёт + ADL растёт → подтверждённый восходящий тренд. Расхождение (цена растёт, ADL падает) → слабость тренда. |
| Оценка силы движения | CMF > 0 → преобладает накопление; CMF < 0 → преобладает распределение. Значения > +0.25 / < −0.25 указывают на сильное давление. |
| Раннее предупреждение разворота | Расхождение между ценой и CMF за 21 день часто предшествует развороту тренда на 3–5 баров. |
| Фильтр ложных пробоев | Пробой уровня подтверждается только при одновременном росте CMF выше нуля (для бычьего пробоя). |
| Торговля в диапазоне | При боковом движении использовать осциллятор Чайкина: пересечение нулевой линии вверх → сигнал к покупке. |
| Управление размером позиции | Увеличивать позицию при росте CMF в зону > +0.20 (усиление накопления), сокращать при падении ниже −0.10. |

## Философия
- **Объём раскрывает намерения «умных денег»**: закрытие цены ближе к максимуму дневного диапазона при большом объёме — признак накопления институциональными игроками.
- **Расхождения важнее совпадений**: когда цена и денежный поток расходятся, рынок готовится к развороту — это надёжнее любого подтверждения.
- **Многослойный анализ**: краткосрочные осцилляторы для входа, кумулятивные линии для подтверждения тренда, фундаментальные факторы для фильтрации — только комбинация даёт устойчивый результат.

## Кратко для разработчика
```
Измерение денежного потока:
• Кумулятивный тренд → ADL (без периода, накапливается)
• Сила за период → CMF(21), пороги: >0 накопление, <0 распределение
• Моментум потока → Chaikin Oscillator(3,10), пересечение нуля = сигнал
• Расчёт базы → CLV = ((C-L)-(H-C)) / (H-L), затем × объём

Правила использования:
1. Подтверждение тренда: цена и ADL движутся в одну сторону
2. Предупреждение разворота: расхождение цена/ADL или цена/CMF
3. Фильтр входа: пробой + CMF > 0 (быки) или < 0 (медведи)
4. Стоп по объёму: выход при смене знака CMF на противоположный
```

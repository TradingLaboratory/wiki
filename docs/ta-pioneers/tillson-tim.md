# Tim Tillson
*Тим Тилсон*

> «Сглаживание — это не просто уменьшение шума, а поиск оптимального баланса между запаздыванием и ложными сигналами»  
> *«Smoothing is not just about reducing noise, but finding the optimal balance between lag and false signals»*

## Основной вклад

- Разработал индикатор **T3 Moving Average** (1998), который значительно уменьшает запаздывание по сравнению с традиционными скользящими средними при сохранении гладкости линии.
- Внёс концепцию **обобщённого двойного экспоненциального сглаживания (GD — Generalized DEMA)** как основы для построения многоступенчатых сглаживающих фильтров
- Предложил параметр **«volume factor» (v)** для адаптивного контроля степени сглаживания, позволяющий настраивать баланс между отзывчивостью и шумоподавлением
- Применил биномиальные коэффициенты третьей степени для построения композитного индикатора, что обеспечило математически обоснованное улучшение характеристик сглаживания

## Предупреждение для программистов

При реализации T3 важно учитывать:
- Формула требует трёхкратного применения обобщённого DEMA: `T3 = GD(GD(GD(price)))`, где `GD(x) = EMA(x) * (1 + v) - EMA(EMA(x)) * v`
- Параметр `v` (volume factor) должен находиться в диапазоне [0, 1]; типичное значение — 0.7. При `v = 0` T3 вырождается в обычную EMA, при `v = 1` — в DEMA
- Для корректного расчёта требуется минимум `6 × период` баров истории из-за многоступенчатой структуры индикатора
- Некоторые платформы ошибочно реализуют T3 как простую тройную EMA — это нарушает оригинальную формулу Тилсона

| Фильтрация ложных пробоев в боковике | Использовать T3(10) как динамический уровень поддержки/сопротивления: вход в лонг при отскоке цены от T3 снизу |
| Снижение запаздывания при входе в тренд | Комбинировать T3(5) и T3(21): сигнал на покупку при пересечении быстрой линии снизу вверх медленной |

## Философия

- **Баланс важнее экстремумов**: оптимальный индикатор должен находить компромисс между запаздыванием и шумом, а не стремиться к минимизации одного параметра в ущерб другому
- **Математическая строгость**: применение биномиальных коэффициентов и многоступенчатых преобразований обеспечивает предсказуемые свойства индикатора
- **Практическая применимость**: индикатор разрабатывался для реальной торговли, а не как теоретическая конструкция — акцент на снижение ложных сигналов в условиях рыночного шума

## Кратко для разработчика

```
# Параметры T3
period = 10          # базовый период (рекомендуется 5-21)
v = 0.7              # volume factor [0.0 .. 1.0]

# Алгоритм расчёта
def GD(price, period, v):
    ema1 = EMA(price, period)
    ema2 = EMA(ema1, period)
    return ema1 * (1 + v) - ema2 * v

def T3(price, period, v):
    gd1 = GD(price, period, v)
    gd2 = GD(gd1, period, v)
    gd3 = GD(gd2, period, v)
    return gd3

# Практические правила
# 1. Для краткосрочных стратегий: period=5..8, v=0.6..0.7
# 2. Для трендовых фильтров: period=14..21, v=0.7..0.8
# 3. Минимальная глубина истории: 6 * period баров
# 4. Сигнал на покупку: цена пересекает T3 снизу вверх + наклон T3 > 0
# 5. Избегать использования при v > 0.9 — резкое увеличение шума
```

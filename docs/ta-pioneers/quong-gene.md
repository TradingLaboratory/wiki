# Gene Quong (1940 - )

*Джин Куонг*

> «Объём — это подтверждение цены. Без подтверждения объёмом цена может вести к ложным сигналам»  
> *«Volume is the confirmation of price. Without volume confirmation, price can lead to false signals»*

## Основной вклад
- Совместно с Аврумом Судаком (Avrum Soudack) разработал индекс денежного потока (MFI) как модификацию RSI с учётом объёмов, преодолев ключевое ограничение классического осциллятора Уайлдера.
- Внёс концепцию «денежного потока» (money flow) как произведения типичной цены на объём, создав метрику реального давления денег на рынок.
- Предложил методику выявления дивергенций с учётом объёмного подтверждения, повысив надёжность сигналов разворота.
- Работал аналитиком в Shearson Lehman Brothers, применяя объёмный анализ для институциональной торговли в конце 1980-х годов.

## Индикаторы, используемые до сих пор
| Индикатор | Общепринятое название | Назначение | Базовый период |
|-----------|------------------------|------------|----------------|
| MFI | Money Flow Index<br>Индекс денежного потока | Оценка перекупленности/перепроданности с учётом объёмов | 14 |

## Предупреждение для программистов
При реализации MFI критически важно корректно обрабатывать случаи равенства типичных цен (без изменения цены): денежный поток в таких периодах должен приравниваться к нулю, а не относиться к положительному или отрицательному потоку. Ошибка в этой логике искажает расчёт соотношения положительного/отрицательного потока и приводит к систематическому смещению значений индикатора.

## Практическое применение в стратегиях
| Задача | Решение через индикаторы автора |
|--------|--------------------------------|
| Фильтрация ложных пробоев уровней | Игнорировать пробой при отсутствии подтверждения ростом MFI выше 50 (для восходящего движения) |
| Выявление силы тренда | Сравнивать динамику цены и MFI: совпадающий рост = сильный тренд, расхождение = ослабление |
| Торговля на разворотах в диапазоне | Вход при выходе MFI из зоны 20 (лонг) или 80 (шорт) с подтверждением объёмом выше среднего |
| Подтверждение дивергенции | Требовать одновременного формирования ценовой и объёмной дивергенции (падение цены + рост MFI + рост объёма) |
| Определение зоны накопления/распределения | Анализировать устойчивость MFI в диапазоне 40–60 при боковом движении цены как признак баланса сил |
| Фильтрация сигналов в тренде | В восходящем тренде учитывать только сигналы из зоны перепроданности (MFI < 20), игнорируя перекупленность |

## Философия
- Цена без объёма — неподтверждённый сигнал; объём подтверждает намерения крупных участников рынка
- Осцилляторы должны учитывать не только направление движения, но и силу (денежный поток) за этим движением
- Простота расчёта не должна жертвоваться ради сложности — эффективный индикатор строится на минимуме надёжных компонентов (типичная цена + объём)

## Кратко для разработчика
```
# Правила использования MFI от Куонга и Судака
1. Базовый период: 14 баров (минимум 14 для валидного значения)
2. Зоны экстремумов: >80 перекупленность, <20 перепроданность
3. Типичная цена = (High + Low + Close) / 3
4. Денежный поток = Типичная цена × Объём
5. При равенстве типичных цен: денежный поток = 0
6. Дивергенция + выход из зоны 20/80 = сильный сигнал разворота
7. В тренде: игнорировать сигналы против направления основного движения
8. На низколиквидных инструментах применять с осторожностью (искажённые объёмы)
```

# Tushar Chande (1958–)
*Тушар Чанде*

> «Тренд определяется не только направлением цены, но и устойчивостью её движения во времени»  
> *«A trend is defined not just by price direction, but by the persistence of price movement over time»*

## Основной вклад
- Создал семейство **адаптивных индикаторов**, меняющих параметры в зависимости от волатильности рынка (VIDYA, RAVI), что позволило снизить ложные сигналы в условиях меняющейся рыночной динамики.
- Разработал **Арун (Aroon)** — первый индикатор, измеряющий время до достижения экстремумов вместо скорости изменения цены, что дало трейдерам инструмент для оценки «возраста» тренда.
- Ввёл концепцию **симметричного измерения импульса** в CMO, учитывающего как рост, так и падение цены в расчёте, в отличие от асимметричных осцилляторов вроде RSI.
- Совместно с Стэнли Кроллом популяризировал идею **комбинирования индикаторов** (например, StochRSI) для повышения чувствительности сигналов без увеличения шума.

## Предупреждение для программистов
При реализации **VIDYA** критически важно корректно рассчитывать коэффициент α на основе волатильности (обычно через CMO или стандартное отклонение). Ошибка в формуле адаптации превращает индикатор в обычную EMA. Для **Аруна** необходимо точно определять индекс бара с экстремумом внутри окна — ошибка на 1 бар даёт систематическое смещение значений. В **CMO** знаменатель включает сумму абсолютных изменений (не только положительных), что отличает его от RSI.

## Практическое применение в стратегиях
| Задача | Решение через индикаторы Чанде |
|--------|-------------------------------|
| Фильтрация ложных пробоев в боковике | Использовать RAVI: вход в сделку только при значениях > 0.3% (для акций) или > 0.1% (для фьючерсов) |
| Раннее определение зарождения тренда | Сигнал при росте Aroon Up выше 70 одновременно с падением Aroon Down ниже 30 |
| Адаптивный стоп-лосс под текущую волатильность | Расчёт уровня через VIDYA ± 2×ATR(14), где VIDYA заменяет фиксированную SMA |
| Подтверждение разворота при дивергенции | Дивергенция цены + пересечение нулевой линии CMO в противоположную сторону |
| Оценка силы импульса без искажения от предыдущих экстремумов | CMO вместо RSI: симметричный расчёт исключает «затягивание» значений после сильных движений |
| Торговля на основе свечного анализа в автоматизированных системах | QStick > 0 как фильтр для лонговых сделок при подтверждении объёмами |

## Философия
- **Адаптивность важнее фиксированных параметров**: индикатор должен менять чувствительность в ответ на изменение рыночных условий, а не полагаться на универсальные настройки.
- **Время как измерение тренда**: сила движения определяется не только размахом цены, но и продолжительностью устойчивого направления (ключевая идея Аруна).
- **Симметрия в расчётах**: объективная оценка импульса требует учёта как восходящих, так и нисходящих движений без приоритизации одного направления.

## Кратко для разработчика
```
# Арун (Aroon)
period = 14
aroon_up = 100 * (period - bars_since_highest(high, period)) / period
aroon_dn = 100 * (period - bars_since_lowest(low, period)) / period
# Сигнал: пересечение Up > Down + обе линии > 50

# CMO
Su = sum(max(close[i] - close[i-1], 0) for i in range(period))
Sd = sum(max(close[i-1] - close[i], 0) for i in range(period))
cmo = 100 * (Su - Sd) / (Su + Sd)
# Диапазон: [-100, +100], нейтраль: [-10, +10]

# VIDYA
alpha = 2 / (period + 1)
cmo_val = abs(CMO(close, cmo_period))
vidya = vidya_prev + alpha * cmo_val * (close - vidya_prev)
# cmo_period обычно = 9 для расчёта волатильности

# Важно: для всех индикаторов первый валидный бар = период (lookback)
```

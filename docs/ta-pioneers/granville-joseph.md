# Joseph Granville (1923–2013)
*Джозеф Гранвилл*

«Когда объём резко возрастает без существенного изменения цены, цена в конечном итоге быстро пойдёт вверх — и наоборот»  
*«When volume increases sharply without a significant change in price, the price will eventually increase rapidly, and vice versa»*

## Основной вклад

- Впервые систематизировал **связь объёма и цены** как ведущего и ведомого индикатора: объём как «пар под крышкой» предшествует ценовому движению
- Создал индикатор **OBV (On-Balance Volume)** — один из первых количественных инструментов для измерения «умных денег» через накопленный объём
- Разработал **«8 правил Гранвилла»** для анализа взаимодействия цены со скользящими средними, ставших классикой трендового анализа
- Показал практическую ценность **расхождений (дивергенций)** между объёмом и ценой как раннего сигнала разворота тренда

## Индикаторы, используемые до сих пор

| Индикатор | Общепринятое название | Назначение | Базовый период |
|---|---|---|---|
| OBV | On-Balance Volume<br>Энергетический баланс («Энергия») | Накопленный объём для выявления «умных денег» и дивергенций | — |
| MA Rules | Granville's Eight Rules<br>Восемь правил Гранвилла | Сигналы входа/выхода на основе взаимодействия цены и скользящих средних | 30 / 50 / 200 |

⚠️  
**Важно для программистов:**  
Расчёт OBV прост, но критичен для интерпретации:  
`OBV = OBV_пред + объём` при росте цены,  
`OBV = OBV_пред - объём` при падении цены,  
`OBV = OBV_пред` при неизменной цене.  
Для дивергенций сравнивайте **накопленное значение OBV**, а не его производные.

## Практическое применение в стратегиях

| Задача | Решение с индикаторами Гранвилла |
|---|---|
| Раннее выявление разворота | Дивергенция: цена растёт, OBV падает → сигнал ослабления бычьего импульса |
| Подтверждение пробоя | Пробой уровня сопровождается ростом OBV → подтверждённый пробой |
| Фильтр ложных движений | Цена движется без роста объёма (плоский OBV) → движение недостоверно |
| Определение тренда | Цена выше скользящей средней + растущий OBV → подтверждённый восходящий тренд |
| Торговля по скользящим | Применение «8 правил»: вход при пересечении цены через МА с подтверждением объёма |
| Измерение силы движения | Угол наклона линии OBV: крутой рост → сильный приток «умных денег» |

## Философия

- **Объём ведёт, цена следует:** Деньги «умных» участников проявляются в объёме задолго до ценового движения
- **Простота интерпретации:** Чем проще связь между индикаторами, тем надёжнее сигнал в стрессовых условиях рынка
- **Дивергенция как предупреждение:** Расхождение между ценой и объёмом — самый ранний сигнал о смене баланса сил

## Кратко для разработчика торговых стратегий

```
Для анализа объёма:
• Базовый инструмент → OBV (накопленный объём)
• Сигнал разворота → дивергенция цена/OBV
• Подтверждение тренда → совпадающие направления цены и OBV
• Фильтр шума → игнорировать движения без роста объёма

Для работы со скользящими:
• Правила 1-4 → сигналы в восходящем тренде
• Правила 5-8 → сигналы в нисходящем тренде
• Ключевой принцип → цена должна подтверждаться объёмом при пересечении МА
```

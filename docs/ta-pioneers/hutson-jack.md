# Jack K. Hutson

*Джек К. Хатсон*

> «Индикатор содержит два необходимых ингредиента для торговли акциями и товарами: 1) фильтр случайного рыночного шума и 2) своевременный позитивный сигнал»  
> *«It contains two essential ingredients required in stock or commodity trading: 1) A filter of random market noise. AND 2) a positive timely signal»*

## Основной вклад

- Разработал индикатор TRIX (Triple Exponential Smoothing Oscillator) в 1983 году, впервые применив тройное экспоненциальное сглаживание для фильтрации краткосрочных колебаний цен.
- Внёс новаторский подход к анализу импульса: вместо однократного сглаживания использовал трёхкратную фильтрацию для выделения устойчивых трендовых изменений.
- Как издатель и редактор журнала *Technical Analysis of Stocks & Commodities* способствовал популяризации количественных методов и системного подхода к техническому анализу в 1980-х годах.
- Предложил использовать процентное изменение тройного сглаженного ряда (а не сам ряд) как осциллятор, что позволило стандартизировать сигналы независимо от абсолютного уровня цены.

## Предупреждение для программистов

Критическая ошибка при реализации — нарушение порядка операций. Сначала выполняется тройное экспоненциальное сглаживание исходного ценового ряда (три последовательных EMA с одинаковым периодом), только затем рассчитывается процентное изменение (ROC) полученного ряда за 1 период. Применение сглаживания к уже рассчитанному ROC искажает логику индикатора и увеличивает лаг.

## Практическое применение в стратегиях

| Задача | Решение через индикаторы Хатсона |
|--------|----------------------------------|
| Фильтрация ложных пробоев в боковике | Использовать пересечение TRIX нулевой линии как подтверждение смены тренда |
| Раннее обнаружение ослабления импульса | Выявлять дивергенции: цена формирует новый максимум, TRIX — нет |
| Оценка силы текущего тренда | Абсолютное значение TRIX: чем дальше от нуля, тем сильнее импульс |
| Снижение лага при входе в тренд | Комбинировать TRIX с коротким периодом (8–10) для таймфреймов <1H |
| Подтверждение сигналов других индикаторов | Требовать совпадения направления TRIX и MACD/RSI для фильтрации ложных сигналов |
| Автоматизация выхода при развороте | Закрывать позицию при пересечении TRIX нулевой линии в противоположную сторону |

## Философия

- **Фильтрация шума как основа анализа**: эффективный индикатор должен сначала устранить случайные колебания, только затем выявлять сигналы
- **Своевременность превыше точности**: лучше получить сигнал с небольшой погрешностью, но вовремя, чем идеально точный с запаздыванием
- **Простота интерпретации**: осциллятор должен давать однозначные правила (пересечение нуля, дивергенции) без субъективных оценок

## Кратко для разработчика

```
# Расчёт TRIX (псевдокод)
def trix(close, period=14):
    ema1 = EMA(close, period)          # первое сглаживание
    ema2 = EMA(ema1, period)           # второе сглаживание
    ema3 = EMA(ema2, period)           # третье сглаживание
    return (ema3 - ema3.shift(1)) / ema3.shift(1) * 100  # ROC за 1 период

# Правила генерации сигналов:
# • Покупка: TRIX пересекает 0 снизу вверх И выше линии сигнала (EMA(TRIX,9))
# • Продажа: TRIX пересекает 0 сверху вниз И ниже линии сигнала
# • Дивергенция бычья: цена ↓, TRIX ↑ → подготовка к росту
# • Дивергенция медвежья: цена ↑, TRIX ↓ → подготовка к падению
# • Период 14 оптимален для дневных графиков; для внутридневных — 8–10
# • Избегать торговли при |TRIX| < 0.1 (зона неопределённости)
```

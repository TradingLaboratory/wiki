# Краткое руководство по началу работы.

Здесь представлены индикаторы технического анализа.

## Momentum Indicators (Индикаторы импульса)

Индикаторы импульса измеряют **скорость изменения цены** и помогают определить силу движения, перекупленность/перепроданность и развороты тренда. В отличие от трендовых индикаторов (скользящих средних), momentum-индикаторы реагируют быстрее на изменения цены.

### Критерии группировки

#### 1. 📊 Осцилляторы (Oscillators)

**Критерий отнесения:**  
Индикатор колеблется в **фиксированном диапазоне** (0–100, -100–0 и т.п.) и генерирует сигналы при достижении крайних зон.

**Характеристики:**
- Чёткие границы перекупленности/перепроданности
- Сигналы на разворот: выход из зоны перекупленности → продажа, из зоны перепроданности → покупка
- Эффективны во флетовых рынках

**Примеры из TALib:**
```csharp
TA_Rsi.cs       // RSI (0–100): >70 перекупленность, <30 перепроданность
TA_Stoch.cs     // Stochastic (0–100): >80 перекупленность, <20 перепроданность
TA_WillR.cs     // Williams %R (-100–0): >-20 перекупленность, <-80 перепроданность
TA_Cci.cs       // CCI: >+100 перекупленность, <-100 перепроданность
TA_UltOsc.cs    // Ultimate Oscillator (0–100)
TA_StochRsi.cs  // Stochastic RSI (0–100)
TA_Cmo.cs       // Chande Momentum Oscillator (-100–100)
TA_Mfi.cs       // Money Flow Index (0–100)
TA_Bop.cs       // Balance of Power (колеблется вокруг 0)
```

---

#### 2. 📈 Неограниченный импульс (Unbounded Momentum)

**Критерий отнесения:**  
Индикатор **не имеет фиксированных границ** — значения могут расти/падать бесконечно. Измеряет чистую скорость движения цены.

**Характеристики:**
- Нет зон перекупленности/перепроданности
- Сигналы: пересечение нулевой линии, дивергенции, пересечение с сигнальной линией
- Подтверждает силу тренда, но не даёт точек входа по перекупленности

**Примеры из TALib:**
```csharp
TA_MacD.cs      // MACD (разница между двумя EMA)
TA_Macd.cs      // MACD + сигнальная линия + гистограмма
TA_MacDExt.cs   // Расширенный MACD
TA_MacdFix.cs   // MACD с фиксированным периодом
TA_Roc.cs       // Rate of Change (абсолютное изменение цены)
TA_RocP.cs      // Rate of Change (%) — процентное изменение
TA_RocR.cs      // Rate of Change (нормированный)
TA_RocR100.cs   // Rate of Change × 100
TA_Mom.cs       // Momentum (разница цены текущей и N периодов назад)
TA_Ppo.cs       // Percentage Price Oscillator (MACD в процентах)
TA_Trix.cs      // TRIX (тройная сглаженная скорость изменения)
```

---

#### 3. 🧭 Направление тренда (Trend Direction)
**Критерий отнесения:**  
Индикатор показывает **направление движения** (вверх/вниз), сравнивая положение текущей цены относительно экстремумов за период.

**Характеристики:**
- Определяет, «ближе» ли максимумы или минимумы к текущей цене
- Часто используется в паре с индикаторами силы тренда

**Примеры из TALib:**
```csharp
TA_Aroon.cs     // Aroon Up/Down: чем ближе к 100 — тем сильнее направление
TA_AroonOsc.cs  // Aroon Oscillator (разница Aroon Up – Down)
TA_PlusDi.cs    // +DI (положительное направление)
TA_MinusDi.cs   // -DI (отрицательное направление)
TA_PlusDM.cs    // +DM (положительное направленное движение)
TA_MinusDM.cs   // -DM (отрицательное направленное движение)
```

---

#### 4. 💪 Сила тренда (Trend Strength)
**Критерий отнесения:**  
Индикатор измеряет **интенсивность тренда**, но не его направление. Чем выше значение — тем сильнее тренд.

**Характеристики:**
- Имеет логические уровни (например, ADX > 25 = сильный тренд)
- Не показывает, в какую сторону движется цена
- Используется для фильтрации сигналов во флет

**Примеры из TALib:**
```csharp
TA_Adx.cs       // ADX: >25 сильный тренд, <20 слабый/флет
TA_Adr.cs       // ADXR (усреднённый ADX)
TA_Dx.cs        // DX (базовый индекс направленного движения)
```

---

### 🔑 Важный нюанс: осцилляторы как индикаторы тренда

**Ключевой принцип:**  
Осциллятор с **большим периодом** (например, RSI(21), RSI(50)) ведёт себя иначе, чем с коротким (RSI(14)):

| Период осциллятора | Интерпретация зоны перекупленности/перепроданности |
|--------------------|---------------------------------------------------|
| **Короткий** (7–14) | Сигнал разворота: цена «устала», ожидается откат |
| **Длинный** (21+)   | **Диагностика тренда**: устойчивое пребывание в зоне = сильный тренд |

#### Как это работает на практике

| Сценарий                          | Короткий период (RSI 14)       | Длинный период (RSI 50)         |
|-----------------------------------|--------------------------------|---------------------------------|
| RSI > 70                          | «Перекупленность» → ждём падения | **Сильный восходящий тренд** → продолжение роста |
| RSI < 30                          | «Перепроданность» → ждём роста  | **Сильный нисходящий тренд** → продолжение падения |
| RSI колеблется 40–60              | Флет / слабое движение         | Отсутствие тренда               |

#### Примеры применения

```csharp
// Стратегия «Тренд + Коррекция»
// 1. Длинный RSI(50) > 70 → подтверждение восходящего тренда
// 2. Короткий RSI(14) < 40 → точка входа на коррекции
// 3. Вход в лонг при отскоке короткого RSI от зоны 30–40

// Стратегия «Дивергенция на тренде»
// 1. RSI(21) устойчиво в зоне 60–80 → восходящий тренд
// 2. Цена обновляет максимум, но RSI(21) не обновляет → скрытая слабость
// 3. Сигнал на разворот при подтверждении
```

> 💡 **Почему это работает?**  
> Длинный период «сглаживает» шум и отражает **долгосрочную силу движения**. Если даже на таком периоде осциллятор остаётся в зоне перекупленности — значит, покупатели доминируют **устойчиво**, а не кратковременно. Это не сигнал к продаже, а подтверждение тренда.

### Практические рекомендации

| Задача стратегии                     | Какую группу использовать       | Пример комбинации                                  |
|--------------------------------------|---------------------------------|----------------------------------------------------|
| Поиск точек разворота                | `Oscillators` (короткий период) | RSI(14) < 30 + Stochastic(14) < 20                |
| Диагностика тренда                   | `Oscillators` (длинный период)  | RSI(50) > 70 → восходящий тренд                   |
| Подтверждение тренда                 | `TrendStrength` + `TrendDirection` | ADX(14) > 25 + +DI > -DI                        |
| Фильтрация ложных сигналов           | `UnboundedMomentum`             | MACD выше нуля при покупке по короткому RSI       |
| Торговля во флет                     | Только `Oscillators`            | RSI(14) + CCI(20)                                 |
| Стратегия «Тренд + Коррекция»        | Комбинация периодов осциллятора | RSI(50) > 70 (тренд) + RSI(14) < 40 (коррекция)   |

> ⚠️ **Важно:**  
> - Не используйте осцилляторы с **коротким периодом** в сильном тренде — они будут давать ложные сигналы перекупленности/перепроданности.  
> - Для диагностики тренда применяйте **длинные периоды осцилляторов** (21+) или специализированные индикаторы (`TrendStrength`).  
> - Идеальная комбинация: `TrendStrength` (ADX) → подтверждение тренда + `Oscillators` (длинный период) → диагностика направления + `Oscillators` (короткий период) → точка входа.


## Overlap Studies (Индикаторы наложения)

Индикаторы наложения **отображаются прямо на ценовом графике** и используются для определения тренда, поддержки/сопротивления, точек входа и фильтрации шума. В отличие от осцилляторов, они не имеют фиксированного диапазона и работают непосредственно с ценовыми данными.

### Критерии группировки

#### 1. 📈 Скользящие средние (Moving Averages)

**Критерий отнесения:**  
Индикатор представляет собой **сглаженную линию цены**, рассчитанную по различным методам. Показывает направление и силу тренда.

**Характеристики:**
- Чем больше период — тем медленнее реакция на изменения цены
- Пересечение цены и скользящей средней — сигнал тренда
- Используются для определения поддержки/сопротивления

**Примеры из TALib:**
```csharp
TA_Sma.cs       // Simple Moving Average (SMA)
TA_Ema.cs       // Exponential Moving Average (EMA)
TA_Wma.cs       // Weighted Moving Average (WMA)
TA_Dema.cs      // Double Exponential Moving Average (DEMA)
TA_Tema.cs      // Triple Exponential Moving Average (TEMA)
TA_T3.cs        // T3 Moving Average (Tillson)
TA_Trima.cs     // Triangular Moving Average (TRIMA)
TA_Kama.cs      // Kaufman Adaptive Moving Average (KAMA)
TA_Mavp.cs      // Moving Average with Variable Period (Mavp)
```

---

#### 2. 📐 Каналы и ленты (Bands & Channels)

**Критерий отнесения:**  
Индикаторы, представляющие **диапазон цен** (верхняя и нижняя линии) вокруг средней линии. Показывают волатильность и уровни поддержки/сопротивления.

**Характеристики:**
- Ширина канала отражает волатильность
- Цена у края канала — сигнал разворота или продолжения тренда
- Используются для определения перекупленности/перепроданности

**Примеры из TALib:**
```csharp
TA_Bbands.cs    // Bollinger Bands (средняя линия + 2 стандартных отклонения)
TA_AccBands.cs  // Acceleration Bands (каналы на основе волатильности)
```

---

#### 3. 📌 Трендовые индикаторы (Trend Indicators)

**Критерий отнесения:**  
Индикаторы, **отслеживающие тренд** с помощью точек или линий, часто используемые как стоп-лоссы.

**Характеристики:**
- Точки ниже цены — восходящий тренд, выше — нисходящий
- Автоматически регулируются под тренд
- Используются для фильтрации ложных сигналов

**Примеры из TALib:**
```csharp
TA_SarExt.cs    // Parabolic SAR (Extended) — точки над/под ценой
```

---

#### 4. 📏 Уровни цен (Price Levels)

**Критерий отнесения:**  
Индикаторы, показывающие **средние или экстремальные цены** за период, используемые для определения поддержки/сопротивления.

**Характеристики:**
- Статические или динамические уровни
- Часто используются в комбинации с другими индикаторами
- Помогают определить точки входа

**Примеры из TALib:**
```csharp
TA_MidPoint.cs  // Midpoint (средняя точка диапазона цены)
TA_MidPrice.cs  // Midprice (средняя цена за период)
TA_MinMax.cs    // Min/Max (минимум и максимум за период)
```

---

### 🔑 Важный нюанс: комбинация скользящих средних

**Ключевой принцип:**  
Комбинация скользящих средних с **разными периодами** позволяет определить силу тренда и точки разворота:

| Скользящие средние | Интерпретация |
|--------------------|---------------|
| **Короткий период** (5–10) | Быстрый тренд, реакция на краткосрочные движения |
| **Средний период** (20–50) | Основной тренд, поддержка/сопротивление |
| **Длинный период** (100–200) | Долгосрочное направление тренда |

#### Как это работает на практике

| Сценарий                          | Пример комбинации | Интерпретация |
|-----------------------------------|-------------------|---------------|
| Цена выше всех MA (5, 20, 50)     | SMA(5) > SMA(20) > SMA(50) | Сильный восходящий тренд |
| Цена между SMA(20) и SMA(50)      | SMA(50) > SMA(20) > Цена | Нисходящий тренд с коррекцией |
| Пересечение SMA(5) и SMA(20) вверх | SMA(5) пересекает SMA(20) снизу вверх | Сигнал разворота вверх |

#### Примеры применения

```csharp
// Стратегия «Золотой крест»
// 1. SMA(50) пересекает SMA(200) снизу вверх → подтверждение долгосрочного тренда
// 2. Вход в лонг при отскоке цены от SMA(20)

// Стратегия «Тренд + Фильтр»
// 1. EMA(20) выше EMA(50) → восходящий тренд
// 2. Цена выше SMA(200) → долгосрочная поддержка
// 3. Вход при пробое локального максимума
```

> 💡 **Почему это работает?**  
> Скользящие средние с разными периодами фильтруют шум и показывают тренд на разных временных горизонтах. Короткий период реагирует быстро, длинный — медленно, но надежно. Комбинация позволяет определить силу тренда и избежать ложных сигналов.

| Задача стратегии                     | Какую группу использовать       | Пример комбинации                                  |
|--------------------------------------|---------------------------------|----------------------------------------------------|
| Определение направления тренда       | `MovingAverages` (длинный период) | SMA(50) > SMA(200) → восходящий тренд              |

| Торговля во флет                     | `PriceLevels`                  | Midprice как уровень для отскока                   |
| Стратегия «Тренд + Коррекция»        | `MovingAverages` (разные периоды) | SMA(50) > SMA(200) + цена отскакивает от SMA(20) |

> ⚠️ **Важно:**  
> - Не используйте короткие периоды скользящих средних в сильном тренде — они будут давать ложные сигналы разворота.  
> - Для долгосрочного тренда применяйте длинные периоды (SMA(200)).  
> - Идеальная комбинация: `MovingAverages` (длинный период) → подтверждение тренда + `BandsChannels` → определение волатильности + `TrendIndicators` → точка входа.
